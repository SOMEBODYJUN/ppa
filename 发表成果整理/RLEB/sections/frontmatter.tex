\title{Nonlinear RL Geometry and Error Bounds\\
for Local Proximal Point Convergence}
\author{菠萝之神}

\begin{abstract}
近端映射在零点附近不具有 Lipschitz 连续性时，其迭代仍可能收敛到
非孤立零点集中的一点。本文给出一组局部充分条件：
近端输出相对于输入最近零点的反射位移具有 H\"older 型控制，
原算子的真实残差在实际输出处满足误差界，且两者的标量组合严格收缩。
在输入覆盖和严格初始长度预算下，全部允许的近端选择均可无限进行，
轨道具有有限长度并收敛到零点；无需预先假设轨道留在工作区域。
一个平面三角系统表明，法向距离的线性收缩可以与非 Lipschitz 的
切向漂移同时存在，其锐 RL 指数为 $1/2$、锐残差误差界幂次为 $2$。
固定正定度量下的同类结论通过坐标变换获得，但须在变换后重新验证
近端几何、残差和输入覆盖。对于在全空间处处定义、反射映射具有
全尺度次线性 H\"older 界的完整近端映射，若完整零集为非空紧
$C^2$ 无边界流形，且局部条件在整个小管邻域统一成立，
则该零集的欧拉示性数必须为 $1$。
\end{abstract}

\medskip
\noindent\textbf{关键词：}近端点算法；H\"older 近端几何；

\section{引言}
\label{sec:introduction}

设 $F:\mathbb R^n\rightrightarrows\mathbb R^n$，$\lambda>0$。
近端点算法通过
\begin{equation}
 x^{k+1}\in J_{\lambda F}(x^k),\qquad
 J_{\lambda F}=(I+\lambda F)^{-1}
 \label{eq:ppa-intro}
\end{equation}
寻找 $F$ 的零点。当 $F$ 极大单调时，近端映射处处单值且牢固非扩张，
零点存在即可得到经典收敛结论\cite{Rockafellar1976PPA}。
度量次正则性进一步把残差与到零集的距离联系起来，
从而给出局部线性收敛估计\cite[Theorem~3.1]{Leventhal2009MetricSubregularityPPA}。
本文讨论近端映射在零点附近仅具有 H\"older 型控制的情形。
问题是：较强的输出误差界能否补偿较弱的近端几何控制，
使轨道仍收敛到可能非孤立的零集中的一点？

非单调近端迭代的研究已经发展出数种途径。
对亚单调及负余单调算子，可以借助正则化后算子的单调性分析局部迭代；
Combettes--Pennanen 还处理了负余单调算子的非精确、松弛近端迭代
\cite{CombettesPennanen2004Cohypomonotone}。
近乎平均映射理论将固定点几何与残差正则性配合，
允许具有扩张和集值行为的迭代
\cite{LukeThaoTam2018Quantitative}。
Luke--Tam 针对 PPA 提出次单调性条件，
将其与度量次正则性、截断值域覆盖结合，证明适当局部选择的线性收敛
\cite[Assumption~2, Theorem~2]{LukeTam2025GeneralizedMonotonicity}。
半单调性和 oblique weak Minty 条件则提供了另一类非单调几何，
并可用于松弛、预条件近端方法
\cite{EvensPasLatafatPatrinos2025SemimonotonePPA}。
这些理论使用的点对范围、零点锚和算法更新各不相同，
不能仅凭不等式名称判断其包含关系。

与近端几何并行，误差界理论研究如何由残差控制到解集的距离。
线性误差界之外，H\"older 次正则性、一般模量以及高阶次正则性
允许这种控制具有不同的阶数
\cite{LiMordukhovich2012HolderSubregularityPPA,
Kruger2016NonlinearSubregularity,MordukhovichOuyang2015HigherOrderSubregularity}。
这里需要把两项估计分开：近端几何控制算法步长，
输出误差界控制下一步到零集的距离。
对于 $x^+\in J_{\lambda F}(x)$，近端包含关系只给出
$r_F(x^+)\leq\|x-x^+\|/\lambda$，其中
$r_F(y)=\inf_{v\in F(y)}\|v\|$。
它不是选定图值的范数，误差界也必须在实际输出处适用。

本文先用一个与具体算子无关的收敛判定说明证明所需的两项估计：
到闭零集的距离几何收缩，步长沿该收缩尺度可和。
随后用最近零点锚的非线性 RL 比较取得步长控制，
再与输出真残差误差界组合。
同一组条件作用于每个允许的近端输出，因此允许关系可以严格多值，
极限点也可以随选择改变。
严格初始长度预算保证所有有限轨道前缀留在工作区域，
同时使输入覆盖得以逐步继续使用。
全对图像 RL 条件是验证锚定条件的一条充分途径；
它还保证图块内的输出唯一性，但不自动给出输入覆盖或完整纤维识别。

一个简单的平面三角系统显示上述条件如何起作用：
法向坐标按固定比例衰减，切向坐标却随法向坐标的平方根移动。
由此产生的近端映射不满足局部 Lipschitz 控制，
而切向位移仍可求和，整条轨道收敛到零线中的一点。
在固定正定度量下，可以通过坐标变换使用同一证明，
条件须对变换后的完整对象重新检验。
我们最后考察局部收敛对全局近端几何的限制：
若完整反射近端映射满足全尺度次线性 H\"older 界，
紧光滑闭流形零集的整个小管邻域又严格吸引，
则固定点指数要求其欧拉示性数为 $1$。
这项结论需要全局条件，不能由局部收敛本身推出。

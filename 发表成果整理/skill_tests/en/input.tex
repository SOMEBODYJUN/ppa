The aim of the present section is to provide a discussion of the fact that convergence can be obtained under the assumptions which are stated here.
For each actual proximal output $y$, we use the true residual $r_F(y)=\inf_{v\in F(y)}\|v\|$.
An error bound $d(y,S)\le c\,r_F(y)^q$ and a reflected-resolvent estimate with exponent $\gamma$ yield local contraction when $q\gamma>1$, provided that the orbit remains in the certified neighborhood.
A strict length budget ensures this localization. The resulting allowed orbit has finite length and converges to a point in $S$.

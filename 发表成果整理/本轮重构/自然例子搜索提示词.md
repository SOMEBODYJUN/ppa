# 自然近端收敛例子的团队搜索提示词

你是数学合作者，不是例子的包装者。请独立寻找一个比当前秩亏 Hamilton 例更自然、正文证明更短的非 Lipschitz 近端收敛例。先读取当前完整主定理、RL/真实残差定义、原例和已锁定贡献。候选优先来自清楚的优化或动力学模型；若仅是机制例，明确说出。写定 F、完整零集 S、λ、输入域、全部近端纤维、RL 的作用域与同一组常数。必须解析证明近端输入覆盖、完整图或允许关系桥、真实残差误差界、最近零点锚、同窗兼容和留域，不能以单支、任选图值或数值轨道代替。优先给闭式完整近端映射、最佳 Hölder 指数与 EB 幂次、精确轨道及极限；若不可能，说明最短承重证明。至少比较一个优化来源候选、一个简短机制候选和原例，攻击跨符号、零输入、非孤立零集、远端完整纤维与临界系数。用 Python 检查边界、算术和反算，但全称结论由解析证明支持。把“自然程度、有效性、示例作用、创新性”分开评估，不为原例辩护，也不为追求漂亮而丢掉原例的关键作用。最后推荐一个候选，列出采用后必须删除或重写的摘要、比较段和附录；不要提出多技能流水线。可进一步检查 GPPA 度量变化：先定义算法，逐项核实覆盖、固定点、真实残差和所有输出，不默认任意正定度量保留结论。

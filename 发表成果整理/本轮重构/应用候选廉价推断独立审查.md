## 2. 完整近端：存在、唯一、连续与临界非光滑点

令 `w=u−v`。逐坐标有
\[
(u_i^3-v_i^3)(u_i-v_i)
=w_i^2(u_i^2+u_iv_i+v_i^2)
\ge w_i^4/4.
\]
于是
\[
\langle H(u)-H(v),w\rangle
\ge\tfrac14\sum_iw_i^4+\tfrac14w^\top Lw
\ge\|w\|^4/(4n)>0\quad(w\ne0). \tag{D1}
\]
`H` 严格单调，因此 injective。另一方面
\[
\langle H(u)+b,u\rangle
=\sum_i u_i^4+u^\top Lu/4\ge\|u\|^4/n,
\]
故 `||H(u)||≥||u||³/n−||b||`，`H` proper。对于任意固定输入 `x`，在充分大球面有 `⟨H(u)−x,u⟩>0`，同伦到 `Id` 给 degree `1`，因此 `H(u)=x` 有解。injectivity 给唯一；properness 与唯一性保证逆连续（对收敛输入，输出有界，每个聚点必须是同一个唯一输出）。这证明了全空间上的**完整纤维**存在且单值，未选择或丢弃其它 stationary branches。

由 D1 与 Cauchy 可进一步得
\[
\|T(x)-T(y)\|\le(4n)^{1/3}\|x-y\|^{1/3}.
\]
因为 `D` 消灭常向量，有准确恒等式
\[
T(-b+s\mathbf1)=\sqrt[3]{s}\,\mathbf1.
\]
因此 `−b` 处指数 `1/3` sharp；这里不能是 locally Lipschitz，也不能有任一 exponent 大于 `1/3` 的局部 Hölder 界。`T` 在此非可微。这个点不是 fixed point：`T(−b)=0≠−b`，因为给定 `b≠0`。所以后面的局部 index 公式没有撞上非光滑点。

## 6. 非对称方向、局部 index 与总 index

每个真实零点 `u` 都非零，因为 `F(0)=−b≠0`。对任意实 `u≠0`，
\[
\operatorname{Sym}DH(u)=3\operatorname{diag}(u_i^2)+L/4\succ0.
\]
证明：其 quadratic form 为零必须使方向 vector 为 graph Laplacian 的常向量，且在至少一个 `u_i≠0` 坐标为零，故方向 vector 为零。对该 SPD symmetric part `Q` 和 skew part `K`，路径 `Q+tK` 全程可逆，因为 `wᵀ(Q+tK)w=wᵀQw>0`；determinant 沿路径连续不变号，起点 `detQ>0`。因此 `detDH(u)>0`，不需要 `DH` 对称。

在所有真实 fixed points，inverse function theorem 局部合法，于是
\[
\det(I-DT(u))=\det DF(u)/\det DH(u),
\quad i(T,u)=\operatorname{sign}\det DF(u). \tag{D5}
\]
16 个 stable roots 的 `SymDF` SPD 同理使 `detDF>0`，各贡献 `+1`。

全局 index 不要求 `T` 全球可微。对 `u=T(x)`，前面的 quartic inequality 给
\[
\|T(x)\|\le[13(\|x\|+\|b\|)]^{1/3}.
\]
充分大球上 `T` 严格映入自身内部，全部 fixed points 均在该球内；`x−tT(x)` 在球面无零点，故 `deg(Id−T)=1`。加性给 `M` 外总 index `1−16=−15`。

由全部实根 regular，额外每个 index 都为 `±1`。因此至少 `15` 个管外负指数点，管外实点数至少 `15` 且为奇数，总实点数至少 `31`。这不证明只有 `15` 个负指数点，也不提供全部零点分类。

原 C254 全尺度次线性**反射**前件仍不成立：`T(x)=O(||x||^{1/3})`，`2T(x)−x` 留下 linear 主项。这里用的是明确的独立大球 index bridge；局部管 index 与加性可沿已核经典接口使用。

\]

所以 `0, ±1/√2·1` 都是该输入的真实完整输出。正定核不自动保持原完整单值性；此攻击准确，并没有误把核改变后的输入或 `λ` 沿用旧值。

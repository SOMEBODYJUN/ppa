# C351 的条件、结论和适用范围

这份结果已经给出两个有明确附加条件的恢复定理，并保留了原 RLEB 到 PPA 收敛的推导。恢复方向条件时，附加条件把真残差与距离的关系固定成精确等式；恢复正则性时，附加条件把反射幅度固定成精确等式。因而可以接收一个限定范围内的共同条件。一般单调性与不同正则性质是否来自同一结构，仍需超出这两种精确等式的理论。

正文只用三个点记号。\(x\) 是输入，\(z\) 是从 \(x\) 走一步得到的输出，\(y\) 是任意一个允许输出，可以来自另一个输入。距离和真残差始终写成
\[
d(x)=\operatorname{dist}(x,S),\qquad
r_F(y)=\inf_{v\in F(y)}\|v\|.
\]
每次出现真残差，都对完整的 \(F(y)\) 取下确界。

<a id="setup"></a>
## 1. 固定原问题

设 \(X\) 为有限维欧氏空间，\(F:X\rightrightarrows X\)，\(S\subseteq F^{-1}(0)\) 非空闭。固定步长 \(\lambda>0\)、开集 \(U\)、半径 \(R>0\)。对每个满足 \(x\in U\)、\(d(x)\le R\) 的输入，给定非空允许输出集
\[
\mathcal J(x)\subseteq
\{z:x-z\in\lambda F(z)\}.
\]
所有这些输出组成集合 \(Y\)。

\(P_S(x)\) 表示离输入 \(x\) 最近的零点集合。对同一输入及其输出，原反射条件写成
\[
\min_{p\in P_S(x)}\|2z-x-p\|\le\omega(d(x)).
\tag{1}
\]
最小值存在。这个写法表示至少可以选到一个最近零点满足条件；所选零点可以随输出 \(z\) 改变。

<a id="condition"></a>
## 2. 把 \(M\) 直接写出来

固定 \(0<\kappa<1\)。条件 \(M_\kappa\) 包含以下两项。

首先，每个 \(y\in Y\) 满足
\[
d(y)\le2\kappa\lambda r_F(y).
\tag{2}
\]

其次，对任意输入 \(x\)、任意 \(z\in\mathcal J(x)\)，以及独立选取的任意 \(y\in Y\)，要求
\[
\boxed{
d(x)<\frac{d(y)}{\kappa}
\quad\Longrightarrow\quad
\min_{p\in P_S(x)}\|2z-x-p\|
+\frac{d(y)}{\kappa}
\le2\lambda r_F(y).
}
\tag{3}
\]
若 \(d(x)=d(y)/\kappa\)，这一对点不受式 (3) 限制。

式 (3) 把两个位置的数据放在一起。左边是在输入 \(x\) 处实际出现的反射幅度，右边是在输出 \(y\) 处完整纤维的真残差。只要输入离解集足够近，这个反射幅度就必须小于右边剩下的余量。

式 (2) 对应原稿中的人工零基点。单独写出这条不等式，就不需要再引入一个虚构的点。

<a id="recovery"></a>
## 3. 加什么条件，分别恢复两侧

以下两个恢复定理另取全空间输入，所有输入都有允许输出；\(S\ne X\) 为非空仿射集。固定同一个连续、非负、非减函数 \(\omega_0\)，且 \(\omega_0(0)=0\)。这里使用全部距离尺度。

### 3.1 固定真残差的精确大小，恢复反射条件

附加条件 \(A\) 是每个允许输出都满足
\[
\boxed{
2\lambda r_F(y)=
\frac{d(y)}{\kappa}
+\omega_0\!\left(\frac{d(y)}{\kappa}\right).
}
\tag{A}
\]
还要求输出到 \(S\) 的距离遍历全部 \([0,\infty)\)。

在这些条件下，
\[
\boxed{
M_\kappa
\quad\Longleftrightarrow\quad
\min_{p\in P_S(x)}\|2z-x-p\|
\le\omega_0(d(x))
\quad
\text{对全部允许步 }x\to z.
}
\tag{4}
\]

证明可以直接读式 (3)。固定一步 \(x\to z\)，任取 \(t>d(x)\)。由距离遍历，可以选一个输出 \(y\) 满足 \(d(y)=\kappa t\)。将条件 \(A\) 代入式 (3)，得到
\[
\min_{p\in P_S(x)}\|2z-x-p\|\le\omega_0(t).
\]
令 \(t\downarrow d(x)\)，由连续性得到式 (4) 右边。

反过来，若右边成立，当 \(d(x)<d(y)/\kappa\) 时，非减性给出
\[
\min_{p\in P_S(x)}\|2z-x-p\|
\le\omega_0(d(x))
\le\omega_0(d(y)/\kappa).
\]
条件 \(A\) 随即给出式 (3)，也给出式 (2)。

这里恢复的是原最近输入零点作锚的 RL 条件。若再限定 \(\omega_0(t)=t\)、\(S=\{0\}\)、\(F\) 是完整单值线性关系，才可进一步把它认作通常的全对单调性。一般非线性关系上的零锚条件和全对单调性须分别陈述。

### 3.2 固定反射幅度，恢复真残差误差界

附加条件 \(B\) 是每一步都达到指定反射幅度，
\[
\boxed{
\min_{p\in P_S(x)}\|2z-x-p\|=\omega_0(d(x)).
}
\tag{B}
\]
在全空间输入和原根覆盖下，输入到 \(S\) 的距离遍历全部 \([0,\infty)\)。

在这些条件下，
\[
\boxed{
M_\kappa
\quad\Longleftrightarrow\quad
2\lambda r_F(y)\ge
\frac{d(y)}{\kappa}
+\omega_0\!\left(\frac{d(y)}{\kappa}\right)
\quad(y\in Y).
}
\tag{5}
\]

证明仍从式 (3) 出发。固定 \(d(y)>0\) 的输出，任取 \(0\le t<d(y)/\kappa\)，选距离为 \(t\) 的输入及其一个输出。条件 \(B\) 给出
\[
2\lambda r_F(y)\ge
\frac{d(y)}{\kappa}+\omega_0(t).
\]
令 \(t\uparrow d(y)/\kappa\)，由连续性得到式 (5)。反向用 \(\omega_0\) 非减即可验证式 (2)、(3)。

式 (5) 是一条误差界，因为右边作为 \(d(y)\) 的函数连续、严格递增且趋于无穷。给定真残差的上界，就有唯一对应的距离上界。直接写成式 (5)，便无需另设函数和反函数。

### 3.3 两个附加条件实际规定了什么

| 恢复目标 | 预先固定的内容 | 由 \(M_\kappa\) 恢复的内容 |
| --- | --- | --- |
| 锚定 RL | 真残差与距离处处满足等式 \(A\) | 每步反射幅度的上界 |
| 真残差误差界 | 每步反射幅度处处满足等式 \(B\) | 真残差与距离之间的不等式 |

条件 \(A\) 本身已经强于式 (5) 的误差界，条件 \(B\) 本身已经强于式 (4) 的 RL 上界。它们各自固定了另一侧的精确大小。两项等价据此成立，但其作用域要与这两项强前提一同说明。

<a id="moduli"></a>
## 4. 它对原 RLEB 证明了什么

下面回到第 1 节的有限工作范围。只引入一个反复使用的函数，收集各距离范围内实际出现的最大反射幅度，
\[
W(t)=
\sup\left(
\left\{
\min_{p\in P_S(x)}\|2z-x-p\|:
x\in U,\ d(x)\le t,\ z\in\mathcal J(x)
\right\}
\cup\{0\}
\right),
\quad 0\le t\le R.
\tag{6}
\]
因此，任何适用于原图的非减反射模都必须满足 \(W(t)\le\omega(t)\)。

固定原残差评价范围 \(0\le r_F(y)\le\bar t\)。原稿证明以下两件事等价。

- 存在一对有限、非减、零处连续且零值为零的原模 \(\omega,\psi\)，使反射条件 (1)、真残差误差界
  \[
  d(y)\le\psi(r_F(y))
  \qquad(y\in Y,\ r_F(y)\le\bar t)
  \]
  成立，同时满足原参数条件
  \[
  \frac{R+\omega(R)}{2\lambda}\le\bar t,\qquad
  \psi\!\left(\frac{t+\omega(t)}{2\lambda}\right)\le\kappa t
  \quad(0<t\le R),
  \]
  以及原可和条件
  \[
  \sum_{j=0}^{\infty}
  \frac{\kappa^jR+\omega(\kappa^jR)}2<\infty.
  \]
- \(M_\kappa\) 成立，并且
  \[
  \frac{R+W(R)}{2\lambda}\le\bar t,\qquad
  \sum_{j=0}^{\infty}
  \frac{\kappa^jR+W(\kappa^jR)}2<\infty.
  \tag{7}
  \]

这个等价回答的是，能否为原图找到一对符合旧 RLEB 的模。它并不表示事先指定的任意一对模都可行。

关键关系可直接写成
\[
\boxed{
r_F(y)\le\frac{t+W(t)}{2\lambda}
\quad\Longrightarrow\quad
d(y)\le\kappa t
\qquad(0\le t\le R,\ y\in Y).
}
\tag{8}
\]
在 \(W(R)<\infty\) 时，式 (8) 与 \(M_\kappa\) 等价。

从 \(M_\kappa\) 证明式 (8)，只需反证。若 \(d(y)>\kappa t\)，式 (3) 对所有 \(d(x)\le t\) 的允许步都适用。取反射幅度的上确界，并用式 (2) 包含零基线，得到
\[
W(t)+\frac{d(y)}{\kappa}
\le2\lambda r_F(y)
\le t+W(t),
\]
矛盾。

反过来，同一个最近零点上的三角不等式给出
\[
d(z),\ \|x-z\|
\le\frac{d(x)+W(d(x))}{2},
\qquad
\lambda r_F(z)\le\|x-z\|.
\tag{9}
\]
所以每个输出都满足 \(r_F(y)\le(R+W(R))/(2\lambda)\)。式 (8) 在 \(t=R\) 给出 \(d(y)/\kappa\le R\)。若 \(d(x)<d(y)/\kappa\)，对每个
\[
d(x)\le t<d(y)/\kappa
\]
应用式 (8) 的逆否命题，得到
\[
2\lambda r_F(y)>t+W(t)
\ge t+\min_{p\in P_S(x)}\|2z-x-p\|.
\]
令 \(t\uparrow d(y)/\kappa\)，即得式 (3)。对 \(0\le t<d(y)/\kappa\) 使用 \(W(t)\ge0\)，同样得到式 (2)。

原模推出 \(M_\kappa\) 时，使用 \(W\le\omega\)，由原误差界和参数条件直接得到式 (8)。由 \(M_\kappa\) 重建模时，可以取
\[
\omega(t)=W(t),\qquad
\psi(s)=
\sup\bigl(\{d(y):y\in Y,\ r_F(y)\le s\}\cup\{0\}\bigr).
\tag{10}
\]
式 (7) 保证 \(W\) 在零处连续、取零值。式 (2) 给出 \(\psi(s)\le2\kappa\lambda s\)，保证 \(\psi\) 的零处性质。式 (9) 保证输出距离一致有界，式 (8) 给出重建后的原参数相容。上述证明允许原模在正尺度发生跳跃。

<a id="ppa"></a>
## 5. 原 PPA 为什么收敛

先看当前一步 \(x\to z\)。若 \(d(z)>\kappa d(x)\)，式 (3) 可以取 \(y=z\)。同一最近输入零点上的三角不等式于是给出
\[
\begin{aligned}
\min_{p\in P_S(x)}\|2z-x-p\|+\frac{d(z)}{\kappa}
&\le2\lambda r_F(z)\\
&\le2\|x-z\|\\
&\le d(x)+\min_{p\in P_S(x)}\|2z-x-p\|.
\end{aligned}
\]
消去两边相同的反射项，得到 \(d(z)\le\kappa d(x)\)，矛盾。因此每个允许步都满足
\[
\boxed{
d(z)\le\kappa d(x),\qquad
\|x-z\|\le\frac{d(x)+W(d(x))}{2}.
}
\tag{11}
\]

取初值 \(x^0\in U\)、\(d(x^0)\le R\)，满足
\[
\sum_{j=0}^{\infty}
\frac{\kappa^j d(x^0)+W(\kappa^j d(x^0))}{2}
<
\operatorname{dist}(x^0,X\setminus U).
\tag{12}
\]
从任意已构造的有限前缀再选一步，式 (11) 保证距离仍不超过 \(R\)，已走长度小于式 (12) 的右边，因此下一点仍在 \(U\)。非空覆盖便能继续使用，轨道可无限延拓。

式 (7) 保证总步长有限，所以点列为 Cauchy 列。又由式 (11)，到闭集 \(S\) 的距离趋于零，故点列收敛到 \(S\cap U\) 中一点。

每组原 RLEB 数据都有 \(W\le\omega\)，因此原初值预算所允许的全部初值仍被保留。若要宣布有非平凡收敛域，还须该认证域中有不属于 \(F^{-1}(0)\) 的初值。

<a id="assessment"></a>
## 6. 对研究目标的判断

按已经写明的要求，这次有同一个 \(M_\kappa\)、两种附加条件下的等价、原一般非线性 RLEB 导入，以及原 PPA 的续接和收敛证明。可以接收这些带明确范围的定理。

对老师希望的更一般解释，当前证据还有以下边界。

- 两个恢复使用全距离范围、连续参考模和精确幅度等式。原 RLEB 的有限工作范围导入允许正点跳跃，但这项导入不能自动取消恢复定理的额外前提。
- 原 PPA 收敛定理还使用根覆盖、式 (7) 的残差评价范围和可和性，以及式 (12) 的初值留域预算。显示的 \(M_\kappa\) 式本身给出距离收缩，点收敛的证明还用了这些条件。
- 一般恢复的是最近输入零点作锚的 RL。通常全对单调的恢复还用了完整单值线性关系等限制。
- \(M_\kappa\) 自带式 (2) 的线性真残差误差界。因此，它能够承接的正则条件须在所认证范围内足以产生这个结论。
- 加上残差评价范围和可和性后，它与“存在一对相容的原 RLEB 模”等价。它对旧条件的整理和两侧恢复有具体内容，更广泛的单调与正则理论尚未由此得到。
- 与最接近旧结论相比，值得核对的新意是消去两套模的存在量词，以及同一关系的两个恢复。公开首创仍未认定。

数学条件成立、这些条件能解释到什么程度、结果是否新颖，应分别按上述证据判断。

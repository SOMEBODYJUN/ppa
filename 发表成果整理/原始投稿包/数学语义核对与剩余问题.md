# 数学语义核对与剩余问题

## 最终核对结论

本轮重写没有改变核心数学语义。下列内容已逐项核对：

- graph-level all-pairs RL 与较弱的 solution-comparison 条件被明确区分；
- 主定理采用 Luke--Tam Assumption 2(d)(ii) 同型的局部 range-coverage 接口，不再把局部存在性写成自建理论；
- coverage、RL 参数、误差界参数和兼容常数集中在前置的 Assumption 2.4；
- 图上 RL 推出相应局部输入块上 (J_{\lambda F}) 的单值性；Corollary 2.7 单独保留对所有允许 proximal selections 的一致结论；
- 能量不等式与步长界分别承担距离控制和有限长度/局部化作用；
- 步长界保持精确系数 (1/2)：(s\le(d+Ld^\gamma)/2)；
- 误差界施加于实际 proximal output，残差为 (s/\lambda)；
- 主定理的初始半径预算同时保证迭代可继续、误差界有效并使轨道留在局部区域；
- 幂律直接判据的临界阈值为 (\lambda m>L/2)，能量判据的阈值为 (\lambda m>L/\sqrt2)；
- 线性端点在 (L=1) 时恢复 Leventhal 的已知因子；
- 二值平方根例子的 (J) 公式、最优 RL 指数 (1/2)、二次误差界、距离因子 (1/4) 和点收敛渐近因子 (1/2) 均相互一致；
- 对旧理论的比较只排除同一完整邻域上的特定有限二次/Lipschitz 证书，不声称旧理论不能处理一般多值算子。

## 仍然存在的问题

1. **一般 gauge 的展示仍弱于定理本身。** 主定理允许一般非减误差界函数 (\psi)，但旗舰轨道例子仍是幂律误差界。若要把“一般 gauge”列为主要创新，应补一个真正不能由局部幂包络替代、且能产生完整轨道结论的实例；否则摘要和投稿信应把一般 gauge 定位为自然定理形式，而非首要新颖性。

2. **signed-Schur 模块尚缺全球优先权审计。** 其作用和数学证明已经独立成形，但强单调反演、隐函数消元和一维增长等组成部分各有成熟先例。当前稿件只把联合证书作为可计算验证工具，不作“首次”声明。投稿前仍应对最接近的 seam/active-set/graph-parametrization 文献做定理级排查。

3. **目标期刊尚未确定。** 当前为通用 A4 稿。选定期刊后还需转换模板，补充 MSC/keywords，并按该刊格式更新在线优先文献的卷期页码。

4. **多值优势的范围必须保持精确。** 旗舰例子中的 (F) 是二值的，但完整 proximal mapping (J) 是单值且非 Lipschitz。文章的主定理确实允许多值 proximal selections，不过当前显式例子展示的是“多值图导致非 Lipschitz proximal 几何”，不是随机分支迭代。

这些问题不构成现有定理或例子的逻辑错误；它们决定投稿时可主张的新颖性强度及下一轮研究重点。

# Research Cosmos · 动态研究宇宙

打开 [index.html](index.html)。这是 **D3-force + SVG + JavaScript** 前端：离线嵌入真实研究图，行星/卫星持续公转，主题星系作为整体缓慢移动并相互避让，内部节点局部松弛，超边按当前天体位置实时重绘。背景星场使用 Canvas。无需 Java、Flash、CDN 或运行时网络。

当前来源快照：294 个真实节点、194 条真实超边；这个数字来自 `research/graph.json`，以后重建会自动变化。这里没有把 600 个程序素材数量当作已验收美术。

## 像素美术层

- [舰船与星球接触表](art/contact-sheet.png) 同时展示地图尺寸、放大尺寸与单色轮廓。[六舰近景与多尺度对照](art/fleet-detail.png) 展示抬高的舰桥、顶甲板、厚船舷与推进器。现有 **20 种原创船体构型、12 种星球地貌**；材质、细节与 ID 可稳定组合，但组合数不等于逐件人工验收的独立构型。舰船近景正常显示宽度约 48 px，总览缩放下隐藏，以免遮盖星系关系。它借用复杂 2.5D 像素星舰的视觉语言，没有复制其他游戏的具体素材。
- 太阳系八个入口分别指定不同的外观；其余对象依据稳定 ID 选择。小卫星采用简化图形，中央太阳采用像素表面与柔和光晕。外观是**导航与美术**，不编码命题真假、状态、重要性或依赖类型。
- 美术源码与接口在 `src/visuals.js`：`ship(edgeId)`、`planet(node)`、`shipCatalog`、`planetCatalog`、`visualBounds(node)`；航道实现仍在 `src/app.js`。可展开的舰船图鉴在详情面板内。新增构型时先看 24/40/80 px 与单色轮廓，检查实际路径上的尺寸，再重建页面。
- 重建接触表：`node visualization/cosmos/art/contact-sheet.cjs`，再以 `node visualization/cosmos/art/rasterize.cjs visualization/cosmos/art/contact-sheet.svg visualization/cosmos/art/contact-sheet.png` 栅格化。SVG 是可编辑的矢量像素图形，PNG 只用于预览。

## 进入方式

- **太阳系**：`R02` 恒星及八个真实入口 `D01,D02,D03,D04,COV,CMP,LOC,R01`。
- **全宇宙**：点击命名的主题星系进入。主题 glyph 是导航分组，不是新命题。
- 点击天体查看图 ID、标题、规范正文与关联关系。悬停查看摘要。点击 `∧` 枢纽查看**全部输入、输出、relation、scope、status 原文**。
- `/` 搜索全部节点与超边。滚轮/触控缩放，空白宇宙背景可拖动平移；鸟瞰可拖动星系 glyph，连内部星体与航道端点一并移动，再由星系层碰撞力避让；近景的非轨道节点可单独拖动后局部松弛。`＋/−` 按钮也可缩放。
- `Ⅱ` 暂停公转、纹理自转、星系形态旋转与航船动画；布局可能继续完成一次松弛。支持 `prefers-reduced-motion`，开启时初始停止动画。速度有 `0.35×/1×/3×`。
- `航道：关联 / 全部 / 隐藏` 控制密度。选中星体时，显示它直接参与的超边以及所属星域真正参与的跨域超边；详情把两者分开。鸟瞰默认展示全部 30 条真实跨域超边。Gaussian 星域在当前图中暂无线索通到其他星域，它与最近星域的灰色虚线只供导航，明确不是数学超边。
- `＋ 生长演示` 是**隔离沙盒**：8 个明显标明 `DEMO` 的临时对象在局部排开，可退出恢复。它从不写回规范图。

## 宇宙形态与数学含义

| 画面 | 身份与范围 |
| --- | --- |
| 太阳系 | RLEB–PPA 主链；中心真实节点 `R02` |
| 八个公转行星 | 八个导航入口；不声称八个必要条件或真实太阳系物理尺度 |
| 六个卫星 | `R03,R04,GROW,SCHUR,COLLIDE,FULL` 六个独立节点；导航父对象在详情显示。公转不是数学依赖 |
| 螺旋、椭圆、侧视尘盘、环状、相互作用、弥散星云 | 各个命名主题区域的形态；不决定定理证据状态 |
| 未知暗星域 | 算子空间和开放规模比较方向；`SIZE` 仍是可独立打开的真实节点 |
| 探测器与航线 | 阅读方向动画，不是 PPA/Markov 动力模拟。输入合取到 `∧` 后再到输出 |
| 红色断续线和终端叉号 | 原记录 `refutes` / `limits`，没有正向飞行的证明船 |

二进制条件刷新与 Gaussian Gibbs 有独立星系、残差与节点；不得通过空间分组替换其数学对象。完整约束见 [上层语义契约](../COSMOS_SEMANTIC_CONTRACT.md)。

## 技术与稳定增长

1. **权威数据**：`../../research/graph.json`。页面内嵌逐字义一致的 JSON，运行模型只使用副本。
2. **持久语义锚点**：`data/anchors.json` 按 ID 保存。追加/乱序/删除恢复不洗牌旧锚点；删除节点的旧锚点保留以便恢复。
3. **两层动态排布**：一个 D3 simulation 处理主题星系的缓慢漂移、真实跨域关系带来的微弱吸引、避碰与拖动；另一个处理内部非轨道节点的斥力、碰撞与锚点回拉。星系位移同步平移内部星体、锚点目标、公转中心和超边端点。拖动中心贴图时，同时更新中心的 D3 固定目标与全部成员的位置；非轨道成员在指针停留期间保持相对中心偏移，公转成员继续绕移动后的父对象运动。松手后以落点更新星系 home 并解除临时固定。D3 的成员锚点力和星系 home 力在每次 tick 前重新读取当前目标，避免松手或恢复动画后被旧缓存拉回。这个绑定只有坐标约束，没有可见连线。新增图从已有渲染位置续接，语义锚点不被动画写回；渲染位置允许松弛。
4. **公转层**：太阳固定在太阳系的局部中心，整个太阳系可以移动；八个行星有不同周期；卫星在父节点周围真实运动。轨道运动不改节点 ID。短相位绕行用于避免卫星投影重叠，故是科幻导航运动而非严格天体力学模拟。
5. **航道层**：每条超边拥有唯一合取枢纽，各输入分别接入，输出从枢纽接出。端点每帧追踪当前天体位置，箭头/终止符位于天体外缘。力学内部的 links 仅用于排布，不在页面画成输入间的串联推理。
6. **层级显示**：总览显示主题形态，近看显示真实节点及轨道；文本随缩放适配。全部节点始终可搜索、通过键盘/目录进入。

```sh
python visualization/cosmos/build.py
node visualization/cosmos/tests/test_engine.js
```

运行中追加真实图数据：`window.cosmos.updateGraph(newGraph)`；输入须有唯一 ID 和完整超边端点。`window.cosmos.anchors`、`.positions`、`.state` 供调试/持久化读取。方法 `.selectNode(id)`、`.selectEdge(id)`、`.focus(id)`、`.pause()`、`.resume()`、`.reset()` 不修改研究图文件。真实数据持久写入仍通过规范流程编辑 `graph.json` 后重建。

## 验证范围

22 项结构/数值测试通过：除原有图谱、轨道与增长检查外，按页面的外层力学→内部力学→公转顺序检查拖动中心跟随指定位置、停止指针后的多帧保持、释放后 240 帧成员仍在新中心周围，以及暂停拖动→释放→恢复 150 帧。另直接核验已初始化的四个 D3 位置力读取更新后的成员锚点、home 和时钟；也检查航道端点、星系重叠后的分离，以及跨域桥只能来自真实超边。旧测试只验成员相对中心的偏移，整组被拉回旧位置时仍会通过；本次新增的中心绝对位置检查在修复前第一帧即失败。当前图有 30 条跨域超边；Gaussian 星域为 0 条。测试是离散场景，不是任意拖动轨迹的碰撞定理。压力例旧渲染位置最大松弛约 **61.9 个世界坐标单位**。

[太阳系 t=0](qa/solar-0.png)、[t=12s](qa/solar-12.png)、[全宇宙](qa/overview.png) 是此前同引擎/天体 SVG 的静态渲染快照，本次未以这些旧图验收拖动修复。它们**不是浏览器截图**，没有验证 CSS 侧栏、字体回退、触控和真实帧率。

**真实浏览器交互/视觉验收尚未完成。** 新增 `tests/test_browser.js`，准备通过真实 SVG 鼠标事件检查运行/暂停两种拖动、释放后 120 帧、公转和 E02 合取端点，以及近景隐藏 glyph 不截获天体输入。脚本已通过语法检查；当前环境虽有 Playwright，却缺少 Chromium 可执行文件，因此五个浏览器场景没有实际运行，也没有新浏览器截图。先前远程浏览器预览被自动审批拒绝，本次未绕过。具备 Playwright 与已安装 Chromium 的环境可运行：

# Research Cosmos · 动态研究宇宙

打开 [index.html](index.html)。这是 Astra 新写的 **D3-force + SVG + JavaScript** 前端：离线嵌入真实研究图，行星/卫星持续公转，非轨道节点由开源力导向引擎排布，超边按当前天体位置实时重绘。背景星场使用 Canvas。无需 Java、Flash、CDN 或运行时网络。

当前来源快照：294 个真实节点、194 条真实超边；这个数字来自 `research/graph.json`，以后重建会自动变化。这里没有把 600 个程序素材数量当作已验收美术。

## 进入方式

- **太阳系**：`R02` 恒星及八个真实入口 `D01,D02,D03,D04,COV,CMP,LOC,R01`。
- **全宇宙**：点击命名的主题星系进入。主题 glyph 是导航分组，不是新命题。
- 点击天体查看图 ID、标题、规范正文与关联关系。悬停查看摘要。点击 `∧` 枢纽查看**全部输入、输出、relation、scope、status 原文**。
- `/` 搜索全部节点与超边。滚轮/触控缩放，背景拖动平移，非轨道节点可拖动后局部松弛。`＋/−` 按钮也可缩放。
- `Ⅱ` 暂停公转、纹理自转、星系形态旋转与航船动画；布局可能继续完成一次松弛。支持 `prefers-reduced-motion`，开启时初始停止动画。速度有 `0.35×/1×/3×`。
- `航道：关联 / 全部 / 隐藏` 控制密度。太阳默认显示 E02/E03；其他节点可展示自己的关系。
- `＋ 生长演示` 是**隔离沙盒**：8 个明显标明 `DEMO` 的临时对象在局部排开，可退出恢复。它从不写回规范图。

## 宇宙形态与数学含义

| 画面 | 身份与范围 |
| --- | --- |
| 太阳系 | RLEB–PPA 主链；中心真实节点 `R02` |
| 八个公转行星 | 八个导航入口；不声称八个必要条件或真实太阳系物理尺度 |
| 六个卫星 | `R03,R04,GROW,SCHUR,COLLIDE,FULL` 六个独立节点；导航父对象在详情显示。公转不是数学依赖 |
| 螺旋、椭圆、侧视尘盘、环状、相互作用、弥散星云 | 各个命名主题区域的形态；不决定定理证据状态 |
| 未知暗星域 | 算子空间和开放规模比较方向；`SIZE` 仍是可独立打开的真实节点 |
| 探测器与航线 | 阅读方向动画，不是 PPA/Markov 动力模拟。输入合取到 `∧` 后再到输出 |
| 红色断续线和终端叉号 | 原记录 `refutes` / `limits`，没有正向飞行的证明船 |

二进制条件刷新与 Gaussian Gibbs 有独立星系、残差与节点；不得通过空间分组替换其数学对象。完整约束见 [上层语义契约](../COSMOS_SEMANTIC_CONTRACT.md)。

## 技术与稳定增长

1. **权威数据**：`../../research/graph.json`。页面内嵌逐字义一致的 JSON，运行模型只使用副本。
2. **持久语义锚点**：`data/anchors.json` 按 ID 保存。追加/乱序/删除恢复不洗牌旧锚点；删除节点的旧锚点保留以便恢复。
3. **实际动态排布**：D3 `forceSimulation`、`forceManyBody`、`forceCollide`、`forceLink` 与 `forceX/Y` 共同运行。它不是一张静态图换素材。新增图的节点从已有渲染位置续接，只局部松弛；渲染位置允许小范围移动，不能称为“旧物件像素永不移动”。
4. **公转层**：太阳固定，八个行星有不同周期；卫星在父节点周围真实运动。轨道运动不改节点 ID。短相位绕行用于避免卫星投影重叠，故是科幻导航运动而非严格天体力学模拟。
5. **航道层**：每条超边拥有唯一合取枢纽，各输入分别接入，输出从枢纽接出。端点每帧追踪当前天体位置，箭头/终止符位于天体外缘。力学内部的 links 仅用于排布，不在页面画成输入间的串联推理。
6. **层级显示**：总览显示主题形态，近看显示真实节点及轨道；文本随缩放适配。全部节点始终可搜索、通过键盘/目录进入。

```sh
python visualization/cosmos/build.py
node visualization/cosmos/tests/test_engine.js
```

运行中追加真实图数据：`window.cosmos.updateGraph(newGraph)`；输入须有唯一 ID 和完整超边端点。`window.cosmos.anchors`、`.positions`、`.state` 供调试/持久化读取。方法 `.selectNode(id)`、`.selectEdge(id)`、`.focus(id)`、`.pause()`、`.resume()`、`.reset()` 不修改研究图文件。真实数据持久写入仍通过规范流程编辑 `graph.json` 后重建。

## 验证范围

12 项结构/数值测试通过：精确数据与合取、真实力排斥、模型分离、差异周期、静止时钟、600 秒每 0.25 秒的太阳系实体碰撞采样、非轨道节点碰撞、追加 125 个对象与关系后的锚点保留、删除恢复和离线内嵌等。当前压力例旧渲染位置最大松弛约 **61.9 个世界坐标单位**；这是该测试实例的实测值，不是任意输入的理论上界。

[太阳系 t=0](qa/solar-0.png)、[t=12s](qa/solar-12.png)、[全宇宙](qa/overview.png) 来自与页面相同的引擎/天体 SVG 的静态渲染。它们**不是浏览器截图**，没有验证 CSS 侧栏、字体回退、触控和真实帧率。已做代码与数值检查，**真实浏览器交互/视觉验收尚未完成**：当前环境的远程浏览器预览被自动审批拒绝，未绕过。

# 云岫 · 修仙数学山海图

这是 `research/graph.json` 的独立可视化项目。先看 [万象图鉴](gallery.html)，逐个评判 32 种物件；再进入 [可漫游山海图](index.html)。两页均可离线打开，已内嵌数据与素材，无 CDN、字体下载或运行时依赖。规范正文链接需配合完整仓库使用。

## 这一阶段交付

- **32 个独立 SVG 物件**：书院建筑 8 种、法器灵物 8 种、山海秘境 8 种、禁制断路 8 种。不是仅更换颜色；书阁可见藏书、山门保留通行空洞、断桥有中断桥面、封印有符纸，均有独立轮廓。
- **独立美术图鉴**：每件物品同时展示放大图和 82 px 地图尺寸；可点开透明背景 SVG 原件。统一 144×144 画布、(72,122) 地面落点、青绿金石色板。当前是清晰的二维矢量仙侠美术，不称为已完成的逐像素精灵美术。
- **真实图谱**：节点与超边均来自权威 `research/graph.json`；实际数量以重建后的页面和权威图为准；点击节点或 ∧ 看完整 inputs、output、relation、scope、status。搜索、主题过滤、悬停、拖拽、缩放、小地图、WASD 漫游、键盘目录与深链接保留。
- **持久世界**：`data/world.json` 固定节点坐标和变体，固定超边阵眼。新增内容优先填入同主题空位，满后添加外山。删除条目保留空地；恢复相同 ID 回到原地。数据数组重排不会重排世界。
- **多变外观与严格状态分离**：无显式状态就显示“未单列”，不按建筑高低、地图面积或物件发光推定已证/高价值。既有状态改变时，徽记和导航角色会刷新，位置不变。

默认仅显示选择相关的路线；“路线”按钮打开全图关系。这样鸟瞰先看山海，选择后看推理。∧ 是合取阵眼；青色双向线、朱红禁线、金色边界和紫色云路保留不同关系身份。轮廓、颜色、路程和空间邻近都不代替数学前提。

## 世界怎么长

1. 读真实图 ID 与关系，为每个节点保存独立的导航角色和**原始证据状态**。
2. 保留所有旧坐标、所属物理岛屿及旧阵眼；语义字段重新对照当前图刷新。
3. 新 ID 在主题的固定格点中寻找空位；已知依赖邻居只用于导航距离偏好，不能制造新数学连线。
4. 一块主题岛满后，开启预留的南方外山。旧山海不挪动，画布边界扩展。初版已有实例主题外山。
5. 物件变体由世界 seed、稳定 ID、资产版本确定；地貌和树木按坐标确定。新增节点只局部腾出树木，不洗牌所有风景。
6. 超边阵眼从输出附近的保留环带找空位，避开节点核心与既有阵眼；极端密集时全部超边仍由目录、搜索、详情可达。
7. 提交新的 `world.json`。重新生成完全相同图不产生布局变化。

这是固定格点和分区约束下的增量生成，**不是**无限世界、实时地形串流或商业游戏引擎。未实现内容见交接。故意修改旧位置属于世界版本迁移，应独立记录，不用“重新随机生成”覆盖旧地图。

## 验证边界

自动回归验证图快照相同、所有对象和超边存在、重排与重建不变、125 个新对象和关系加入后旧定位不变、删除恢复、语义状态更新、素材结构与最小间距。美术原件可单独栅格化检视。合成 DOM 执行也覆盖了全部节点/超边详情、搜索、缩放与区域定位，但不是浏览器验证。

当前会话的真实浏览器预览被访问策略阻挡，因此整页 CSS、触控和真实浏览器字体布局尚未完成目测。不得把静态素材检视或脚本测试写成已经通过浏览器视觉验收。打开图鉴和地图后，优先记录用户对每件造型的意见，再推进下一轮材质和动画。

## 美术锚点与预览

`src/world.py` 的 `ART_OVERRIDES` 为少量精确 ID 指定造型：SIZE 是未定航线的海，STOCH-LIMIT-V0 是原错误版本被阻断的桥，D01–D03 用书阁/山门/亭分别承接入口，R02 为研修山亭。它们只改外观，不改变 role、evidence 或数学数据。其余变体继续稳定选择。

[静态物件总览](assets/preview.png) 由同一组 SVG 栅格化得到，没有另画一套图。可安装 Node `sharp` 后运行 `node visualization/xianxia/src/render_preview.js` 重新生成；当前运行环境也可从 `CODEX_PRIMARY_RUNTIME_NODE_MODULES` 加载该包。Sharp 只用于这个 PNG 预览，网页本身没有该依赖。

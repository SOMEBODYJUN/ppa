# PPA 长期研究项目：DD1–DD2 及其算法推广的最终数学验收协议

## 一、总目标：验收一套数学理论，而不是验收一份研究报告

本轮假定 DD2 一般函数补偿、非线性有限长度、约化前向表示、shadow recovery、残差理论、自适应松弛、误差界传递以及算法应用均属于研究任务。

你需要完成这些任务，并对最终成果进行严格的数学验收。

但不能将“写出了某个公式”“给出了一个证明草稿”“数值实验通过”“可以引用某篇论文”直接等同于完成研究。

**最终要回答的核心问题是：**

> 我们是否真正建立了一套关于非线性次单调性、非线性正则性、PPA 距离下降、有限长度、预条件算法和原空间恢复的统一数学理论？这套理论中哪些部分是严格新结果，哪些部分已经存在，哪些仍有无法消除的数学障碍？

本轮研究目标不设定人为的结论上限。

可以发现比现有 DD1、DD2 更强的定理、更弱的假设、更好的表示方式，甚至可以推翻当前候选理论中的错误部分。

但是不得改变原始数学命题后，仍然沿用旧命题的身份。

# 第一部分：核心数学理论的验收

## 1. DD2 的数学身份是否已经完全固定？

必须回答：

1. DD2 究竟削弱了 A、B 中的哪一个？是否同时推广了二者？
2. DD2 的一般下降函数与旧 A 的固定收缩因子之间是什么关系？
3. DD2 的步长控制究竟是一般函数包络，还是直接的有限长度耗散不等式？
4. DD2 对算子 `F`、目标集 `S`、近端参数 `\lambda`、投影点、合法近端对有哪些精确要求？
5. 是所有合法近端输出满足条件，还是只要求存在某个选择？
6. 零点锚定条件对所有最近点成立，还是仅对某个最近点成立？
7. DD2 是否要求预解式单值、局部存在、满射性、连续性、闭图或其他结构？
8. 对有限维欧氏空间与一般 Hilbert 空间，哪些结论仍然有效？
9. 原来的 `B_\omega`、新的 `B_\Phi`、输出相对步长条件是否被严格区分？
10. DD2 所有函数的定义域、连续性、单调性、非负性、可逆性要求是否真正必要？

**验收要求：**

最终必须给出一份不可含糊的 Exact Theorem Statement。

量词、定义域、局部工作区域、零点集、投影选择、参数依赖及结论必须全部明确。

任何假设变化都应作为新的 theorem version 记录。

## 2. 一般函数补偿关系是否真正得到完整刻画？

研究核心：

```math
\langle x-y,y-p_1\rangle \ge\Phi(d(x,S)),
```

```math
d(y,S)\le\psi(d(0,F(y))).
```

必须回答：

1. 对一般 `\Phi,\psi`，是否存在显式、可计算的一步下降上包络？
2. 该上包络究竟是最优的，还是只是一条方便的充分上界？
3. 是否真正使用了全部四点几何限制？
4. 是否存在没有被当前平方能量推导捕获的额外几何信息？
5. 如果允许 `\Phi` 变号、不连续、非单调或局部振荡，结论如何变化？
6. 如果 `\psi` 不能严格求逆，能否使用广义反函数而保持定理成立？
7. 是否能构造显式双向补偿关系：给定 `\Phi` 求允许的 `\psi`，给定 `\psi` 求允许的 `\Phi`？
8. 哪些条件是充分的？哪些是必要的？哪些是充要的？
9. 哪些边界是逐尺度尖锐的？哪些只有统一充分性？
10. 是否存在比目前 DD2 更强、更简洁的共同关系式？

重点独立审查当前候选公式：

```math
D(t)=[-\Phi(t)]_+,
```

```math
B_\Phi(t)= \frac{t+\sqrt{t^2+4D(t)}}2,
```

以及

```math
\varphi_{\Phi,\psi}(t)= \max_{0\le s\le B_\Phi(t)} \min\left\{ \psi(s/\lambda), \sqrt{t^2+2D(t)-s^2} \right\}.
```

必须确认：

- 公式在所声明的定义域上良定；
- 最大值是否确实达到；
- 该表达式是否给出所有合法近端步的统一上界；
- 它是否为相应几何模型的精确最优值；
- 何时有 `\varphi(t)<t`；
- 何时有 `\varphi^{\circ n}(t)\to0`；
- 何时可以构造非减的下降模函数；
- 反向刻画是否成立；
- 相关临界界是否存在可实现的取等构型。

**不允许只重新排列公式，就宣称完成了最优刻画。**

## 3. DD2 是否严格恢复 DD1 的全部分段机制？

这是必须通过的核心验收。

取

```math
\Phi(t)=-\sigma t^2, \qquad \psi(s)=\ell s, \qquad L=\frac{\ell}{\lambda}.
```

必须严格恢复：

```math
T(L)= \begin{cases} \dfrac{1-L}{L^2},&0<L\le1/2,\\[6pt] \dfrac1{2L^2},&L\ge1/2. \end{cases}
```

不仅检查最终公式一致，还必须检查：

1. DD2 的假设能否容纳 DD1 的完整假设？
2. DD2 的结论是否恢复 DD1 的统一收缩及步长估计？
3. 两段临界边界分别由什么几何机制决定？
4. 两类极值构型是否满足全部最近点约束？
5. 在 `L=1/2` 处是否连续，是否存在结构切换？
6. 严格不等号能否放宽？
7. 分段曲线是否对整个四点几何类尖锐？
8. 是否对完整局部 PPA 算子类尖锐？
9. 是否可以构造达到临界边界的实际算子？
10. 是否存在更强的第三分支或目前未发现的约束？

**验收标准：**

必须同时给出正面证明与边界攻击。

纯四点几何尖锐性和算子层面尖锐性必须分别证明，不得互相替代。

# 第二部分：有限长度与收敛机制的验收

3. 何时能够保证点列本身收敛？
4. 何时能够保证有限长度？
5. 何时只有渐近正则性？
6. 何时能够保证残差趋于零？
7. 何时能确认极限属于指定的 `S`，而不只是 `\operatorname{zer}F`？
8. 是否能够允许没有传统线性收敛率的迭代？
9. 是否能够覆盖有收敛率但没有固定收缩系数的情况？
10. 是否能够得到更一般的、无法由简单幂次描述的收敛过程？

必须严格区分：

```math
d(x^{k+1},S)<d(x^k,S),
```

```math
d(x^k,S)\to0,
```

```math
x^k\to x^\infty,
```

以及

```math
\sum_k\|x^{k+1}-x^k\|<\infty.
```

这些是不同命题。

**不得把其中任何一个自动升级成另一个。**

## 5. 有限长度是否有真正的一般函数型判据？

```math

```

必须回答：

1. 什么条件保证这样的 `\Theta` 存在？
2. 能否直接由 `\Phi,\psi` 构造？
3. 所需条件是否可以写成可计算的积分判据？
4. 积分判据是充分、必要，还是某个函数类中的充要条件？
5. `\Theta` 是否需要单调、连续、凹或可微？
6. 是否允许非幂次、对数修正、振荡模函数？
7. 是否可以弱化当前的可积性假设？
8. 是否存在具有有限长度、却不满足当前候选势函数判据的例子？
9. 是否可以建立最佳或近最佳的尾部长度包络？
10. 有没有不使用这类势函数、却能得到更强结论的证明机制？

必须特别重新审查此前提出的 F1–F3 条件以及相关望远镜估计。

**这些先前的推导不能因为已经写进 DD2 草稿，就免除独立数学审查。**

9. 是否能够构造达到速率上界的算子？
10. 是否能够从一般函数判据直接恢复幂次分类，而不是分别重复证明？

```math

```


不得仅以有限次实验支持临界指数。

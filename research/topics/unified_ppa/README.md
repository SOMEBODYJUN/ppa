# 次单调 PPA 的联合证书与边界

共同目标是在同一个原算子、完整近端、真残差和全部输出政策下，结合 RL 一般模、逆/矩阵耗散、零锚几何与物理长度。已证的是充分认证框架与几个原始结构子类；完备大一统、自动证书生成和全球先行性未完成。

- [联合原图与有限状态](../../canonical/unified_ppa_joint_certificates.md)：同一步/跨步关联、有限状态长度势、真残差评价窗、全部政策与物理留域；一维两支及两步nilpotent给严格信息边界。
- [原算子演算](../../canonical/unified_ppa_raw_calculus.md)：仿射物理零集的 LMI、signed remainder、和/逆/拉回、矩阵同参数完成、全域非线性紧凸扰动。
- [同预算覆盖](../../canonical/unified_ppa_coverage.md)：一般预算极大缺口反例、Hilbert混合核完成、正逆全部纤维与degree；完成不自动保指定零集或EB。
- [曲零簇](../../canonical/unified_ppa_curved_geometry.md)：reach曲率与半阶临界、完整闭管coverage/全根、补偿机制；全空间原图远根尚另核。
- [非精确/变化核](../../canonical/unified_ppa_inexact_interfaces.md)：可执行真实图停止、方向预算、奇异物理提升、movingprojection锐门、uniformSPD精确发散。

[本轮报告](../../../发表成果整理/本轮重构/次单调PPA统一框架_证明与边界_2026-10-14.md)分真值、价值、机制与优先性；[6pro交接](../../../发表成果整理/本轮重构/6pro_统一次单调PPA_研究交接.md)只保有限原生状态生成、自然曲零簇全图屏障、带跨步结构的非线性奇异核三道精确目标。

旧 [C208–C214](../../canonical/generalized_ppa_modulus.md) 与 [C249/C250](../../canonical/physical_rleb_gppa.md) 的对象范围保留；本主题不以有限维/完整zero版本冒称全部包含。复算与证据范围见[代码](../../code/unified_ppa/README.md)和[局部接收](../../audit/UNIFIED_PPA_REVIEW_2026_10_14.md)。

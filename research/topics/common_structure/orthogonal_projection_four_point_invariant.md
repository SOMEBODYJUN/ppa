# 同一目标直线上的四点投影不变量

<a id="orthogonal-projection-invariant"></a>
## C396 · 四个指定边长的无量纲恒等式

这一页修正 C395 中引入外部参照长度 L 的做法。若题设只给单调性、正则性和平方可和型不等式，四个边长仍有连续自由度，不能推出非平凡等式。要得到真正的不变量，必须把换锚和前后距离差放进一个明确的几何等式。

固定一条仿射目标直线 ell。取 P1,P2 在 ell 上，并令 X,Y 在 ell 的同一侧，XP1 与 YP2 都垂直 ell。记

    s = XY,  b = YP1,  a = XP1,  t = YP2,  D = P1P2.

最终的不变量不含 D。同侧条件给出有向法向高度 a,t>0。

### 两条接缝等式

切向的换锚量与法向的前后高度差正交，因此

    s^2 = D^2 + (a-t)^2.                                  (1)

从 Y 到 P1 的向量由切向段 P2P1 和法向段 YP2 组成，故

    b^2 = D^2 + t^2.                                       (2)

消去 D^2 得

    a^2 + b^2 - s^2 = 2 a t.                              (3)

于是只用用户指定的四个长度得到无量纲不变量

    I = (XP1^2 + YP1^2 - XY^2) / (2 XP1 YP2) = 1.          (4)

退化时使用多项式形式 (3)，避免除以零。若 X,Y 位于 ell 的相反两侧，法向高度差变为 a+t，相应常数为 -1。题面必须固定同侧，或改用 I^2=1。

### 与单调性和正则性的关系

把 x-y 与 y-p1 的夹角条件写成

    <y-p1, x-y> >= 0,

在上述坐标中等价于

    D^2 <= t(a-t).                                         (5)

因此

    a^2 - t^2 >= s^2 + D^2,                               (6)

正好是平方距离下降同时支付步长平方和换锚平方的 Fejer 型预算。正则性只需再给半径 t=YP2 与步边 s=XY 的大小关系，例如 t <= psi(s)。这些条件筛选允许的构形，但不改变恒等式 (3)。恒等式本身来自同一目标直线上的切向与法向正交分解，因而把 P2-P1 和 XP1-YP2 两个接缝关系同时纳入。

### 为什么原不等式题设不能直接产生不变量

若不固定同一条目标直线和两条正交投影，单调性、正则性及收敛条件都只是单边不等式。它们允许连续改变 a,b,s,t，所以允许构形在四维边长空间中含相对开集。任何在整个允许族上恒定的连续表达式只能是平凡常数。即使把局部构形按尺度缩小并串成平方可和链，也不会消掉这个自由度。

因此 (4) 是一个明确修订题设下的精确不变量，不是从 C395 的一般不等式子类自动推出的结论。若目标集不是仿射直线，或 XP1、YP2 不是同一法向的正交投影，必须另加等式并重新推导，不能继续宣称 (4)。

### 非平凡变形见证

取 a=3,t=1，令 D 在 (0,sqrt(2)) 内，并在 ell 上按上述投影构造 X,Y,P1,P2。则

    s^2 = D^2 + 4,  b^2 = D^2 + 1,  D^2 < t(a-t),

且 t <= s。四边形形状随 D 连续改变，但 (4) 始终等于 1。这排除了“只是固定形状的恒等式”的误解。

状态：candidate。四点投影恒等式已经闭合；它尚未完成原一般多值 PPA 的共同结构恢复，也不把正则性不等式自动提升为等式。

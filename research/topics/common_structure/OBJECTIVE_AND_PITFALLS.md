# PPA 这条研究线的目标与已有教训

<a id="w-objective"></a>
## 主目标：一个共同充分条件 \(W\)

研究同一个普通欧氏近端点法
\[
x^k-x^{k+1}\in\lambda F(x^{k+1}),\qquad \lambda>0,
\]
以及指定的非空闭目标 \(S\subseteq F^{-1}(0)\)。\(W\) 要把三项前提组织成一条能证明收敛的数学机制。

| 前提 | 要保留的信息 | 验收时查什么 |
| --- | --- | --- |
| 单调或次单调结构 | 原图的方向关系、耗散或反射亏损 | 比较的是全部图对、某个图块，还是每步的最近零锚？在 RLEB 这一行须保留原一般非线性反射模 \(\omega\)。 |
| 正则性 | 图值或真残差与到指定目标 \(S\) 的距离之间的关系 | 是零右端次正则、变化右端的正则性，还是经证明能转接的 KL/增长条件？残差在哪个图与窗口内取下确界？ |
| 参数兼容 | 步长、违背常数、误差界常数或模、指数及有效尺度之间的关系 | 两种结构合用后，哪一项能压过亏损或控制位移？可行参数范围怎样随组合改变？ |

设第 \(i\) 类单调结构的数据为 \(\theta_i\)，第 \(j\) 类正则性的数据为 \(\eta_j\)。目标是逐行兑现
\[
\mathsf{Mon}_i(F;\theta_i)\ \land\
\mathsf{Reg}_j(F,S;\eta_j)\ \land\
\mathsf{Comp}_{ij}(\lambda,\theta_i,\eta_j;\text{工作窗})
\quad\Longrightarrow\quad W
\quad\Longrightarrow\quad \text{存在收敛的原 PPA 轨道}.
\]
这里的“任意”指对每类明确纳入的组合寻找并证明其**自己的可行参数窗**。每个声称覆盖的组合须给可核验的参数关系和一般论证。同一 \(W\) 可以接受不同形式的参数预算。若某组合在现用证书下无参数可行，记下失效原因。能否换一条证书或真正不存在可行参数，是另外的问题。

\(W\) 就是任务书中的 \(M\)。还要找出条件 \(A,B\)，证明在 \(A\) 下 \(M\) 等价于单调或次单调，在 \(B\) 下同一个 \(M\) 等价于正则性。这两个等价和上面的收敛推导都须证明。[现行完成标准](GPT_PRO_PROMPT.md#pro-hard-gates)

<a id="w-quantifiers"></a>
## 最低收敛结论与选根

对定理认证的初值 \(x^0\)，证明**至少存在一条从该初值出发的无限原 PPA 轨道**，且 \(x^k\to x^\infty\in S\)。若写成局部初值定理，可约定存在非平凡初值域 \(U_0\)，对每个 \(x^0\in U_0\) 至少有一条这样的轨道。此量词是本次整理采用的工作写法，也允许对单个给定初值精确列出认证条件。

原图可以有其他合法根。证明可认证一个非空原根子关系，给出选根策略，或直接证明一条相容的无限轨道。沿所选路线上仍须证明根存在、能够反复选择，以及所用估计的共同留域。逐点存在一个当前下降根，还须说明它能接进下一步。存在性本身不提供连续或可计算的选根器。如要主张这些更强结论，另给证明。

[C322 的两粒子例](../../canonical/ppa_native_alignment_and_transverse_test.md#native-sharp)清楚解释了降量词的意义。从同一个初值选小根可以收敛，首步选大根可以发散。这个例子排除的是该初值的全选保证，保留了存在性。全根收敛、固定线性因子、有限长度以及收敛速率可作为附加成果。

<a id="w-parameters"></a>
## 参数为什么是理论的一部分

最简单的例子固定 \(F(y)=-by\)（\(b>0\)）、\(S=\{0\}\)。弱单调常数 \(b\) 和线性真残差界 \(d(y,S)=r_F(y)/b\) 都固定。原近端在 \(\lambda b\ne1\) 时是 \(y=x/(1-\lambda b)\)。于是同一个 \(F\) 有四种参数情形。

| \(\lambda b\) | 非零初值的原 PPA |
| --- | --- |
| \(0<\lambda b<2,\ \lambda b\ne1\) | 唯一轨道扩张 |
| \(\lambda b=1\) | 第一步没有根 |
| \(\lambda b=2\) | 唯一轨道在两个点间交替 |
| \(\lambda b>2\) | 唯一轨道收敛到零 |

平方恒等式也说明两个性质怎样在同一近端弦相遇。对 \(p\in S\) 和 \(x=y+\lambda v\)，
\[
 \|x-p\|^2-\|y-p\|^2
 =2\lambda\langle y-p,v\rangle+\lambda^2\|v\|^2.
\]
单调结构可以控制第一项的符号或亏损，误差界可以把距离尺度和第二项的图值联系起来，步长改变两项的相对大小。最近锚、切向输运或非二次条件会要求不同的证书。这个恒等式只提供一种图几何路线。

原 RLEB 已给出了三项如何配合的基准。写 \(H(t)=(t+\omega(t))/2\)，在同窗用
\[
\psi(H(t)/\lambda)\le\kappa t,\qquad 0<\kappa<1.
\]
若 \(0<\gamma<1\)、\(\omega(t)=Lt^\gamma\)、\(\psi(s)=Cs^q\)，则
\[
\frac{\psi(H(t)/\lambda)}{t}\sim C\Big(\frac L{2\lambda}\Big)^q t^{\gamma q-1}.
\]
所以在给定这两个模的前提下，\(\gamma q>1\) 可用缩窗压住比例，\(\gamma q<1\) 时缩窗没有帮助，\(\gamma q=1\) 时由系数决定该门能否给一个固定 \(\kappa<1\)。更换步长须重新核原 RL 模、根覆盖和评价域。[C09 原参数门和留域](../../canonical/general_modulus_dynamics.md#gm-data)

<a id="w-pitfalls"></a>
## 前面几次踩过的大坑

| 坑 | 现在怎样判定 |
| --- | --- |
| **把存在收敛支改成所有根都要收敛** | 主结论固定从给定初值存在可延拓的收敛支。坏根本身只排除全选保证。反驳存在性要在该初值排除所有无限收敛选择，或证根无法延续。 |
| **换了单调结构却沿用原题身份** | 全对 RL、最近输入零锚 RL、Luke–Tam 的二次合同和常数弱单调各有自己的尺度。C329 留在二次子类。若声明覆盖原 RLEB，要在一般论证中保留原 \(\omega\)、评价窗和原根身份。 |
| **把裸正则性和整窗相容混为一谈** | GMSR 包含线性次正则这一特例。比较弱化应写出要比较的原整套条件及参数窗。把某个误差界常数写小或把窗口缩空，不会产生覆盖。见 [F105](../../../FAILED_ROUTES.md#f105)。 |
| **更换了残差或 \(B\) 的含义** | \(r_F(y)\) 对完整纤维取下确界，而选中步只给 \(r_F(y)\le\|x-y\|/\lambda\)。真残差的下界或逆向蕴含需要整纤维理由。原 \(B\) 是输入距离的 \(H(d(x,S))\)，输出相对线性步界是另一命题，C310 给反例。见 [F106](../../../FAILED_ROUTES.md#f106) 与 [C310](../../../CLAIMS.md#c310)。 |
| **把中间估计当作研究的最终要求** | 距离趋零、点列收敛、平方步长可和和有限长度分别主张。Dini 的锐必要性针对给定模的类级统一保证，不能挪给一条具体轨道。两步相消属于点收敛的另一条证明路线。见 [C318](../../../CLAIMS.md#c318)、[C319](../../../CLAIMS.md#c319) 与 [F108](../../../FAILED_ROUTES.md#f108)。 |
| **把 KL、次正则、Lyapunov 当作可直接互换的词** | KL 到次正则需要子水平集到目标集的识别和相应结构。KL 有限长度还要下降和相对误差，原 RL 单独没有自动 Lyapunov 桥。Zhu 等人的距离端幂和本库残差端幂互为倒数。见 [文献定位](../../LITERATURE.md#lit-monotonicity-regularity-bridge) 与 [C314](../../../CLAIMS.md#c314)。 |
| **把共同表示或局部扩张当成统一定理** | C320 严格推广原标量兼容，但仍保留原 RL 与真误差界。C324/C329 的截面可以共享变分表示，动力学还需保留原弦方向。C334 的标量宽度会损失正则指数，C336 的精确向量结果有明确的同模 Hölder 延拓范围。主张 \(W\) 时要给三项到共同证书的推导，再证明原轨道可无限拼接。见 [F110–F111](../../../FAILED_ROUTES.md#f110) 与 [原非线性图桥](nonlinear_rl_bridge.md)。 |

## 现有资产怎样用于新目标

- **参考定理。** C09 的一般模 RLEB 保留真实残差、兼容和留域证明，提供一条成熟的 \(W\) 转接测试。C329 的二次参数门和单调 PPA 可作其他测试行。要说覆盖某个旧结果，使用该结果的原条件、参数及窗口去验证 \(W\)。
- **正面机制。** C319 提供跨步位移相消。C322 从原场的速度耗散与位置输运直接给原 PPA 收敛，另有同初值分根例。它们可检验 \(W\) 能否接受不同正向机制，而无需统一要求一个固定线性 \(A\) 或绝对步长可和。
- **义务改变。** C337 的小图值加入仍约束任何声称控制**完整真残差**的原图推导。C339 的长支仍反驳全输出推论，但存在性定理可以避开坏支。现在检验这条好支能否由三项数据构造、继续，并到达指定 \(S\)。若只调取选中图值，明确它在证明中是动力学证书，保留原正则性的完整残差身份。
- **当前判定。** [C341–C342](compensated_anchor_convergence.md) 完成两个基准的同一收敛证书。共同结构仍开放：原 RLEB 先取得旧收缩预算，闭图完整零集上的 C341 正则项可以由紧性自动满足。[第 004 轮机制层复核](../../audit/COMMON_STRUCTURE_M_ACCEPTANCE_2026-11-18.md#m-mechanism-review) · [现行任务与验收](GPT_PRO_PROMPT.md)

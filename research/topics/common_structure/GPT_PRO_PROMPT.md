# GPT Pro 研究任务书：统一原 PPA 的单调结构、正则性与参数兼容

先读[目标与已有教训](OBJECTIVE_AND_PITFALLS.md)，再从仓库的 [README](../../../README.md)、[RESEARCH_STATE](../../../RESEARCH_STATE.md)、[CLAIMS](../../../CLAIMS.md)、[FAILED_ROUTES](../../../FAILED_ROUTES.md) 和 [研究协议](../../../RESEARCH_PROTOCOL.md) 恢复研究状态。文献与现成证明由[主题导读](README.md)索引。除非一个承重引文缺少原文，主要时间用于推导和反例。

## 1. 要证明的命题

对原欧氏 PPA \(x^k-x^{k+1}\in\lambda F(x^{k+1})\) 及非空闭目标 \(S\subseteq F^{-1}(0)\)，找一个具有独立数学含义的**共同充分条件 \(W\)**。对纳入的任一指定单调或次单调结构、任一指定正则性结构和它们自己的可行参数条件，证明
\[
 \mathsf{Mon}_i(F;\theta_i)\land\mathsf{Reg}_j(F,S;\eta_j)
 \land\mathsf{Comp}_{ij}(\lambda,\theta_i,\eta_j;\text{工作窗})
 \ \Longrightarrow\ W
 \ \Longrightarrow\
 \text{从认证初值存在一条收敛到 }S\text{ 的无限原 PPA 轨道}.
\]
不同组合可以有不同参数窗。若声称覆盖旧定理的存在性结论，须用旧定理原有参数窗、根和局部化条件导出 \(W\)，并标出任何缩小的范围。参数门须在得出收敛之前能检查。空窗或把结果本身写进参数门不能给覆盖。

对给定认证初值，证明能选出并无限拼接一条原图轨道。可用所选原根子关系或显式选根规则，证每次有根、估计在前缀上可反复调用、极限属于指定 \(S\)。其他根可以发散。全根收敛、固定线性 \(A\)、绝对步长可和、Dini 或统一速率可作为额外成果。若只证明距离趋零，另补原空间点收敛。若改用不同核或更新，单独证明与原 PPA 的对应。

## 2. 怎样判断 \(W\) 有真正内容

解释 \(W\) 的哪个数学对象同时用到了图方向、真实误差信息与参数。给出一个共享的定量转接或收敛证明，标出不同输入组合各自验证哪一段。可从同一母对象分别读出单调或次单调与正则两支，也可经同一参数敏感的图或能量证书把两者接到收敛。两侧等价是有价值的加强。逐行析取旧定理、直接改名 \(A+B\)、或先要求原轨道收敛，再定义形式上的 \(W\)，均不形成这条桥。

保留完整真残差 \(r_F(y)=\inf_{v\in F(y)}\|v\|\) 的身份。若在选根证明里使用 \(v=(x-y)/\lambda\)，只有 \(r_F(y)\le\|v\|\) 自动成立。使用其他残差时把转接写出来。区分全对 RL、最近输入零锚 RL、Luke–Tam 的二次条件与常数弱单调。声称覆盖原 RLEB 时，用同一原非线性 \(\omega\) 通过 C242 与原参数门，并保留旧结论所用窗口。C329 可作为二次参照。原输入步界是 \(\|x-y\|\le H(d(x,S))\)，\(H=(\mathrm{id}+\omega)/2\)。

## 3. 首轮比较与验收

1. **先做两条参数逻辑不同的路线。** 一条用 [C09 原一般模](../../canonical/general_modulus_dynamics.md#gm-data) 的 RL、真残差与整窗兼容。另一条从二次条件、单调 PPA，或具有独立数学来源的其他类出发。固定每行的数学对象、参数和目标域，尝试用同一个 \(W\) 证明存在原轨道收敛。要给明确的参数范围和非空见证。
2. **用同初值分根测试。** [C322](../../canonical/ppa_native_alignment_and_transverse_test.md#native-sharp) 有小根支收敛和大根支发散。给出好支可选择、可续走及其耗散的证明。同一个例子的坏根只能攻击全选保证；要反驳存在性，必须排尽所有合法收敛策略。
3. **把现有障碍用在对应量词上。** [C333–C339](nonlinear_rl_bridge.md) 限定二次位移见证、原非线性模、完整真残差及长支。C337 约束完整真残差的推导。C339 的长支反例可用来检查为什么要选根。其他可复用路线有 [C319 跨步相消](../../canonical/ppa_two_step_and_directional_residual.md#td-cancellation)、[C322 原生耗散](../../canonical/ppa_native_alignment_and_transverse_test.md#native-alignment)、[C325 支撑曲率](energy.md#support-sharp)。[C328–C330 的临界曲率](critical_graph.md) 可作为专项检验。
4. **保存精确结果。** 交付一张同一对象的条件、参数、选根量词和结论比较表。对每个新覆盖给确切证明。声称严格弱化时，给同窗反例或严格见证。若共同 \(W\) 未闭，留下最窄成立范围和能区分下一步的具体义务。把数学成立性、解释能力及文献新颖性分别判断。

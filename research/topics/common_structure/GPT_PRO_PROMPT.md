# GPT Pro 研究任务｜找出单调性与正则性的共同结构

<a id="pro-exact-goal"></a>

你的任务是找到一个有可能是新的数学结构 \(M\)，让人看清**单调或次单调给出的方向信息，与正则性给出的误差信息，为什么会在同一个原 PPA 问题里发生联系**。交付的核心是 \(M\) 的定义和揭示这层联系的定理。由 [仓库研究地图](../../../README.md) 和 [当前研究状态](../../../RESEARCH_STATE.md) 进入，按需要调用已有定义、证明和文献。

仍研究原欧氏近端步 \(x^k-x^{k+1}\in\lambda F(x^{k+1})\)，目标是指定的非空闭零点集 \(S\subseteq F^{-1}(0)\)。想找的是一个能跨单调或次单调类别、跨正则性类别复用的结构。每种有精确定义的组合可以有自己的参数条件。要求是由**单调或次单调、正则性、该组合的参数兼容**推出同一个 \(M\)，再从每个认证初值推出至少一条可无限延拓、点收敛到 \(S\) 的原轨道。认证范围须包含非解初值。原 [RLEB](../../../发表成果整理/RLEB/sections/theorem_spine.tex) 的最近输入零锚和一般非线性反射模须进入真正的论证。用真残差时，始终在原算子的完整输出纤维上取下确界。

<a id="pro-hard-gates"></a>
## 唯一的完成标准

1. **说出并证明那条联系。** 给出 \(M\) 的精确定义和一条可单独陈述的结构命题。删去最终的 PPA 收敛结论后，读者仍能准确说出，关于这两类性质的关系，现在多知道了什么。原近端关系和步长可以留在命题里。导师提出的路线是从同一个 \(M\) 出发，各自加入一种有独立数学含义的条件，分别恢复单调性与正则性，并解释两种恢复为何共用 \(M\)。也可以证明一条实质转接，或在一般类别上从两侧原始数据导出共同的参数相容律。附加条件不能预先假定待恢复的性质。
2. **让这条联系在原 PPA 中承担推导。** 指出正则尺度如何与方向结构在参数条件下相互制约，并用这条联系证明声明范围内的收敛充分性。写明所覆盖的类别、参数和量词，原一般非线性 RL 不能被线性模或二次条件代替。若两侧各自用旧证明先解决了相容性和承重的下降问题，最后才共用一个收敛引理，只算接入同一个证书。两条既有定理能接入、覆盖变宽或结论更强，都不能替代这条结构推导。
3. **新意落在结构上。** 对照最接近的已有对象或定理，准确指出新的是 \(M\) 的哪项结构，或它揭示的哪条关系，以及为何不能直接从既有结论换记号或拼接得到。用已有材料支撑原创可能性，必要时只核最贴近的出处。公开首创可保留未定。

<a id="pro-loop"></a>
<a id="pro-stop"></a>
## 执行与交付

直接研究 \(M\)。自己选方法，先攻能决定结构是否成立的命题；一条路线卡住就换表示或换想法。只交付 \(M\) 的定义、结构命题及其证明、原 PPA 推论和最接近的先行关系。不布置构造例子、数值验证、逐例核查、覆盖数量、锐边界、新参数窗口或新选根策略。

只有三项标准都达到，才宣布找到 \(M\)。阶段性定理和真实障碍按仓库协议保存后继续；若会话资源用尽，只报最有价值的已得关系和首个未解决的关键命题，状态写未完成。

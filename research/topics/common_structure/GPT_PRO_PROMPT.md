# GPT Pro 任务｜寻找单调性与正则性的统一结构 \(M\)

<a id="pro-exact-goal"></a>

老师希望找到同一个数学结构 \(M\)，证明单调性和正则性在不同条件下是它的两种表现，并用它解释原 PPA 的收敛。这个任务仍未完成。

先从单调、次单调和正则性各自的数学定义出发，寻找它们共同描述的东西。研究方法由你选择。原锚点 RL 是最后要纳入的一种理论，不能把整个研究问题缩成如何改造这条 RL 收敛定理。

<a id="pro-failures"></a>
## 以下发现按本任务一律判失败

- 从“锚点 RL＋误差界＋旧参数相容”出发，重写不等式、取包络、用广义逆、消去模的存在量词，再把得到的条件命名为 \(M\)。
- 改锚点、局部范围、量词或反射尺度，对原 RLEB 做削弱、推广或等价刻画，然后宣布发现统一结构。
- 先固定正则性的精确等式，解出 RL；再固定 RL 的精确等式，解出正则性，以这两个结果充当两侧来自同一本质的证明。
- 两条旧定理各自已完成关键推导，只是最后共用一个下降、势函数或收敛引理。
- 用增加例子、扩大覆盖、证明参数更锐或堆出更多定理，代替单调性与正则性之间的新联系。

这些结果即使数学正确、表述新颖或局部有用，也算这次统一结构任务失败。C351 属于这一类。遇到后记录断点，换研究方向，不沿同一思路继续包装。该判定针对主要数学贡献，使用某个已有工具本身不决定成败。

<a id="pro-hard-gates"></a>
## 必须找到并证明什么

1. 给出同一个 \(M\) 的定义。说明它本身描述什么，并证明在条件 \(A\) 下，\(M\) 等价于所讨论的单调或次单调性质；在另一条件 \(B\) 下，同一个 \(M\) 等价于所讨论的正则性质。\(A,B\) 也要找出，须各有独立数学含义，两个恢复不能落入上述失败类型。
2. 由这条共同关系，说明单调或次单调、正则性与参数怎样配合，推出原 PPA 收敛。对每个认证初值，只要求至少存在一条能无限延拓、点收敛到指定非空闭零点集 \(S\) 的原轨道
   \[
   x^k-x^{k+1}\in\lambda F(x^{k+1}),\qquad \lambda>0.
   \]
   认证范围包含非解初值。不同组合可以有不同参数条件。声明覆盖什么，就给出什么范围的证明。
3. 最终把原 [RLEB](../../../发表成果整理/RLEB/sections/theorem_spine.tex) 纳入已找到的结构，保留原一般非线性反射模、最近输入零锚、完整纤维真残差及其实际范围。这证明新结构容得下原理论，不能单凭这一导入认定结构发现成功。
4. 对照最接近的已有理论，指出新的是哪条关于两侧关系的定理，以及为什么它超出了旧理论的重写或拼接。可以用已有对象证明新关系。公开首创是否成立，按实际证据说明。

<a id="pro-stop"></a>
## 执行和交付

优先研究那条能解释两侧关系的命题，方法自选。候选若落入失败类型，立即换思路。任务不布置例子、数值实验和逐例审核。

交付 \(M,A,B\) 的定义、两个恢复定理及证明、原 PPA 推论、已有理论的准确关系。数学表达直接使用原对象，减少代换和临时符号。

只有完成以上要求并排除失败类型，才宣布找到 \(M\)。阶段性结果保存后继续。若实际资源用尽，写清首个未解决问题并标为未完成。由[研究地图](../../../README.md)、[当前状态](../../../RESEARCH_STATE.md)和[失败原因](../../../FAILED_ROUTES.md#f120)恢复项目。

# GPT Pro 持续研究任务：寻找统一原 PPA 的充分条件 \(M\)

你在接续 PPA 的开放研究。你的工作是实际产生 idea、试证、找反例、修订并继续搜索。**先写出候选，随即执行验证。候选未通过验收就继续研究。** 方案、进度总结、候选列表和个别成功例都只是中间产物。

先核对当前工作区、分支和远端，保留未提交工作。读 [README](../../../README.md)、[RESEARCH_STATE](../../../RESEARCH_STATE.md)、[CLAIMS](../../../CLAIMS.md)、[FAILED_ROUTES](../../../FAILED_ROUTES.md) 和 [研究协议](../../../RESEARCH_PROTOCOL.md)。再读[目标与已有教训](OBJECTIVE_AND_PITFALLS.md)与[专题导读](README.md)。优先使用仓库中已核的一手文献。若某个承重引文仍缺适用范围或原文位置，就核那一处。宽泛查新不可替代证明。

<a id="pro-exact-goal"></a>
## 1. 冻结不变的研究目标

\(M\) 与项目状态中的 \(W\) 指同一个待找的共同充分条件。固定有限维原欧氏精确 PPA
\[
J_{\lambda F}(x)=\{y:x-y\in\lambda F(y)\},\qquad \lambda>0.
\]
\(S\subseteq F^{-1}(0)\) 为指定非空闭目标。对每个宣称覆盖的组合 \((i,j)\)，给出
\[
\underbrace{\mathsf{Mon}_i(F;\theta_i)}_{\text{单调或次单调}}
\ \land\
\underbrace{\mathsf{Reg}_j(F,S;\eta_j)}_{\text{正则性}}
\ \land\
\underbrace{\mathsf{Comp}_{ij}(\lambda,\theta_i,\eta_j;\text{工作窗})}_{\text{参数兼容}}
\quad\Longrightarrow\quad M
\quad\Longrightarrow\quad
\forall z\in U_0\quad
\exists(x^k)_{k\ge0}\quad
\begin{cases}
x^0=z,\\
x^{k+1}\in J_{\lambda F}(x^k)&(k\ge0),\\
x^k\to x^\infty\in S .
\end{cases}
\]
\(U_0\) 是被认证的初值域，须包含非解初值。若原定理以指定的单个初值及预算表述，就对该预算认证的初值保留存在性结论。给出不会中断的一条原图轨道即可。全根收敛、固定线性收缩、有限长度、统一速率及有效可计算的选根规则均可另证。

“任意”表示研究应逐步扩展到有精确定义的不同组合。列出当前要覆盖的组合、各自的适用窗与尚未覆盖的情形。不同组合的参数门可以不同。只有证明过的范围才可进入结论。一个组合的本轮证书失效，先判明是该证书保守，还是在给定参数下真的没有收敛支。

## 2. 硬性验收

以下每项都须有具体证明或精确出处。任何一项缺失，当前候选只能称为试证中的候选或限定结果。

| 验收项 | 必须交出的证据 |
| --- | --- |
| **G1 同一个 \(M\) 有独立数学内容** | 在调用收敛前给出同一对象或判据的独立定义。说明它在哪里把图方向、正则尺度和参数真正放进同一次推导。给出不同组合共用的承重引理。只统一符号、把旧定理作析取、把 \(A+B\) 或收敛轨道存在性原样写成定义，均未通过。若使用轨道势或值函数，独立证明该量良定、可由上游数据控制，并能构造所需原根。 |
| **G2 原 RLEB 同模导入** | 以[投稿主定理](../../../发表成果整理/RLEB/sections/theorem_spine.tex)的原最近输入零锚、真残差和参数预算为基准，另核 [C09 全对一般模](../../canonical/general_modulus_dynamics.md#gm-data) 的区别。保留同一 \(\omega,\lambda,F,S\) 及各自工作范围。把原前提推出 \(M\) 的证明写全。用 [C242](../../canonical/triangular_rleb.md#tri-object) 的真正非线性反射作检查。只覆盖线性模、只取全对子图或只做 Hölder 幂次，分别标出范围。若要求旧定理不曾要求的附加前提或仅覆盖严格缩小的参数窗，只登记为部分导入。 |
| **G3 至少一条独立基准同样导入** | 除原 RLEB 外，至少完整导入一条参数机制确实不同的基准。优先核 [Luke–Tam 原定理](../../LITERATURE.md#lit-lt-2025)。若该行失败，记录精确断点，再证明另一条独立基准，例如经典单调 PPA 或有原模型耗散的定理。给出同一个 \(M\) 的第二条导入证明、非空参数实例和共有引理。仅用 \(\omega(t)=Lt\) 代入原 RLEB，或换一个同一条件的名称，不计为独立行。另列未覆盖的其他正则结构，继续寻找导入或障碍。 |
| **G4 参数窗真实可核** | 列出 \(\lambda\)、反射或次单调的亏损、正则模及有效尺度怎样参与。参数窗要在使用 \(M\) 之前可确定，并至少有一个非平凡原算子实现。声称覆盖已有定理时，在相同对象、目标、尺度和原许可参数上比较。若改变步长，重新验证该步长处的结构与根覆盖。若宣称门槛锐，给临界点和两侧的正确证据。 |
| **G5 原轨道的存在与点收敛** | 从该初值选出合法原根，证明有限前缀可以无限续走、随后仍满足所用的局部假设，并证明原空间 \(x^k\) 收敛到 \(S\)。只给逐步可选而后继不可接，或只给 \(d(x^k,S)\to0\)，均未通过。比较只针对所声明的存在量词。一个坏根只能反驳全选结论。用 \(r_F(y)=\inf_{v\in F(y)}\|v\|\) 时始终取完整纤维。选中图值只自动给 \(r_F(y)\le\|v\|\)。 |
| **G6 有可区分的新数学信息** | 至少得到一项严格可查的增量，例如在同一原算子、步长、目标和窗口上认证一个与基准严格分离的有效情形，或给一个从已知单侧结构无法直接读出的定量转接、参数边界、选根机制。明确哪一步由共同机制解释。与 C277、C320、C324/C329 和 C333–C339 去重。若声称严格弱化，先给旧条件推出新条件，再给反向严格见证。公开先行性与内部证明成立分别裁决。 |
| **G7 可重建与可反驳** | 定理需逐项写清定义、量词、固定参数、工作窗、根与残差身份、所有外部导入及其适用条件。再独立重构一次两条箭头，优先攻击最危险的承重步骤。一个成立的反例或未闭的致命缺口即可阻止通过。数值实验只作诊断。 |

导师提出的母结构“两侧恢复”可以作为发现 \(M\) 的路线。如果能在两个有独立含义的附加结构下，分别精确恢复单调性和正则性，写清两边与参数门怎样联系。两侧等价属于额外数学成果。共同对象的任何切片都要有实际转接，参照已有[朱江醒合著论文的子水平集目标识别](../../LITERATURE.md#lit-monotonicity-regularity-bridge)。

## 3. 用已有反例攻击候选

按候选的实际主张逐条使用。反例若不满足某项前提，指出正是哪个前提挡住它。用反例排除存在性，须排除认证初值的所有合法收敛选择。

| 测试 | 应判别的事 |
| --- | --- |
| [C242 平方根三角图](../../canonical/triangular_rleb.md#tri-object)与 [C333 固定位移惩罚](nonlinear_rl_bridge.md#rl-shift-obstruction) | 真正非线性的原 \(\omega\) 是否保留。若候选实质用二次上界或丧失同弦下界，要定位并降为子类。 |
| [C322 同初值分根](../../canonical/ppa_native_alignment_and_transverse_test.md#native-sharp) | 对选根候选，能否证一条原好支持续。大根发散排除全选保证，不能否定已证好支。 |
| [参数例 \(F(y)=-by\)](OBJECTIVE_AND_PITFALLS.md#w-parameters) | 在单调结构和真误差界固定时，能否分别识别无根、扩张、二周期、收敛。若 \(M\) 声称保证其中某一段，要在实际参数上对照。 |
| \(F(a,n)=(0,n^3)\) 与 [C318](../../../CLAIMS.md#c318) | 允许非线性收敛，不随意要求固定 \(\kappa<1\)。若从根的收缩反推真残差，检查完整反向输入覆盖。 |
| [C337 小图值加入](nonlinear_rl_bridge.md#rl-anchor-independence)、[C339 长支](nonlinear_rl_bridge.md#rl-multivalued-observation)、[F110 同零截面异动力](../../../FAILED_ROUTES.md#f110) | 完整真残差、所选根、最短步和任意根是不同量词。不要以同一残差范数或同一间隙切片代替方向控制。 |
| [C319 两步相消](../../canonical/ppa_two_step_and_directional_residual.md#td-cancellation) | 把点列收敛与有限长度分开。若 \(M\) 只能用绝对步长和证明，写明有效范围。 |

<a id="pro-loop"></a>
## 4. 研究循环必须执行

1. **锁定一个承重问题。** 从 G1–G7 选当前最可能让候选失败的一项。按“定义、输入条件、参数、欲证推论、首个可攻击步骤”写出精确版本。
2. **提出并比较不同机制。** 先从最能区分现有路线的问题下手。可尝试原图方向与参数化耗散、可以无限拼接的选根证书、跨步相消或原函数/模型的结构。相同证明换记号只算同一个 idea。保留自行换方向的自由。
3. **先做便宜的否证，再做完整证明。** 优先试坏参数、临界端点、弯曲或非孤立零集、真正非线性模、真残差极小点与长支。若反例成立，记录它击中哪条箭头、保留哪些假设。修补若改变对象、窗口、假设或结论，另立版本。若还缺关键引理，下一轮优先证明它或找能击穿它的对象。
4. **逐项给出裁决。** 对每个候选保留简短记录：G1–G7 中哪些已证、被反例击破或尚缺证明，证据在哪，下一次实验是什么。先证完一个子类可以保留该结果，同时继续攻一般 \(M\)。某条路线重复或只剩空窗时，改做实质不同的路线。不要因阶段报告、个别例子成功或某条路线失败而交回任务。
5. **整理并提交真实成果。** 完整推导、关键反例、有效边界、可复用工具或精确障碍形成后，按仓库协议归档。只在确有新数学资产时更新 Claim、失败记录和超边。对有价值的阶段结果 `git add`、`git commit`、`git push`，核验远端。历史探索日志、重复草稿和凭证不进入仓库。

<a id="pro-stop"></a>
## 5. 什么时候才能宣布完成

只有当 G1–G7 全部有承重证据，且第 2 节的最低覆盖被证明，才可交付“找到了 \(M\)”并逐行标明可证范围。先给 \(M\) 的精确定义，然后给各组合到同一个 \(M\) 的导入、各自可行参数窗、共享收敛证明和严谨见证。至少一条原非线性 RLEB 导入与一条独立基准导入须有非平凡实例。超出已证明的组合仍列为开放范围。

只要还有可辨别的试证或反证能推进，就继续下一轮，无需逐轮等作者批准。若会话或工具到达实际限制，先检查点并留下当前最强候选、首个未闭义务、已排除的路线和下一步可直接执行的验证。将状态标为未完成。即使给出了某个候选的不可能性定理，也要标明其对象类、参数和量词，再更换可行路线。局部障碍不能替代一般结论。

**现在开始执行。** 先固定原 RLEB 与另一条参数逻辑不同的精确对照行，选一个能区分二者的候选机制，实际完成第一轮否证和试证。

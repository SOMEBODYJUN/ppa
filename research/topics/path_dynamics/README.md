# 合法路径与有限捕获：主题入口

本目录承接路径动力学的**独立对象、例子和障碍**。共同定义和整轨道定理见 [PA-DEF / PA-WHOLE](../../canonical/path_atlas.md)；全局身份与状态见 [CLAIMS](../../../CLAIMS.md)。一个新结果若有自己的对象、量词或可独立使用的证明，就在本目录开一个短文件；修正原结果的假设或结论则另立 Claim 版本。不要把反例追加成一篇无限增长的主题总稿。

| 独立单元 | 精确关系 | 后续写入点 |
| --- | --- | --- |
| [M1 映射的捕获与一步锐收缩](m1_capture.md) | 显式 \(T:\mathbb R^2\to\mathbb R^2\)，在端点球两步捕获且一步锐因子 \(3/\sqrt {10}\)；只对这个映射作结论 | 原生多值广义方程若找到，另建 native-graph 文件并证明它产生此 \(T\)，再连接路径证书 |
| [幂次剪切 GX-071](power_shear.md) | 显式完整图与真残差给 \(r_{k+1}=r_k^{\gamma q}\)；有界窗口反射指数 \(\gamma\) 且切向余量可算 | 这只是反向校准的可达性；与 GX-072 是不同对象 |
| [振荡剪切 GX-072](oscillatory_shear.md) | 同为完整三角图，但最大全对反射指数 \(\gamma\)，局部每条非零轨道与真残差均有双边 \(q\)-阶 | 归一化轨道 Q 因子未证收敛；与 GX-073 的自然域关系不是同一对象 |
| [自然域逃逸 GX-073](domain_escape.md) | 仅在指定 Minty 域的关系：一步反射有锚定 \(\alpha\)、全对 \(\alpha/(\beta+1)\)，真残差线性，但非零轨道有限步越域 | 改域或延拓 J 属新对象，不能称原算法在全局发散 |
| [PA-WHOLE](../../canonical/path_atlas.md#pa-whole) | 对**每条**合法路径的前缀 coverage、统一终点收缩和可和位移的合取 | 改定理量词须新版本；只改证明可在原单元注明审查范围 |
| [F12](../../../FAILED_ROUTES.md#f12) | 无限词的统一性与非平凡周期障碍 | 新反例独立写对象卡，然后在 F12 记录被否定的精确版本 |

新增工作先固定对象和 Claim 版本，正文给完整证明及反向攻击；随后更新 `CLAIMS.md`、需要时更新失败路线和当前前沿。超边只表达实际承重关系。来源审计的逐单元去向只针对历史材料，原创结果可直接进入本目录。

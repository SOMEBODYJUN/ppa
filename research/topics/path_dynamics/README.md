# 合法路径与有限捕获：主题入口

本目录承接路径动力学的**独立对象、例子和障碍**。共同定义和整轨道定理见 [PA-DEF / PA-WHOLE](../../canonical/path_atlas.md)；全局身份与状态见 [CLAIMS](../../../CLAIMS.md)。一个新结果若有自己的对象、量词或可独立使用的证明，就在本目录开一个短文件；修正原结果的假设或结论则另立 Claim 版本。不要把反例追加成一篇无限增长的主题总稿。

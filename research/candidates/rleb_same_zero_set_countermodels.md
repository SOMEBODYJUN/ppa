# 同一零集不能判定当前严格 RLEB 分支的准入

日期：2026-10-13。范围：独立临时机制对照及复算证据；不改主稿、canonical、Claim 编号或规范状态。已读 `ppa/AGENTS.md`、`RESEARCH_PROTOCOL.md`、`academic-writing-skills` 的 proof-review / example-selection 所需引用、C02-v3 的 TRS1–TRS3、C249/C250 的物理标量门及 C254 的完整映射接口。以下一般陈述由自足解析证明承担；有限计算只检查指定实例。

**结果。** 即使零集、全局总指数、完整 PPA 的单值覆盖、全尺度次线性反射界及所有初值的有限长度收敛都相同，也不能仅由零集决定当前严格几何 RLEB 合同是否成立。下面两个标准凸目标都有完整零集 $S=\{0\}$；第一个满足 C02-v3，第二个不可能满足 C02-v3 或 C250 的任何同算法、同物理距离严格收缩元组。这是机制对照，不作为真实应用模型。第二个仍有非幂型真误差界，且全部 PPA 轨道收敛。因此不能把第二个简称为“没有 RL 或 EB”，也不能由其严格门失败宣称经典 PPA 失败。

## 1. 冻结对象及完整纤维

空间是 $\mathbb R$，固定普通 PPA 步长 $\lambda=1$、完整算子和完整目标零集。取

\[
F_{\rm good}(y)=y,\qquad
F_{\rm flat}(y)=
\begin{cases}
y\exp(-1/y^2),&y\ne0,\\
0,&y=0.
\end{cases}
\]

两者均是从整个 $\mathbb R$ 到 $\mathbb R$ 的单值算子，而非图块。零集、真残差、最近零锚分别是

\[
\operatorname{zer}F_i=S=\{0\},\quad
r_{F_{\rm good}}(y)=|y|,\quad
r_{F_{\rm flat}}(y)=|y|e^{-1/y^2}\ (y\ne0),\quad P_S(x)=\{0\}.
\]

平坦表达式在零点是 $C^\infty$ 的；各阶导数为负幂多项式乘 $e^{-1/y^2}$，在零点均趋零。对于 $y\ne0$，

\[
F_{\rm flat}'(y)=e^{-1/y^2}(1+2/y^2)>0,
\quad F_{\rm flat}'(0)=0.
\]

所以 $F_{\rm flat}$ 连续、奇、严格递增。令 $h_i=I+F_i$，则 $h_i'\ge1$，并且 $h_i(y)\to\pm\infty$ 当 $y\to\pm\infty$。因此每个输入 $x$ 的**全部**近端纤维恰有一个点：

\[
J_{F_i}(x)=\{T_i(x)\},\qquad
T_{\rm good}(x)=x/2,\qquad
T_{\rm flat}(x)=h_{\rm flat}^{-1}(x).
\]

没有遗漏额外近端根，也没有选择政策。$T_i$ 为全域连续映射。这两个完整近端由以下给定凸最小化目标产生：

\[
f_{\rm good}(y)=y^2/2,\qquad
f_{\rm flat}(y)=\int_0^y s e^{-1/s^2}\,ds,
\]

其中积分被积函数在零点按上式延拓。$f_{\rm flat}$ 偶、$C^\infty$、严格凸，且唯一最小点为零。对 $y\ge1$，$F_{\rm flat}(y)\ge e^{-1}y$，故目标强制；负方向由偶性相同。函数 $f_i(y)+|y-x|^2/2$ 强凸且强制，其唯一最小点的最优性条件就是 $x=y+F_i(y)$。两种完整普通 PPA 都有直接优化解释。

## 2. 同样的全局反射控制和指数

固定 $C_i=2T_i-I$。良性例有 $C_{\rm good}=0$。平坦例写 $x=h_{\rm flat}(y)$ 时有准确恒等式

\[
C_{\rm flat}(x)=y-F_{\rm flat}(y)
=y(1-e^{-1/y^2}).
\]

对 $y\ne0$，$1-e^{-a}\le\min\{1,a\}$ 给

\[
|C_{\rm flat}(h_{\rm flat}(y))|
\le\min\{|y|,1/|y|\}\le1.
\]

零点也满足此界。由于 $F_{\rm flat}$ 单调，设 $\Delta y=y_1-y_2$、$\Delta F=F(y_1)-F(y_2)$，则 $\Delta y\Delta F\ge0$，且

\[
|\Delta y-\Delta F|^2
\le|\Delta y+\Delta F|^2.
\]

这准确给出 $C_{\rm flat}$ 的全局 $1$-Lipschitz 界。故对全部 $x,z\in\mathbb R$、任意 $0<\gamma_*<1$，

\[
|C_i(x)-C_i(z)|
\le\min\{|x-z|,2\}
\le2^{1-\gamma_*}|x-z|^{\gamma_*}.
\]

良性例当然可使用同一上界。特别地，两者共同满足 $\gamma_*=1/2$、$L_*=\sqrt2$ 的全尺度完整反射界。

两者的 $S$ 都是非空紧 $C^\infty$ 零维无边界嵌入流形，$\chi(S)=1$。对任意 $a>0$，$I-T_i$ 在 $a$ 处为正，在 $-a$ 处为负。其与 $I$ 的直线同伦在区间端点均无零点，所以

\[
i(T_i,(-a,a))=\deg(I-T_i,(-a,a),0)=1.
\]

同理 $\deg(F_i,(-a,a),0)=1$。所以它们有同一全局完整固定点指数，也有同一零集拓扑。这里直接计算指数；**不能**把平坦例称为 C254 的完整实例，因为其 C02-v3 局部严格门将失败。

以上全局次线性反射界固定在 $\lambda=1$。若把步长改成 $\lambda\ne1$，平坦算子的远场 $F(y)\sim y$ 导致
$C_\lambda(x)\sim[(1-\lambda)/(1+\lambda)]x$，不再满足上述全尺度 $\gamma_*<1$ 界。后面的局部严格收缩失败则对每个固定有限 $\lambda>0$ 都成立。

## 3. 良性例的准确 C02-v3 与 C250 元组

取完整允许关系 $\mathcal J=J_{F_{\rm good}}$，并取

\[
U=\mathbb R,\quad R=1,\quad\bar t=1,\quad
L=0,\quad\gamma=1,\quad\psi(q)=q,\quad\kappa=1/2.
\]

完整覆盖已证；最近锚只能是 $p=0$；$y=x/2$ 使 $2y-x-p=0$；真误差界为等式。评价窗是 $(R+LR^\gamma)/(2\lambda)=1/2\le\bar t$，全窗直接兼容为

\[
\psi((t+Lt^\gamma)/(2\lambda))=t/2=\kappa t.
\]

长度预算函数为 $\Theta(t)=t$，到 $\mathbb R\setminus U=\varnothing$ 的距离为 $+\infty$，所以每个合法初值的严格预算成立。C02-v3 供应

\[
|x_k|=2^{-k}|x_0|,\qquad
\sum_{k\ge0}|x_{k+1}-x_k|=|x_0|.
\]

C250 也准确闭合：取 $v=I,a(t)=t,\omega(q)=0,h(t,s)=s$、$\psi(q)=q$、$M_0=1$、$\rho(q)=q$、$g(q)=q$。其全标量门就是

\[
2q^2\le t^2/2\quad\Longrightarrow\quad q\le t/2,
\]

仍取 $\kappa=1/2$，相同预算和相同全部完整 PPA 适用。

## 4. 平坦例仍从全部初值有限长度收敛

若 $x>0$，唯一输出满足 $0<T_{\rm flat}(x)<x$；若 $x<0$ 则同号且绝对值严格减小；$T_{\rm flat}(0)=0$。因此任意初值的轨道在固定符号半轴单调，存在极限。把 $x_k=x_{k+1}+F_{\rm flat}(x_{k+1})$ 传到极限，得 $F_{\rm flat}(\ell)=0$，只能 $\ell=0$。由单调性准确望远镜求和，

\[
\sum_{k=0}^{\infty}|x_{k+1}-x_k|=|x_0|,
\quad x_k\to0.
\]

此证明覆盖全部初值，且无限延拓来自完整全域覆盖。无需把某个已知定理名称当作缺失前提。这个经典单调凸机制恰好说明严格几何证书不可能成为一切有限长度 PPA 收敛的必要条件。

## 5. 平坦例排除全部同算法严格几何元组

对非零输出 $y$，令 $x=h_{\rm flat}(y)$，则

\[
\frac{d(T_{\rm flat}x,S)}{d(x,S)}
=\frac{|y|}{|y+F_{\rm flat}(y)|}
=\frac1{1+e^{-1/y^2}}\longrightarrow1\qquad(y\to0).
\]

给任意 $\kappa<1$，取非零 $y$ 足够小使 $e^{-1/y^2}<(1-\kappa)/\kappa$，则实际转移满足
$d(Tx,S)>\kappa d(x,S)$；输入 $x\to0$，所以该反例落在包含零点的任何开域、任何正认证半径中。因而不存在零点邻域上的统一严格一步距离收缩。

**这排除全部当前 C02-v3 / C250 严格元组，而不只是某个选择。** C02-v3 的 TRS1–TRS3 对每个实际转移先给

\[
d(Tx,S)\le\psi(r_F(Tx))
\le\psi((d(x,S)+Ld(x,S)^\gamma)/(2\lambda))
\le\kappa d(x,S).
\]

该一步结论在长度预算之前成立。C250 的核能量和全标量门同样先给实际物理距离 $d(Tx,S)\le\kappa d(x,S)$。前述实际转移反驳该必要后果，因此任何可选 $R,\bar t,L,\gamma,\psi$ 或 C250 的 $a,\omega,h,\rho,g$ 都不能在同一个完整普通 PPA、同一个 $S$ 和同一个物理距离上闭合严格门。改变核通常改变算法；用新算法的证书不能反驳这个同算法排除。

对任意非零轨道，邻接误差比也趋 $1$。更强地，记 $e_k=|x_k|>0$，则 $\log(e_{k+1}/e_k)\to0$。Cesàro 平均给

\[
\frac{\log e_k}{k}\to0,\qquad e_k^{1/k}\to1.
\]

故该轨道没有任何固定 $q<1$ 的 $R$-几何上界 $e_k\le Cq^k$；有限长度与严格几何率确实分开。

但是平坦算子**有**非幂型真 EB。函数 $\eta(t)=t e^{-1/t^2}$（$\eta(0)=0$）在 $[0,\infty)$ 连续严格递增且满射，取 $\psi=\eta^{-1}$，就有

\[
|y|=\psi(r_{F_{\rm flat}}(y)).
\]

其在零点连续且非减，满足一般 EB 的基本规范。对任意 $\alpha>0$，

\[
\frac{|y|}{r_{F_{\rm flat}}(y)^\alpha}
=|y|^{1-\alpha}e^{\alpha/y^2}\longrightarrow\infty,
\]

所以不存在 $|y|\le K r_F(y)^\alpha$ 的局部幂 EB。反射锚界也仍可取 $L=1,\gamma=1$，因为 $C$ 是全局非扩张且 $C(0)=0$。失败处准确位于这些前件与统一严格兼容/能量收缩的合取，而非零集形状、覆盖、单值性、反射连续性或真 EB 的存在。

## 6. 对“零点几何分类”的实际含义

| 冻结字段 | 良性例 | 平坦例 |
|---|---|---|
| 完整零集 / 最近锚 | $\{0\}$ / $0$ | $\{0\}$ / $0$ |
| $S$ 的几何、拓扑、欧拉示性数 | 单个光滑零维点，$\chi=1$ | 相同 |
| 完整全局 PPA | 全域、连续、唯一 | 相同 |
| 全尺度完整反射 | 有界、全局 Hölder | 相同类别；共同 $(\gamma_*,L_*)=(1/2,\sqrt2)$ |
| 完整零点/固定点总指数 | $1$ | $1$ |
| 全部初值 PPA | 有限长度趋零 | 相同结论，总长同为 $|x_0|$ |
| 准确相邻误差渐近比 | $1/2$ | $1$ |
| 当前严格 C02-v3 / C250 合同 | 显式通过 | 任意同算法元组均不可能 |
| 图在零点附近的横向增长 | $F'(0)=1$，线性真 EB | $F'(0)=0$、无限平坦；仅非幂型 EB |

因此可把“点、孤立零簇、流形、有交叉/奇异等”作为零集形状的描述，但其本身不是当前 RLEB 类的充分判据。必须加入完整算子图在零集附近的增长、完整近端根政策、同最近锚反射、真实输出 EB 及准确严格门等动态/解析数据。当前拓扑指数结论提供的是认证后的必要约束，没有把零集拓扑提升为可判定准入的充分条件。

如需要同一机制的二维版本，直接取

\[
\widehat F_{\rm good}(u,v)=(u,v),\qquad
\widehat F_{\rm flat}(u,v)=(F_{\rm flat}(u),v).
\]

两者仍有完整 $S=\{(0,0)\}$、全域唯一完整 PPA、全部轨道有限长度趋零及总固定点指数 $1$。平坦映射的反射是 $(C_{\rm flat}(u),0)$，仍有界且 $1$-Lipschitz，故同一全尺度 Hölder界成立。初值轴 $v=0$ 保留上面的严格门反例。这把机制嵌入平面而不更换目标几何。

## 7. 精确与 binary64 复算证据

复算命令：`python3 research/code/rleb_same_zero_set_countermodels/verify.py`。无外部依赖，seed 为 `20261013`。程序对两个承重平方恒等式及良性 C250/尾系数做有理多项式精确核对；对 601 个输出、5000 个点对和 7 组 3000 步轨道前缀做 binary64 核对。

本次运行全部通过：最大逆方程重建相对误差为 $4.301\times10^{-16}$；采样反射最大绝对值约 $.638173$；采样全局 $1$-Lipschitz 和 $(1/2,\sqrt2)$ Hölder 界均无正超差；有限轨道前缀长度与望远镜等式一致。

在足够小的输出上，严格正的步长会低于 binary64 分辨率。结果文件对此逐行标注；显示相邻比为 $1$ 是舍入，不能把它当作额外固定点或有限计算的渐近证明。一般覆盖、界、收敛和排除量词全部由上面的解析论证承担。

文件：`research/code/rleb_same_zero_set_countermodels/verify.py`、`research/code/rleb_same_zero_set_countermodels/results.json`、本报告。独立数学反审确认主机制，并专门指出全局 Hölder 前件须固定 $\lambda=1$；该范围已写明。

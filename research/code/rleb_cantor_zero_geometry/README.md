# 无限 Cantor 完整 PPA 的精确复算

运行：`python3 research/code/rleb_cantor_zero_geometry/verify.py`（仓库根目录）。输出：`results.json`。

环境：Python 3.12.14，仅标准库；`fractions.Fraction` 精确算术，无随机 seed 和浮点分类。参数固定为普通 PPA、`lambda=1`、`v=Id`、三分 Cantor 集和算子内段系数 `1/2`。

归一化三进制状态的精确重复判断有理点是否属于实际无限 Cantor 集；遇到中间三分之一则返回实际间隙端点。势函数用同一循环的仿射闭合反算，包含周期三进制点，绝不以有限 Cantor 近似代替目标。

有限检查：835 点、63 个第 1–6 层间隙、35778 点对、252 个近右端扩张、6300 个轨道前缀、12060 个近端目标比较，以及 20 层面积和加精确几何级数尾 `1/56`。零输入、Cantor 端点、切换点、全部分支、负输入与远端输入均已包含。可选四次目标的反算只用精确有理关系，不靠浮点立方根猜测。

全称证明见[候选卡](../../candidates/rleb_cantor_zero_geometry.md)。模型是机制对照：Cantor 是完整驻点集，唯一全局极小点为 0；全轨道有限长度并不供应共同消失尾界，也不供应连续极限回缩。

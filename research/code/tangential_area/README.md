# C232 候选的完整包含与二阶面积复算

从仓库根运行 `python3 research/code/tangential_area/verify_area.py`。
仅依赖 Python 标准库；运行版本保存于 area_results.json。

固定seed20261010；p=1/3、0.75、1.25及ω=π/2、π、2π，各500个随机初值核完整J+F(J)=Id与真EB，包含正负法向输入。identity容差1e-9。另对p=1/3、0.75、t0=8、w0=z0=0，各相位复算200000步；相位用精确四分之一圈幂，避免大三角函数参数的范围约简误差。

有向面积常数核对使用后半段增量；需减去一阶项0.5 Im(conj(w_inf)*(w_N−w_mid))。w_inf 用独立Abel首项R_N≈d_N/(1−i)估计。容差1e-4。未减一阶项的有限比值在p=0.75处并非可靠常数估计，代码同时保留原比值和校正比值，不将它们误当相同数学对象。

有限输出不证明无穷级数、充要分类或sharp RL。正文仍为candidate，未参与构造者的独立接收、原生交换子判据和扰动合同均开放。

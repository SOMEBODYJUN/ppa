# C238–C240 的有限复算范围

从仓库根目录运行 `python3 research/code/completion_budget_gate/verify.py`。仅用 Python 标准库，seed=238240，浮点不等式诊断容差3e−12；有理对称与覆盖算术使用 Fraction。实际环境和结果保存在 results.json。

- 280组有限概率方差检查 C238 的 b 下界及 η 有理化；维数1/2/5、锚数1–7、γ取0.001至0.999。有限复算不证明 Hilbert 全称结论，也不求最优 b。
- 精确符号共轭核固定平面维数2、RP²三点范数和距离、管盘分离、限制次数缺额−2、单矩阵符号稳定子及双矩阵共同稳定子±I。
- C240 的一维全覆盖示例：N=[−1,1]、C₀=0、指定预算L=1、γ=1/2；精确端点和步长认证两段过渡区的 h 网及原区间的 δ 网，核2Lδ^γ缓冲和位移余量。**这是证书估计示例，不是有限维n≥2一般命题的计算证明，更不是RP²完成。** 此例最小原预算为0，程序未把指定L=1当最优值。

规范正文与独立审查承担一般证明。没有全域Hopf算法、RP²预算证书、γ=1或无限维有限网断言；也没有用随机点集冒充覆盖。

# 非线性 Bregman 核的自然 GPPA 例

模型为凸最小化 `f(t,s)=t²/2`，Bregman 核 `h(t,s)=t⁴/4+s²/2`。
完整 GPPA 方程为 `t³=u³+λu`，第二坐标保持不变。
解析证明和核/物理两套证书见
[自然例子与任务定位](../../../发表成果整理/GPPA主理论/自然例子与任务定位.md)。

运行：

```bash
python3 research/code/rleb_gppa_example/verify.py
```

仅用 Python 标准库。`Fraction` 作精确图关系及 Bregman 距离检查；
`Decimal` 精度为 110 位，每一步用 240 次二分独立求完整隐式解。
无随机抽样或 seed。参数、初值、符号、零、很小/大尺度在脚本中明列。
最小二分起始上界为 `min(|t|, |t|³/λ)`，避免极小解的数值相消。
隐式方程的相对残差门为 `1e-65`；速率试验门为 `1e-20`。
代码同时复算普通 PPA、合法转移的立方逆模及退化核的非收敛物理选择。

输出 [results.json](results.json) 记录实际计数、精度和误差。
有限检查验证的是这些指定输入的算术与隐式解；
一般覆盖、全部图值、无限轨道收敛和精确速率依赖报告中的解析证明。

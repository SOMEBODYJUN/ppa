# 精确经典转接的有限复算

运行：

```bash
python3 research/code/novelty_development/verify.py
```

[verify.py](verify.py) 写入 [output.json](output.json)。Python/NumPy/SciPy 版本、脚本及被调用旧辅助函数的 SHA256 均随输出登记。输入固定，无随机 seed。标量根用 100 位 Decimal、最多 500 次二分；矩阵反算用 IEEE binary64，归一化残差阈值 `2e-9`。本轮实跑通过 16 个 C272 SPD 转接、10 个 C273 原生 Gram 转接、10 个 C274 部分对偶转接及 13 个 C1 合法驻点输出。

检查内容：

- 对比原点 Bregman 幂核与中心距离幂近端：领先幂次相同，有限输入的算法输出一般不同。避免靠相同速率偷换算法。
- C272 常数 SPD 多维子类：原完整方程、普通对偶 PPA、物理逆变换同时反算；覆盖零、跨符号、`m=1` 临界线性参照及远输入。
- C272 C1 多根例：至少三个合法根分别核共同 `E=||u||²` 的 ABS H1/H2；也核 NG12 原目标的局部 H1。包括零输入和正负小输入。这里只调用旧代码的辅助函数，不重新执行整套旧检查，不声称枚举完整数值纤维。
- C273：原式、守恒切向对偶、SVD 逆、共轭 Fenchel 等式及普通对偶 PPA。同时测试物理原点、真实零点、秩亏、满秩与远输入；物理原点不是 `zer F_c`，输出因此不必为零。
- C274：部分共轭/梯度、Fenchel 等式及 SPD 子类的普通对偶 PPA；正负切向、零输入、正常中心与远输入。`p=2` 中心单独核精确线性算法；Fraction 核源定理的超线性参数门，`p≤2` 不错误外推。

全输入覆盖、完整纤维身份和保阶由三个[规范证明](../../novelty/2026_10_13/README.md)承担。有限计算既不证明全称结论，也不证明某公式公开首创；本代码仅排查代数、符号、临界参数及反算错误。

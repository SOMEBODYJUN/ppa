# C455 的有限复算

证明在 [DD1 可观察误差余量](../../topics/dd2/inexact.md#dd1-observable-margin)。本目录仅检查有限算术，不代替全称证明，不认证公开新颖性或相对其他算法的成本优势。

运行：

```sh
python3 research/code/dd1_robust_margin/verify.py > research/code/dd1_robust_margin/results.json
```

仅依赖 Python 标准库。`Decimal` 使用 80 位有效精度、容差 `1e-65`；关键十步判据使用 `Fraction` 精确有理数。无随机抽样，seed 为 null。具体 Python 版本、脚本 SHA256 及实际输出保存在 `results.json`。

参数为 `L = .1,.25,.5,.9,1,2,10`，`sigma/T(L) = 0,.1,.5,.9,.99`，三个处于 `(m,1)` 的目标因子；每组检查 101 个 `a/s` 值。两支等号构形分别重构坐标。具体内层模型固定 RM11，初始方向为 `(1,0),(0,1),(1,-2)`、幅度为 `1e-80,1,1e80`；另外计算 `(1,0)` 到范数 `1e-8` 的实际外迭代。换参数的有限点为 `lambda=.25,7/16,.5,1,2,4,8`。零缺陷预算比在 `z=0,.01,...,10` 上检查，其上界 `5/4` 的一般证明另在正文。

复算的盲区包括未测试的所有实参数、一般闭目标或多值图的全称性质、浮点实现中的严格可认证舍入、局部图成员 oracle、实际应用和全部文献先行性。RM13 的数学成本界是精确算术模型中的上界，程序运行次数只是这些固定输入的观察。

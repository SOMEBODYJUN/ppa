# C236/C237 的有限复算

从仓库根运行 `python3 research/code/sharp_completion_cost/verify.py`。
依赖 NumPy；脚本 SHA-256、实际 Python/NumPy 版本、seed 20261011、binary64 绝对容差 3e-11 和最大诊断误差保存在 `results.json`。

- Fraction 精确核单点径向上界，覆盖零距离、管边界、刚出管、大输入、θ=0、θ=1/2、θ接近1；独立反算上界差。
- 枚举长度1–3的缺额向量，每项−3至3，逐分量重建一般/非退化补偿分配，并用独立有限signed-index搜索核非退化最少数量；从胞腔数独立反算表中Euler特征。
- 检查整数指数模型的二维绕数、所有指定正则目标原像及其定向计数，在维数2/3/5核唯一零点和范数保持，含复平面零坐标、原点与极角分支。
- 检查不同θ、旋转角、管半径和γ的单点投影完成：全部指定有限输入对的Hölder预算，反向用对径边界点核精确局部半范数，完整图输入/反射回代，有限真实迭代的径向收缩。含精确零预算和大管外输入。

程序不构造全域 Hopf 延拓、不证明球值延拓、全称计数最优性、任意Hölder数据或无限时间收敛。承担这些量词的是[显示解析证明](../../canonical/sharp_completion_cost.md)。本轮没有新增独立代理审查；不把有限PASS称为数学证明。

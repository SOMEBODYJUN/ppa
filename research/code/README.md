# 可维护研究代码的入口

新的可复现实验放在 `research/code/<topic>/`。每个专题目录包含可运行源文件和一个短 README，写明：绑定的 Claim ID/版本、测试对象与有限参数范围、依赖版本、完整命令、seed、精度/误差控制、预期输出及本次实际输出、数学上不能推出的结论。随机或浮点实验应保存足以重放结果的输入与容差；精确有理证书要说明它验证的是哪个有限断言。

现在尚无已从历史代码重写且经规范验收的可维护程序。十个已复跑旧验证器仍在 [历史代码登记](../CODE_REGISTER.md) 和 `history/sources/`；它们不会因为被复制进这里而获得新的证明状态。需要持续改进某个验证器时，先锁定其 Claim 版本与有限断言，再写新的代码并分别保存原件出处和新运行记录。

# C215/C216 的有限复算

在仓库根目录运行 `python research/code/gppa_scope/verify.py`，只依赖 Python 标准库。输出为相邻 `results.json`；脚本记录 Python 版本、固定参数、正文 SHA-256、精度和误差边界。没有随机 seed，因为全部检查确定性枚举。

- C215：两种 Decimal 精度独立计算超线性尾和；使用 RB3 的解析余尾界复算移位恒等式、坐标共轭与逆回代、零点、负初值首步和超二次真实阶。
- C216：Fraction 精确枚举满足零锚条件的二维向量，反代抵消平方身份；检查偏移零点、零算子、非单射可附加纤维、零误差、交替持续误差、恒定核、源预算的精确差值及正点跳跃 gauge。
- 比较量词：有限集合模型分别演示“固定核严格性在改写饱和后消失”与“已有重合仍可有存在性分离”，防止把两个不同量词混同。

解析余尾界是正文证明的一部分；Decimal 四舍五入不是严格区间算术，双精度一致只作独立复算。有限测试不证明全对条件、无限轨道或全球新颖性。一般结论见[改写边界](../../canonical/gppa_reformulation_boundary.md)与[正则化稳定性](../../canonical/gppa_regularized_stability.md)。

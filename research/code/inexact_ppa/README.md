# 内层精度定理和完整纤维的有限复算

运行命令：

    python3 research/code/inexact_ppa/verify.py

[verify.py](verify.py) 写入 [output.json](output.json)。脚本与独立边界辅助脚本的 SHA256、Python/NumPy 版本、固定输入、100位 Decimal 和 binary64 容差 2e-12 均随结果登记；没有随机 seed。

实际检查：

- C275 的一个共同窗口：反射逆模反算、种子帽、信任半径、完整接受区间端点及中点，零输入和正负边界，共1645个接受见证。
- 真多值算子：直线法锥的全部参数化接受区间，共492个见证；所有输出真实残差为0，所选图值可非零，核查二者不能等同。
- 正点跳跃的反射模：逆下确界未达到的反算，检查证明没有假用 $u\le B(Q(u))$。
- C276：Fraction 临界系数、零／跨符号、临界恒距漂移、远端零输入逃逸、完整纤维反算、闭式精确轨道和 Hölder 共轭。
- 自然循环博弈：125个正对角系数矩阵的奇异值界、步长和非精确收缩系数。矩阵全称结论由候选正文的符号证明承担。
- 实跑独立的 [边界脚本](../inexact_forcing_attack/check_frontier.py)，保存其原 stdout；不以重复实例数量提升证明状态。

有限网格并不枚举全部接受纤维，也不证明最优指数。全称证明、完整纤维公式和失败政策见 [C275/C276](../../topics/inexact_ppa/README.md)。代码仅检查算术、边界和原式反算，不认证公开首创或实际求解效率。

# PPA 主定理调整的复算

在仓库根目录执行：

```bash
python research/code/ppa_main_reordering/verify.py
```

依赖 Python 3 与 SymPy。代数使用精确符号及有理数；非幂次标量窗用
80 位小数核对。输出写入 `output.json`。比较基线为
`b55626c2ca62498620d803fb7e426ec8f6e211fe`。

范围：反射及平行四边形恒等式、幂次/非幂次尾预算反算、完整双输出
关系的跨符号/零/边界检查、SPD 零输入反例，以及原 B1–B4、G1–G5
和 Euler 数学正文的保真、活跃 LaTeX 标签及证明依赖顺序。
作者纠正后的集中假设版本额外核对：P1–P4 与 `10b475b` 同字节，
G2–G3 与原基线同字节；G1/G4/G5 的引用展开逐项回到原条款。
同时核对标题/摘要/引言安排和原第1、3、4、5章正文保持。
非幂次部分仅为标量公式核对，没有构造或认证新的算子模型。
全称收敛结论由主稿解析证明支持，有限样本不代替前件验证。

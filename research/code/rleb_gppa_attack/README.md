# RLEB–GPPA 独立攻击的可复算核验

运行环境：Python 3 标准库，无额外依赖。

```bash
python3 research/code/rleb_gppa_attack/verify.py
```

输出同时打印到终端并保存为代码同目录的 `results.json`。输出路径由 `Path(__file__).with_name('results.json')` 决定，与工作目录无关。

`verify.py` 从独立推导的 scratch 核验器原样复制后，只把结果路径改为可提交的相对代码位置，并增加集成稿的一般核能量/线性特例精确检查。原有检查未改。使用 `Fraction` 做有理数精确运算；凸 Bregman 唯一根使用 100 位 `Decimal` 和固定二分迭代次数，零输入及异号另含在输入网格中。

受检对象包括完整恒等核多值关系、可控及不可控非单射核、远端零输出、非闭核零像、不可和纤维漂移、Bregman 三阶率与一般核能量的线性特例。完整解析证明与测试范围见 `发表成果整理/GPPA主理论/独立边界审查.md`。

结果中的计数由程序累加并反算核对。有限例及有限分支枚举只认证其受检算术；一般定理仍由报告和主稿的完整证明承担，不认证外部新颖性或未读取模块。

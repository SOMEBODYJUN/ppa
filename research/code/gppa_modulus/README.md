# 一般模 GPPA 的有限复算

绑定 C208–C214 的规范证明：完整核关系、残差平方能量、幂次兼容边界、非线性核共轭、误差卷积、壳层阈值及对数/螺旋反例。程序不是数学证明，也不核全球先行性。

从仓库根运行：

```bash
python3 research/code/gppa_modulus/verify.py
```

只依赖 Python 标准库。完整版本、脚本 SHA-256、seed、参数和实际输出保存在 [results.json](results.json)。Fraction 精确复算平行四边形、ASM 能量和临界系数 1、误差卷积及反代；浮点检查非线性核逆、完整图双支的 selected/true residual 区分及有限对数积分包络。参数网格包含零输入、正负输入、很小的 λ·ε、临界等号、幂乘积两侧和 ν>2。确定性随机点使用固定 seed；浮点容差逐项写在代码中。

对数尾用完整有限和加积分余项区间，不把截断和当成精确无限和；螺旋弦长再由两个物理坐标反算核对。任意图点对、无正则性核排除、无限级数门槛和全时间收敛结论均由规范正文承担。`PASS` 的范围是这些有限代数与算例。

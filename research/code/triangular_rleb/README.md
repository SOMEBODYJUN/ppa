# 三角 Hölder 漂移例的有限核验

从仓库根运行 `python3 research/code/triangular_rleb/verify.py`。
只使用 Python 标准库；固定 seed 20261011；输出到同目录 `results.json`。

对象为完整单值 F(u,v)=(u,−√|u|)，完整近端映射 J_F(a,b)=(a/2,b+√(|a|/2))。
核验完整方程反算、锚定条件、真实残差、全对估计、同窗与兼容常数、轨道闭式、松弛 PPA 轨道以及 SPD 度量反例。
锚定 L=√2、κ=3/4 与独立全对 L=3/2、κ=4/5 明确分开。

有限运行不是一般命题的证明。解析证明和作用域说明见
`发表成果整理/本轮重构/自然例子研究.md`；规范身份与主稿由整合者另行登记。

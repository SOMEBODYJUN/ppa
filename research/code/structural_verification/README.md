# 结构性验证结果的复算

从仓库根目录运行：

```bash
python3 research/code/structural_verification/verify.py
```

依赖：Python 标准库、NumPy、SciPy。本轮环境 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0。程序写出同目录 `output.json`，包含实际代码 SHA256、参数和数值结果，无随机采样。

| 受检对象 | 参数、精度及实际检查 | 有限证据的边界 |
| --- | --- | --- |
| C272 全驻点模型 | $m=3,\lambda=\mu=1,B=3/4,R=1/4,\kappa=1/4$；Fraction 核 $4145/65536$；Decimal 100 位有效数字、至多 500 次二分 | 每个指定正输入核至少三个合法根；不枚举全部纤维 |
| C272 跨符号/零/远输入 | $a=0,\pm1/4,1/100,4$；原方程按输入与切向大小分别归一化反算，相对误差最大 $6.4\times10^{-100}$ | 不以一条中心分支轨道证明全分支结论；完整控制来自 NG4–5 |
| C272 失败边界 | 局部条件下零输入远根 $0,\pm1$；反射非扩张的负内积；中心合法根的实际目标下降方向 | 精确代数或指定高精度数值，未升级为其它类的失败 |
| C273 同组证书 | 单位数据、$B=1,R=10^{-8},\lambda=10^4,\kappa=1/4$；Decimal 100 位算 $q_\lambda$、$\Theta(R)$ | 不用数值预算代替全部输入/输出的解析界 |
| C273 锐指数见证 | $\lambda=.1,1,10^4$；$t=-10^{-4},10^{-2},10^{-4},10^{-6},10^{-10}$；binary64 解四个精确缩放后的方程并反算原矩阵方程 | $2/3$ 的最优性来自解析渐近与全输入上界；15 个实例不证明普遍性 |
| C274 混合核 | $p=2,q=4,\lambda=.7$，法向矩阵 $\begin{pmatrix}2&.5\\.5&1\end{pmatrix}$，输入 $(.2,-.1,1.4)$；核不变量、三次逆求解、显式切向极限；中心层另核普通 PPA 恒等式 | 不把中心线性阶和非零切向层三阶混为同一个全域阶 |
| 反馈候选临界门 | $q=1/4,C/c=2,\gamma=1/2$，direct 证书临界值恰 1，正小输入的实际 gauge 比值大于 1 | 这是共同证书门；直接收缩仍可成立 |

矩阵见证使用 $A=1+t^2 A_2$ 等缩放变量，避免直接减去几乎相同的数。把缩放解重建成矩阵后，binary64 的 $A-1$ 损失会被大 $\lambda$ 放大；输出分别记录缩放残差、原式残差及 $5\times10^{-13}+4\epsilon_{\rm machine}\max(1,\lambda)$ 的重建舍入界。该界只处理有限反算的数值误差，不改变解析定理的常数。

程序的 `PASS` 表示这些明确有限检查完成。一般维数、所有远端纤维、零输入吸收、同窗兼容、最优指数和物理收敛由三份规范正文证明；不由程序认证。

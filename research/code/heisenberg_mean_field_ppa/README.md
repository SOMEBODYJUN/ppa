# Heisenberg 平均场完整 PPA：有限复算

对应 [候选正文](../../candidates/heisenberg_mean_field_ppa.md)。不改变论文或定理编号。

从仓库根目录运行：

```bash
python3 research/code/heisenberg_mean_field_ppa/verify.py
```

依赖 Python 标准库；Decimal 240 位，固定 seed 20261013。当前环境没有 SymPy/mpmath，因此精确有理数不等式用 Fraction 核验，双曲函数和完整径向逆用 Decimal exp 与二分法反算。二分法只用于有限计算，完整唯一性由正文解析证明。

程序核验：401 个同窗半径、零输入、10⁻⁹⁰ 级输入、10⁶ 级远输入、径向/切向谱下界、1225 组含跨符号的三维点对、临界 λ=1 与 λ=2 的零输入多值攻击，以及精确指数算术。向量范数最终比较使用双精度；这些点对不认证全尺度 Hölder 常数，正文的谱积分证明承担全称结论。

输出保存为 [results.json](results.json)。指数 2、−1、1 来自解析 ENR/同伦认证；此代码检查数值和算术，不从采样估计拓扑。零附近直接用 240 位可去奇点公式，保证本次测试的有效位数；这不是任意输入精度的求根器承诺。

精度检查曾在160位下发现10⁻⁹⁰输入的反算绝对误差约6.2×10⁻¹⁰³，未达到代码要求的10⁻¹²⁰。提高至240位后保留同一容差，本次最大反算误差约2.05×10⁻¹⁸²；未以放宽容差掩盖双曲函数近零消去误差。

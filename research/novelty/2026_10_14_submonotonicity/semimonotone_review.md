# Semimonotonicity / weak Minty 对 LT→RL 路线的独立审查

日期：2026-10-14。范围：固定原关系、步长和量词后的竞争框架比较；不修改主稿、CLAIMS 或图，不认证世界新颖性。本报告按仓库 `academic-writing-skills` 的证明审查模式执行。代数推导是本次独立检查；文献事实仅限以下实读版本。

**裁决。** LT 的全对二次不等式在同一 scaled 图上，精确重参数化为已有的 tied 负负 semimonotonicity；Otero–Iusem 2010 作者预印本已经给出这个代数类。非 tied 标量/矩阵 semimonotonicity 比一个反射 Lipschitz 常数保留更多方向信息，但在固定步长的正定性门内，它仍给出 Lipschitz 反射，因此不是超越线性模的新正则性。真正不同的竞争入口是 **零锚 semimonotonicity / oblique weak Minty + 原残差 EB + 实际步预算**：它不要求所有图点对，允许同一输入的多个合法输出，已有 PPPA 收敛定理。一般模双损失可以沿这条入口发展，但不能把换模、矩阵预算或新名字本身当作新算法、新模型或新收敛结论。

## 2. 同坐标关系：LT 不是 semimonotonicity 以外的代数类

固定实 Hilbert 空间、原关系 `F`、同一图块 `Γ⊂gph F`、步长 `λ>0`。对两图点定义

\[
a=x-x',\quad b=\lambda(w-w'),\quad z=a+b,\quad c=a-b.
\]

Evens 参数属于未缩放原图：

\[
\langle x-x',w-w'\rangle\ge\mu\|x-x'\|^2+\rho\|w-w'\|^2.
\tag{S1}
\]

置 `m=λμ, r=ρ/λ`，则 (S1) 是 `⟨a,b⟩≥m‖a‖²+r‖b‖²`。这一步不可漏掉 `λ`；本报告以下 `r` 不是 EB 常数。

LT 对 **λF** 的 Def 2 是

\[
\langle a,b\rangle\ge-\tau\|a+b\|^2,\qquad\tau\ge0.
\tag{S2}
\]

展开右侧并除以 `1+2τ>0` 得精确等价：

\[
\langle a,b\rangle\ge-k(\|a\|^2+\|b\|^2),\qquad
k=\frac{\tau}{1+2\tau}\in[0,1/2).
\tag{S3}
\]

因此原图参数是

\[
\boxed{\mu=-\frac{\tau}{\lambda(1+2\tau)},\qquad
\rho=-\frac{\lambda\tau}{1+2\tau}.}
\tag{S4}
\]

Otero–Iusem 2010 Def 2 则把 (S3) 写作系数 `−η/2`，`η∈(0,1)`；对应 `η=2τ/(1+2τ)`，反向 `τ=η/[2(1−η)]`。这是一一重参数化，`τ=0` 补上单调端点。他们 Prop 5 的 `‖z‖²≥(1−η)(‖a‖²+‖b‖²)` 也正是 LT Prop 3(b)。

此身份先比较同一图点集合。LT 的矩形窗口 `gph F∩(U×W)` 与 Otero 的全图声明不能省略作用域差异；但在一个固定窗口中，没有不同的二次几何。LT 的局部化、极大性约定和具体收敛定理仍须另外比较，不能由概念重参数化宣布整篇重复。

同一恒等式 `4⟨a,b⟩=‖z‖²−‖c‖²` 给出

\[
\text{LT}_\tau\quad\Longleftrightarrow\quad
\|c\|\le\sqrt{1+4\tau}\|z\|.
\tag{S5}
\]

**数学上 (S5) 对每个有限 `τ≥0` 成立。** LT Prop 4 使用 `τ<1/2`，是其 almost-firm violation `ε=2τ<1` 的接口范围；不是代数恒等式在 `τ=1/2` 突然失效。LT Thm 2 更要求真 EB 常数 `K` 满足 `τ(1+K/λ)²<1/2`，并有局部coverage、自映射、允许局部全部输出等前件。

## 3. 非 tied 参数：信息更丰富，但正定门内仍是 Lipschitz

设

\[
A=1+m+r,\quad B=m-r,\quad\Delta=1-4mr=1-4\mu\rho.
\]

无论参数符号如何，(S1) 精确等价于

\[
A\|c\|^2+2B\langle z,c\rangle\le(1-m-r)\|z\|^2.
\tag{S6}
\]

若 `A>0, Δ≥0`，配方得

\[
\left\|c+\frac BA z\right\|\le\frac{\sqrt\Delta}{A}\|z\|,
\quad
L_C=\frac{|B|+\sqrt\Delta}{A},\quad
L_J=\frac{|1+2r|+\sqrt\Delta}{2A}.
\tag{S7}
\]

这在自然输入域上给图块 Cayley 与 resolvent 单值、Lipschitz，**不制造输入点**。两个普适常数可由一维线性 Cayley 映射达到；详尽独立证明仓库已有 `canonical/non_tied_cayley.md`，本次重新展开了恒等式。

`B≠0` 的中心偏移是实质信息：固定 `λ=1, μ=1, ρ=0`，`F_1(x)=3x` 和 `F_2(x)=x/3` 的反射常数均为 `1/2`，但只有前者满足 (S1)。所以标量 RL 常数不能恢复指定非 tied 参数；从 (S7) 只保留 `L_C` 是损失信息的充分化。

不过固定 `λ` 并允许任意有限 LT 常数时，任何 `A>0,Δ≥0` 的标量 semimonotone 证书都落入 (S5)，取 `τ=max{0,(L_C²−1)/4}` 即可。反过来 LT 全部有限常数由 (S4) 包含。因此：**“具有某个上述非退化常参数证书”的全对类，并不比“具有某个有限反射 Lipschitz 常数”的全对类大。** 不同参数可显著改善原模型认证、步长和能量估计，这与引入新非线性模是不同价值。

### 3.1 负负双亏损和临界点必须保留

对 `Δ>0`，`A>0` 等价于

\[
\frac{2[-\rho]_+}{1+\sqrt\Delta}<\lambda<
\frac{1+\sqrt\Delta}{2[-\mu]_+},
\tag{S8}
\]

零分母的右端为 `+∞`。这正是 PPPA v2 Prop 4.12 的步长区间。全图同参数极大性在该区间给full-domain；局部图块的极大性不能代替全图条件。

- `μ,ρ<0` 且 `μρ≥1/4` 时，每一张图都满足 (S1)，来自加权 Cauchy–Schwarz；它不是能作普遍收敛承诺的正则类。在 scaled 参数 `m=r=−1/2`，不等式只剩 `‖a+b‖²≥0`。
- 即使 `μρ<1/4`，也必须检查当前步长 `A>0`。例如 `λ=1, μ=−4/5, ρ=−1/5` 有 `Δ=9/25>0`，但 `A=0`。`F(x)=−x` 满足 (S1)，而 `J_F(0)=H`、自然域仅 `{0}`，所有零消失全对模都失败。
- 一般地，任何 `A≤0` 都允许 `F(x)=−x/λ`；这是整类统一单射门的尖锐失败，不能靠不定二次式重新命名消除。
- `μ,ρ>0, μρ=1/4` 给仿射斜率图 `w=2μx+w_0`；此时 `A>0,Δ=0` 仍可配方，但含 `1/√Δ` 的单调图变换不可用。若 `μρ>1/4`，只能有至多一个图点，按允许空/单点关系的通常约定并非逻辑上的“无任何关系”。

不能声称某个 Hölder RL 例“完全不 semimonotone”：每个图都有上述临界负负证书。能严格排除的是 **固定步长有 `A>0` 的非退化全对常参数证书**。

### 3.2 非线性 RL 的严格超出限于这个非退化全对比较

固定 `0<γ<1`，取完整 Cayley 图

\[
C(p)=|p|^\gamma,\quad
\operatorname{gph}F=\left\{\left(\frac{p+C(p)}2,
\frac{p-C(p)}{2\lambda}\right):p\in\mathbb R\right\}.
\tag{S9}
\]

`M_+` 恰为参数 `p`，所以full coverage、完整单值 resolvent 都成立；`C` 是全局 `γ`-Hölder，在零附近不 Lipschitz。这排除了同一步长任何 (S7) 证书，也排除了任意有限 LT 全对常数。它不排临界/vacuous semimonotonicity，不排零锚证书，也不自动证明这个例子的 PPA 收敛。作为纯正则性反例已经足够，不能再偷加动力学意义。

## 4. 矩阵 semimonotonicity：精确椭球，而不是更换范数口号

CP v1 Def 1.2 已允许对称、可不定的原图矩阵 `(M_0,R_0)`。在本报告scaled坐标令 `M=λM_0, R=R_0/λ`。其全对条件是

\[
\langle a,b\rangle\ge\langle a,Ma\rangle+\langle b,Rb\rangle.
\]

置 `Q=I+M+R, D=M−R`，无交换性假设便有

\[
\langle c,Qc\rangle+2\langle z,Dc\rangle
\le\langle z,(I-M-R)z\rangle.
\tag{S10}
\]

若 `Q≻0`，这精确等价于

\[
\|c+Q^{-1}Dz\|_Q^2\le\langle z,H z\rangle,
\quad H=I-M-R+DQ^{-1}D.
\tag{S11}
\]

矩阵不交换时不能把 `H` 草率写成标量判别式的逐项类比，也不能只替换范数却保留错误的Euclidean交叉项。固定有限矩阵且 `Q≻0` 时，(S11) 仍给某个有限Euclidean Lipschitz反射常数，故不产生真正的非Lipschitz一般模。它保留各向异性、偏移和块结构，可使同一模型的证书远优于最坏标量常数。

`Q` 仅半正定则在 `z=0` 时至多推出 `c∈ker Q`，不保证唯一。取 `M=R=diag(−1/2,0)` 和 `F=diag(−1,1)`，`λ=1`，则第一方向完全退化，自然域为 `{0}×R`，同一输入有无限输出。参数矩阵的核是物理信息丢失，不是可忽略的边界。

`H` 还未必在整个空间半正定；(S11) 只在已表示输入差上成立。若宣称full输入域，则必须有 `H≽0`。用椭球扩张或极大性推出coverage要另外证明，本文不把标量 Prop 4.12 直接替换成任意矩阵定理。

## 5. 竞争性最强的是零锚路线：允许多值，又保持原更新

Evens Def 4.1 从指定锚点定义 semimonotonicity；“全对”是进一步要求所有图点均可作锚。Def 2.1 是另一较弱条件：对于声明的 `S_*⊂zer F`、每个 `s∈S_*` 和全部相关 `(y,w)∈gph F`，

\[
\langle y-s,w\rangle\ge\langle w,Vw\rangle.
\tag{S12}
\]

在普通 PPA `P=I/λ`、物理输入 `p=y+λw` 下，`a=y−s,b=λw,z=p−s`，(S12) 即

\[
\langle a,b\rangle\ge\lambda^{-1}\langle b,Vb\rangle,
\quad
\|a\|^2\le\|z\|^2-\langle b,(I+2V/\lambda)b\rangle.
\tag{S13}
\]

这直接保留原关系的能量下降与实际步 `b`，不经过全对单值化。标量 `V=ρI` 时，不松弛PPA的统一严格下降门是 `ρ>−λ/2`；弱到 `ρ>−λ` 仍可在合适 **松弛** 下进入 PPPA，但松弛更新不再等于原未松弛PPA，不能混为同算法。

### 5.1 全部原outputs的明确例子

取一维完整关系

\[
F(x)=\{2x,x/2\},\quad\lambda=1,\quad
J_F(p)=\{p/3,2p/3\},\quad S=\{0\}.
\tag{S14}
\]

这可解释为不确定正系数反馈，本文不将它冒称为某个自然非凸优化函数的完整次微分。

| 核验项目 | 同一完整关系的实际事实 |
| --- | --- |
| 闭图/outer semicontinuity | 两条闭直线之并；全部图值均保留 |
| full coverage | 对每个实输入，两条显示输出都存在 |
| 同一Fix | `Fix J_F=zer F={0}` |
| true EB | `r_F(x)=min{2|x|,|x|/2}=|x|/2`，故 `d(x,S)=2r_F(x)` |
| weak Minty | 每个 `w∈F(x)` 都有 `xw≥0`，取 `V=0,S_*=S` |
| 原算法/参数 | Evens PPPA取 `P=I`，松弛参数 `θ_k=1`；不是换算法 |
| PPPA其余门 | `η_min=1`，`α_k=1`（非终止步），`θ_k(2α_k−θ_k)=1` |
| 物理收敛 | Thm 2.4(v) 的投影是 `I`，所以原迭代 `p_k` 收敛；`\bar p_k=p_{k+1}`，全部outputs轨道也同结论 |
| 全部选择的精确率 | 任意选择都有 `|p_{k+1}|≤(2/3)|p_k|`；固定较慢支达到 `2/3` |
| 有限长度与留域 | 同号逐步缩小，`Σ|p_{k+1}−p_k|=|p_0|`；任意原点球对全部outputs不变 |

在同一非零输入 `p`，取图点 `(p/3,2p/3)` 和 `(2p/3,p/3)`；它们满足 `z=0` 而 `c=−2p/3≠0`、`⟨a,b⟩=−p²/9<0`。因此任意原点邻域的完整图都不满足任意有限 LT 全对条件，也不满足任何 `ω(0)=0` 的全对反射模。该反例针对明确的全对几何，不靠“某一篇的某一前提不成立”来排除整个理论。

**与仓库现状的必要限定。** (S14) 不排除现有 anchored RLEB：`physical_rleb_gppa.md` 的 C249/C250 已允许零锚多值并能覆盖它。例子的结论是“全对LT→全对RL不是收敛研究的唯一入口”，不是“semimonotonicity比仓库一切RLEB强”。

**不能多套一个旧定理。** PPPA v2 Thm 2.13 另要求闭凸零集、完整零集作锚以及单值连续 preconditioned resolvent；(S14) 不满足最后一条，因此此例线性率应按上述显式证明，不冒称 Thm 2.13 已直接给出。Thm 2.4 的全局收敛调用不受此影响，因为这里 `P` 可逆且未松弛。

### 5.2 零锚与全对均不是自动包含另一切路线

(S14) 已严格分开 weak Minty与全对RL。反向，(S9) 的非Lipschitz反射并不保证任何可用weak Minty能量门；不能从“有一般模”推论“有某个好矩阵V”。实际一般模动力学例需要逐一检查固定矩阵下界、同一零锚和当前算法参数。失败某个固定V不排除其它V、其它锚、局部限制或不同算法。

## 6. 一般模双损失：可以提出，但真正承重的是联合可逆预算

以下是本次推导的候选接口，不声称已发表新定理。设在明确窗口/全部所需点对上有

\[
\langle a,b\rangle\ge-\phi(\|a\|)-\chi(\|b\|),
\qquad\phi(0)=\chi(0)=0.
\tag{S15}
\]

记 `s=‖a‖, t=‖b‖, u=‖z‖`。必要的同坐标可行条件是

\[
|s-t|\le u\le s+t,\qquad
s^2+t^2-2\phi(s)-2\chi(t)\le u^2.
\tag{S16}
\]

同时 `‖c‖²=2(s²+t²)−u²`。所以在已声明有界窗口中，对 (S16) 的联合可行集取上确界，即可定义反射/输出/实际步预算。**不能把两损失各自必须小于半平方当作普遍必要条件。** 常数负负情形 `φ(s)=αs²,χ(t)=βt²` 的当前步长门是 `α+β<1`，可允许其中一个大于 `1/2`；三角约束保留了这种有效范围。

若窗口 `0≤s,t≤M` 有界，`φ,χ` 连续，并满足

\[
\phi(v)+\chi(v)<v^2\qquad(0<v\le M),
\tag{S17}
\]

则 (S16) 的可行点在 `u→0` 时必有 `s,t→0`：否则取收敛子列，三角约束给非零 `s=t=v`，能量条件违反 (S17)。因此联合上确界给某个零消失模。全对量词下这又产生图块单值化；零锚量词下则仅产生实际一步预算，仍允许 (S14) 类型的多值。

例如在 `0≤s,t≤1`，取 `p>1`、`φ(v)=χ(v)=(v²−v^{2p})/2`。则 (S16) 给 `s^{2p}+t^{2p}≤u²`，从而 `s,t≤u^{1/p}`、`‖c‖≤2u^{1/p}`。这是损失趋于临界半平方、却由高阶余量恢复非线性模的机制。它与保留正定常矩阵的常参数框架不同；但这里只是条件推导，尚未给一个新的自然原模型和优于现有RLEB的实际定理。

### 6.1 将联合预算直接用于所有outputs

本小节另取有限维Euclidean空间、非空闭 `S⊂zer F`、有限非降且在零处连续的 `ψ`，`ψ(0)=0`。在普通PPA中，对输入 `x` 取同一最近零锚 `s_0∈P_S(x)`，令 `a=y−s_0,b=x−y,u=d(x,S)`。假设 (S15) 对该输入的 **每个允许输出** 成立，并有完整原残差 EB `d(y,S)≤ψ(r_F(y))`。因为 `b/λ∈F(y)`，正确方向为 `r_F(y)≤t/λ`。

在当前认证窗口内定义

\[
Q(u)=\sup_{0\le v\le u}\ \sup_{(s,t)\text{满足(S16),其中输入量为}v}
\min\{s,\psi(t/\lambda)\},\qquad
B(u)=\sup_{0\le v\le u}\ \sup_{(s,t)\text{满足(S16),其中输入量为}v}t.
\tag{S18}
\]

这里外层上确界使预算非减。于是全部允许outputs都满足 `d(y,S)≤Q(u)` 和实际物理步 `‖x−y‖≤B(u)`。需要 `t/λ` 全在EB gauge合法域内；窗口之外的可行点不能随意纳入或删去。若 `Q(u)≤κu`，`0<κ<1`，且 `Σ_j B(κ^ju)` 有限，则标准有限前缀预算给有限长度与留域：初值总预算严格小于距认证域补集的距离。所有这些结论仍以每个所需输入有合法输出为前件。

这是一条更直接的推广研究入口：保留两侧损失和实际步，先解决原图认证与联合预算，再决定是否需要导出RL。它的吸引力是避免将全部几何提前压成一个反射模；它的风险是 (S18) 可能只是把原难题藏进上确界，若没有计算方法或模型闭式解则缺少可用性。

## 7. preservation 检查：哪些随表示走，哪些不会自动得到

| 要保留的事项 | semimonotone / 矩阵 / 双gauge 的实际状态 |
| --- | --- |
| 同原完整F | 只重写不等式时保留；换成剪切后单调关系是新对象，必须反变换 |
| 同Fix | 对同一个完整 `J_{λF}` 恒有 `Fix=zerF`；对一般允许子关系只能先得 `Fix⊂zerF`，须核零点自输出。直接迭代偏移后的 `C+(B/A)I` 通常改Fix和算法 |
| coverage | 点对不等式没有existence。标量全图同参数极大+Prop4.12步长门可给full-domain；局部/矩阵/双gauge需独立证明 |
| 全部outputs | 全对非退化条件可给所表示图块单值；图块外完整纤维仍需核。零锚条件可以保留真正多值，但必须对每个实际输出成立 |
| true EB | 只能取 `r_F=inf‖w‖`；某个选中值只给上界。单调剪切后的残差不等于原残差 |
| 物理留域 | 普通PPA `‖b‖` 就是物理步；奇异P、非线性核或shadow结果不控制全部物理方向，须独立步长/逆模/纤维运动估计 |
| 同算法 | 同图坐标代换可重建原J；改P、松弛系数或直接迭代变换图的J通常产生不同算法 |

具体地，PPPA Cor 4.10 的单调化 `A=(F−νI)^{-1}−ξI` 是图双射，但原图 `w=0` 变成新坐标 `w−νx=−νx` 与 `x−ξ(w−νx)=(1+ξν)x`，并不通常变成 `zer A`。它能解释原类和极大性，却不是保原零集/原PPA的免费通道。

## 8. 原模型、认证、算法、优先性分别裁决

1. **原模型意义。** 常参数semimonotonicity已有可核的自然来源：上下曲率函数及其梯度、点wise minimum的次微分、infimal convolution、interaction-dominant saddle operators；见PPPA v2 §4.1。CP矩阵框架保留线性耦合的奇异值/块几何。研究应从这些原始数据能否给出非二次双损失入手，而非先按任意Cayley映射反造F。
2. **可认证性。** 线性算子 `F(x)=Dx` 的矩阵证书是精确LMI `sym(D)−M_0−DᵀR_0D≽0`；有曲率/结构的非线性模型可用旧演算规则。只有一个经验散点图、失败的某个LMI或一个特选分支，均不足认证完整图或排除所有参数。一般双gauge若没有原数据估计和可算联合预算，概念一般性不等于可用性。
3. **算法性。** 沿LT→RL放松假设不产生新PPA更新；semimonotone→weakMinty已有PPPA/DRS/CP算法与参数规则。可能的新算法价值应来自可实施的矩阵/步长选择、可认证内层近端求解或新的允许输出规则，并保持相应全部输出/残差结论。
4. **可证明的优先性范围。** tied二次类最迟在本次实读2010预印本已有；二参数和矩阵零锚几何分别在2023 PPPA/CP已有；非单调PPPA与线性分支也已有。这里没有证据宣布“所有一般模双gauge理论早已存在”，也没有证据宣布当前任何一般模推广首创。新的可发表主张必须落到确切非二次原模型、完整输出定理、参数改善或未被已有anchored框架覆盖的机制上。

# DD2 一般符号缺陷的一步精确定理

本文件修订允许缺陷函数 Phi 取正、负或变号时的候选公式。它固定的是有限维自由两锚几何；不把逐尺度几何尖锐性升级为任意固定算子或轨道级结论。

## 对象、量词和假设

令 H = R^n，n >= 2；S 是非空闭集；x,y 属于 H；t = d(x,S) > 0；p 属于 P_S(x)；s = ||x-y||；a = d(y,S)。对每一条受检边，假设

    <x-y, y-p> >= Phi(t),       a <= eta(s),

其中 Phi(t) 是有限实数，eta:[0,infinity) -> [0,infinity)。若 y 属于 J_(lambda F)(x)，而 a <= psi(r_F(y)) 且 psi 非减，则可取 eta(s)=psi(s/lambda)，因为 r_F(y) <= s/lambda。边的量词是对所有受检输出 y；锚 p 只要求是该边的一个最近输入锚。

## 定理：有符号四点包络

定义 E_Phi(t) = t^2 - 2 Phi(t)。若 Phi(t) <= t^2/4，定义

    I_Phi(t) = [ max(0,(t-sqrt(t^2-4 Phi(t)))/2),
                 (t+sqrt(t^2-4 Phi(t)))/2 ].

若 Phi(t) > t^2/4，定义 I_Phi(t) = empty. 对 Phi(t) <= t^2/4，定义可行步长集合

    V(t) = { s in I_Phi(t) :
             (t-s)_+ <= min(eta(s), t+s, sqrt(E_Phi(t)-s^2)) }.

若 eta 连续且 V(t) 非空，则所有合法边满足 a <= M(t)，其中

    M(t) = max over s in V(t) of
           min(eta(s), t+s, sqrt(E_Phi(t)-s^2)).

这个最大值在自由有限闭目标类中是精确最优值：每个可行 s 及相应的 a 都能在 R² 中用两个锚构造达到。

## 证明

记 b = ||y-p||。因为 x-p = (x-y)+(y-p)，且 ||x-p||=t，平方展开给出

    t² = s² + b² + 2 <x-y,y-p>,
    b² <= E_Phi(t)-s².                              (1)

三角不等式给 b >= |t-s|。把它代入 (1) 得

    s² + (t-s)² <= E_Phi(t),
    s² - t s + Phi(t) <= 0.                          (2)

二次不等式 (2) 的根正好给出 I_Phi(t)。若 Phi(t)>t²/4，二次式在所有 s >= 0 上为正，所以没有合法边。

又因为距离函数是一阶 Lipschitz，a >= (t-s)_+；因为 p 属于 S，a <= b <= t+s；由 (1) 还得 a²+s² <= E_Phi(t)；输出假设给 a <= eta(s)。这证明了 V(t) 和 M(t) 的必要性。

反过来取 s in V(t)，并取任意满足

    (t-s)_+ <= a <= min(eta(s), t+s, sqrt(E_Phi(t)-s²)).

令 b=max(a, |t-s|)。由可行条件有 b <= t+s 和 s²+b² <= E_Phi(t)，所以存在边长为 t,s,b 的二维三角形 x,y,p。选取其夹角使内积等于 (t²-s²-b²)/2，便有内积 >= Phi(t)。若 a=b，取 S={p}；若 a<b，在从 y 背离 x 的射线上取第二锚 q，使 ||y-q||=a，并令 S={p,q}。此时 ||x-q||=s+a >= t，所以 p 仍是 x 的最近锚；a<=b 又保证 d(y,S)=a。故所有可行值都可达到。连续 eta 使可行集为紧集上的闭子集，最大值达到。

## 正部候选公式的准确范围

令 D_+(t)=[-Phi(t)]_+，B_+(t)=(t+sqrt(t²+4D_+(t)))/2。

当 Phi(t)<=0 时，I_Phi(t)=[0,B_+(t)] 且 E_Phi(t)=t²+2D_+(t)。这时在 eta 连续非减的条件下，旧 DD2 简化包络是自由几何的精确值：

    min( B_+(t), max over 0<=s<=B_+(t)
         min(eta(s), sqrt(t²+2D_+(t)-s²)) ).

当 Phi(t)>0 时，D_+ 丢失正角度造成的下根和能量余量，只能给安全上界。显式反例为 t=1、Phi(t)=1/4、eta(s)=s。此时 I_Phi={1/2}、E_Phi=1/2，精确输出只能为 a=1/2；正部公式把 D_+ 置零并给出 max_{0<=s<=1} min(s,sqrt(1-s²)) = 1/sqrt(2) > 1/2。因此把 D_+ 公式称为任意符号 Phi 的精确最优刻画是 Invalid。

## 不连续、非单调和广义逆

连续性只用于把 sup 写成 max。若 eta 不连续，应把最大值换为 sup；例如 t=1、Phi=0，令 eta(s)=0（s<=1/2），eta(s)=1（s>1/2），则可行输出的上确界在 s 向 1/2 右侧逼近时达到，但没有最大化点。非单调 eta 或非连续 Phi 仍可逐尺度使用上述 sup，但所得 M(t) 不必连续或非减。

若 eta 非负非减但有平台，令 h(s)=s+eta(s)，并定义广义逆 chi_minus(t)=inf{s>=0:h(s)>=t}。所有满足 t <= s+eta(s) 的合法边都有 s>=chi_minus(t)。用它做有限长度势还需要 chi_minus 可测、正值和相应积分可积；严格可逆不是这一步下界的必要条件。

## 反向门与算子层范围

在 Phi<=0、eta 连续严格增且 0<=a0=A(t)<t 位于 eta 的值域时，令 u=eta^{-1}(a0)。自由几何中 M(t)<=a0 的反向门由

    B_+(t)<=u  或  t²+2D_+(t)<=u²+a0²

给出；正或混合符号 Phi 必须改用 I_Phi 和 V(t)，不能只替换一个带符号 D。

二维两锚构造证明的是自由几何 sharpness。在见证输出 \(y\notin S\) 时，把该边加入投影关系 \(J=P_S\) 并令 \(F=(J^{-1}-I)/\lambda\)，能在完整图中实现这条边及其真残差取等。对于同时受检的投影边，取输出本身作最近锚，内积为零。换成其他最近锚 \(p\) 时，内积为 \(-\|y-p\|^2/2\)。因此在要求 \(\Phi(t)>0\) 的受检输入尺度上，这个默认覆盖构造不适用。固定目标、整窗算子尖锐性和轨道续接各有自己的条件。

## 状态

本定理在有限维 n>=2 的自由两锚闭目标几何中 Proved and Sharp。Phi<=0、eta 连续非减的旧简式 Proved and Sharp。正部公式对任意符号 Phi 的 sharp 主张被显式反例 Refuted。本页只登记一步几何。原真残差非单调版本、最值与广义逆端点、标量比较及长度的函数条件分别见 [C417–C420](dd2_function_hypotheses.md)；一般正下界的完整整窗最优、指定固定算子及受限目标类的动态反向必要性须分别核验，不能由本页几何直接提升。

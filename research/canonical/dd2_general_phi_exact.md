# DD2 一般符号缺陷的精确一步定理（修订版）

本文件固定一个可审查的 theorem version。只用 `D=[-Phi]_+` 的旧版本在正缺陷处只是安全上界，不能称为精确最优刻画。

## 定理

令 H 为维数至少为 2 的欧氏空间，S 为非空闭集，x 为输入点，t=d(x,S)>0。设 p 属于 P_S(x)，y 为输出点，s=||x-y||，a=d(y,S)，并满足

    <x-y,y-p> >= Phi(t),       a <= eta(s),

其中 Phi(t) 为有限实数，eta:[0,infinity)->[0,infinity)。定义 E(t)=t^2-2 Phi(t)。

若 Phi(t)<=t^2/4，定义

    I(t)=[ max(0,(t-sqrt(t^2-4 Phi(t)))/2),
           (t+sqrt(t^2-4 Phi(t)))/2 ].

若 Phi(t)>t^2/4，令 I(t) 为空。定义

    V(t)={s in I(t): (t-s)_+
          <= min(eta(s),t+s,sqrt(E(t)-s^2))}.

若 V(t) 非空且 eta 连续，则所有合法边满足

    a <= M(t):=max_{s in V(t)} min(eta(s),t+s,sqrt(E(t)-s^2)). (G1)

而且 (G1) 是自由两锚闭目标几何的精确最优值：每个可行 s 和 a 都能由二维三角形及第二个锚实现。

当 Phi(t)<=0 时，令 D(t)=-Phi(t)，则 I(t)=[0,B(t)]，其中 B(t)=(t+sqrt(t^2+4D(t)))/2；这时 (G1) 退化为 DD2 的简化包络。固定凸目标、固定单值图或无限维空间时，(G1) 仍是统一上界，但 sharpness 需要额外证明。

## 证明

记 b=||y-p||。由 x-p=(x-y)+(y-p) 得

    t^2=s^2+b^2+2<x-y,y-p>,

所以 b^2 <= E(t)-s^2。三角不等式给 b>=|t-s|，故 s^2+(t-s)^2 <= E(t)，等价于 s^2-t s+Phi(t)<=0，正好给出 I(t)。另外

    a >= (t-s)_+,   a <= b <= t+s,
    a^2+s^2 <= E(t),   a <= eta(s),

所以所有合法输出都被 (G1) 控制。

反之，取 s in V(t)，令 a=min(eta(s),t+s,sqrt(E(t)-s^2))、b=max(a,|t-s|)。由 s in I(t) 和 V(t)，有 b<=sqrt(E(t)-s^2) 且 b<=t+s。因此存在边长为 (t,s,b) 的二维三角形 x,y,p，并可令内积等于 (t^2-s^2-b^2)/2，从而角度条件成立。再把第二个锚 q 放在从 y 背离 x 的射线上，令 ||y-q||=a。由于 a>=(t-s)_+，||x-q||=s+a>=t，所以 p 仍是 x 的最近锚；由于 a<=b，d(y,{p,q})=a。故每个可行值都能实现，连续 eta 使最大值达到。

## 正部公式的反例

任务书的 D_+=[-Phi]_+ 和 B_+=(t+sqrt(t^2+4D_+))/2 在 Phi<=0 时正确；Phi>0 时忽略了正角度造成的根区间和更小能量。取 t=1、Phi(1)=1/8、eta(s)=s。精确能量为 E=3/4，真实最大输出为 sqrt(3/8)。而正部公式给 D_+=0、B_+=1，产生 1/sqrt(2)>sqrt(3/8)。因此“正部公式对任意符号 Phi 是精确最优”是 Invalid；它保留为 safe upper bound。

## 范围

这个定理是逐尺度自由闭目标几何的结果。轨道收敛、有限长度、完整算子层 sharpness、固定凸目标和无限维最近点存在性都需要各自的覆盖、留域、闭图、紧性或投影条件，不能由 (G1) 自动推出。

# germ 商与闭集修补的精确障碍

本页独立证明两个局部诊断，承接9/21失败路线总账N06、N11中可以不依赖缺失原稿重建的部分。这里明定的连续映射空间和闭集不是历史的完整算子空间、动力度量空间或fixed-\(E\)修复纤维。原空间的Baire塌缩、孔隙性、Foran递归及规模比较继续属于[待恢复的来源报告](../operator_space.md#no-go)。

<a id="tr-germ-object"></a>
## C177-v1 / NG-GERM：固定零点的连续自映射与germ商

令
\[
X=\{f\in C([0,1],[0,1]):f(0)=0\},\qquad
d_\infty(f,g)=\sup_{x\in[0,1]}|f(x)-g(x)|.
\]
在\(X\)中定义\(f\sim g\)当且仅当存在\(\varepsilon>0\)，使\(f=g\)在\([0,\varepsilon]\)上成立。\(Q=X/{\sim}\)配商拓扑，\(q:X\to Q\)为商映射。这里没有引入PPA图、收敛轨道、全时间度量或任何认证参数。

<a id="tr-germ"></a>
**结论。** 每个germ等价类在\(X\)中稠密。\(Q\)至少含两个点，且仅有\(\varnothing,Q\)两个开集。因此\(Q\)不满足\(T_0\)、\(T_1\)或Hausdorff分离公理，不能是Polish空间；然而\(Q\)仍是Baire空间。

**证明。** 固定任意\(f,g\in X\)。取连续\(\theta_n:[0,1]\to[0,1]\)，在\([0,1/(2n)]\)恒为1、在\([1/n,1]\)恒为0，中间线性插值。令
\[
h_n=\theta_nf+(1-\theta_n)g.
\]
由于目标区间凸，\(h_n\in X\)，且\(h_n\sim f\)。又
\[
\|h_n-g\|_\infty
\le\sup_{0\le x\le1/n}|f(x)-g(x)|\longrightarrow0
\]
由\(f(0)=g(0)=0\)及连续性成立。因此\([f]\)稠密。

若\(O\subset Q\)是非空开集，则\(q^{-1}(O)\)是非空开且饱和的子集。如果\(O\ne Q\)，取\(q(g)\notin O\)；稠密的\([g]\)必与\(q^{-1}(O)\)相交，与饱和性矛盾。所以\(O=Q\)。常值零映射与\(x\mapsto x\)具有不同germ，故\(Q\)不是单点。任意两个不同点不能被开集区分，得分离公理结论。最后，\(Q\)唯一的稠密开集是\(Q\)本身；任意可数个稠密开集的交仍等于\(Q\)，所以它满足Baire定义。证毕。

**与源陈述的关系。** N06的“自然商通常非Hausdorff”未指定唯一空间；本例只证明上述明确常用商的失败。若把原句“不能冒充Polish/Baire”读成“非Hausdorff推出非Baire”，本例否定这一推理。正确门是分别检查所需分离性、可度量/可完备性和Baire性；单独的Baire性也不能让这个具有平凡拓扑的多点商承担精细大小比较。限制到收敛映射、更换等价关系或全时间拓扑都会改变命题，必须重证。

## C178-v1 / NG-CLOSED-REPAIR：闭性不保证局部线性相交界

对度量空间的非空子集\(A\)，记\(d(z,A)=\inf_{a\in A}d(z,a)\)。本命题排除“闭集自动有线性相交误差界”；距离下确界是否取得是另一项检查，在下文直接复用C166的完整闭纤维。

<a id="tr-intersection"></a>
**有限维相交障碍。** 在通常Euclidean空间\(\mathbb R^2\)中取
\[
A=\mathbb R\times\{0\},\qquad B=\{(t,t^2):t\in\mathbb R\}.
\]
二者闭且\(A\cap B=\{(0,0)\}\)。对任意\(r>0\)和有限\(\kappa\ge0\)，存在\(0<\|z\|<r\)使
\[
d(z,A\cap B)>\kappa\bigl(d(z,A)+d(z,B)\bigr). \tag{TR1}
\]
因此将右端换成两距离的最大值仍不能恢复线性界。

**证明。** 取\(z_t=(t,0)\)、\(0<t<r\)。有\(d(z_t,A\cap B)=t\)、\(d(z_t,A)=0\)，而\((t,t^2)\in B\)给\(d(z_t,B)\le t^2\)。再令\(\kappa t<1\)，便有\(\kappa(d(z_t,A)+d(z_t,B))\le\kappa t^2<t\)。\(B\)是连续函数的完整图所以闭；其它集合断言直接成立。证毕。

<a id="tr-attainment"></a>
**另一个已证明的障碍，直接复用C166。** [OP3的完整闭图](operator_profile_tools.md#op-nonattainment)已有非空闭有界纤维\(E=F(e_0)=\{\sqrt{1+1/n}\,e_n:n\ge1\}\subset\ell^2(\mathbb N_0)\)，其\(d(0,E)=1\)且全部值范数严格大于1。该处已由两点距离\(>\sqrt2\)证明闭性，并核下确界不达；这里不重造另一份缩放等价的正交见证。N11这条一般断言直接映射C166-v1，不计为C178的新结论。

**可用修补与不可转授的范围。** 紧的非空纤维能保证距离达到：连续距离函数在紧集上的极小值由收敛子列取得。有限维非空闭集也能保证最近点，因为极小化列可先限制在一个有界球内；OP3明确依赖无限维并不反驳这一事实。对任意非空集合，只要\(d(z,E)>0\)，每个\(\eta>0\)都存在\(v\in E\)满足\(d(z,v)<(1+\eta)d(z,E)\)，由下确界定义即可；若\(E\)闭且距离为0，则\(z\in E\)。因此有严格预算余量时，可另行证明近似极小化足够，不能在边界等号处默认极小元。

这些例没有构造历史N11的父层、orbit-code、合法修复集合或比例\(1/3\)模型，也不否定已经给定紧性或横截性的特殊修补定理。对实际fixed-\(E\)论证，要逐个输入\(U\)证明合法纤维非空，再证相交距离预算和可实现的选择；固定一个\(V\)后的势估计不能承担该存在量词。

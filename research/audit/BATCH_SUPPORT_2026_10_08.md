# 支持资产、版本报告与次问题接口的逐内容裁决

本批按来源 SHA-256 分配，不按文件后缀授予数学状态。完整数学稿由其他五批处理；这里处理打包、旧图、构建、计算、出处记录，以及 M2/M3 的研究简报。原始字节不改。逐单元摘录是来源报告；其 `rewritten` 表示已写入下面指定用途的规范记录，不表示摘录所称 `PROVED/PASS/verified` 自动成为已证命题。

<a id="support-history"></a>
## 版本与执行记录

旧 README、任务 YAML、manuscript_state、冻结账、校准报告和历史 manifest 的日期、路径、任务状态、贡献判断均保留为当时的报告。状态字段不能从旧项目迁移到今天的 Claim；工作流中的 `VERIFIED` 不能补一个数学证明。期刊建议只记录历史用途，不据旧表提供当前推荐。绝对工作区路径不是今天的有效资源定位。每个原始字段或连续段落另有精确来源范围与处置。

冻结账里“无非幂次严格轨道例”等文字只约束相应旧稿；今天的对数接缝有自己的完整证明。旧稿把临界常数当充分常数、把选定转移与完整关系分开等限制仍保留；任何更强断言必须以现行正文的同一对象和量词为准。

<a id="support-math"></a>
## 简报中的数学断言与任务

M2 要求的是半正定预条件近端的完整输出、实际值域及凸子问题取到性；不是仅在商坐标中有解。其可从原资料恢复的代数及取到性已完整写成 [SP1–SP4](../canonical/secondary_problem_interfaces.md#sp-preconditioned)。核方向收敛、完整多值迭代以及各篇外部定理仍是精确研究门。

M3 的高阶 EB 稳定性请求和原反例的域陪域分别记录。[SP5–SP6](../canonical/secondary_problem_interfaces.md#sp-perturbation) 另给同维向量型反例与证明；原标量型反例不能直接当 PPA 的 H→H 关系。旧简报对一般扰动稳定、最大单调性或全算法收敛的建议不获自动认证。

旧支持记录中的主链数学摘要按现行规范量词理解：Minty 完整纤维、RL all-pairs 与 anchored、真实残差和选定残差、direct 与 energy、Dini 与空间内极限均是不同门。这里的原文摘录仅供逐项溯源；它们不代替 [基础定义](../foundations.md)、[RLEB 正文](../rleb_ppa.md)、[一般模证明](../canonical/general_modulus_dynamics.md) 或 [天然完整关系](../canonical/support_normal_natural_class.md) 的证明。

## 旧图、网页及嵌入来源

v2 的 149 个对象、35 条旧超边和 101 个资产槽是历史图的身份，当前 graph.json 的分母独立。语义对象和关系逐字段登记；所有 35 条旧边另由 [历史边对应表](../HISTORICAL_EDGE_CROSSWALK.md) 回连，不能凭旧 `PROVED` 推断现在的证明状态。尤其旧 h03 的比较序列、h05 的 scalar 锐性和 h07 的平坦族必须采用本轮 manuscript 接口各自的范围，不能从标量序列外推完整算子最优性。

本轮对 v2 HTML 作只读检查：嵌入的 graph-data 与原 JSON 完全相等；68 个 base64 原始载荷逐项 SHA-256 与旧资产登记一致。它们是已存在旧网页的载荷；没有作为新附件重导入。v1 HTML、模板和 JSON schema 是旧展示/结构契约。网页的证据槽存在、合成 DOM 测试通过、文件映射完整，都不证明数学槽中的断言。当前离线视图由现行 graph.json 重建。

## 数学计算与构建代码

11 个数学脚本本轮在副本上逐个重跑，命令、环境、退出码、stdout/stderr 见 [执行记录](SUPPORT_VERIFIER_RUNS_2026_10_08.json)。有随机试验的脚本保留原 seed 和 sample count；有精确有理数的脚本保留其运算类型。PASS 仅指实际测试域，不能证明连续全域、最优常数、一般高维情况或文献先行性。原 JSON/CSV 数值记录各自保留历史身份，不由当前执行输出覆盖。

新增 [secondary 校验](../code/cleanup_interfaces/verify_secondary.py) 核完整/空/多值纤维、奇异 Q、取到性二次模型及扰动的零点/非零/正负边界；有限输入测试的证明边界在脚本输出中明确。

旧构建器、验证器、CJS、Lua、shell 的独立职责是解析、打包、结构验证或排版。不得执行硬编码旧工作区路径去修改原件，也不得把模拟 DOM 当真实浏览器验收。bibliography/bbl 每个条目只提供出处身份，不携带外部定理证明；具体承重调用须经过现行 [文献登记](../LITERATURE.md) 的调用门。

## 容器与排版资产

11 个 ZIP 容器的成员身份/字节全部由固定成员表复核；数学处置沿各成员的 SHA 继承，容器本身不产生新命题。字体 TTF 实读 cmap，只有 U+83E0、U+841D 两个作者字；fsType=8。TFM、ENC 及再生成脚本是其排版资源。PNG 实际查看为作者名“菠萝”的透明文字图，2142×1055、RGBA，无数学图示。它们按角色关闭；不能用 UTF-8 LF 表冒充二进制阅读，也不能继续报为未裁决数学。

这里完成的是资产角色和逐源断言处置。所有外部全文调用、历史执行是否真正发生、原生材料未提供的模型以及总目标开放问题仍以逐单元的具体义务为准，不因全字节覆盖而消失。

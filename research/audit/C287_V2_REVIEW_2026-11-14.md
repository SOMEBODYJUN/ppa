# C287-v2 同模局部全对 RL 接收记录（2026-11-14）

## 审查对象

本记录接收 `research/canonical/rleb_dini_geometry.md#rdg-winding` 的 §1A 与 `CLAIMS.md#c287-v2`。旧 C287-v1 保留原身份：它只要求给定凹非 Dini 模的最近零锚条件。新版本增加的是同一个给定 `omega` 的局部全对反射模；为避免量词偷换，RLEB 的半和兼容明确继续使用一个较小的内部模 `widehat{omega}`。

固定连续、非减、凹 `omega`，`omega(0)=0`，\(\int_0^{r_0}\omega(t)dt/t=\infty\)，以及 `lambda>0`、`0<q<1`。构造使用 `K=20`，在足够小的 `epsilon` 上令
\[
\Omega=\omega-Kt,\quad b=\Omega/4,\quad
\theta=2\arctan b,\quad m=2b/\sqrt{1+b^2}.
\]
`J` 与 `F=(J^{-1}-I)/lambda` 仍是 C287-v1 的全局同胚反演构造，零集为 `{0} union S^1`，工作环带取 `R<1/2`。

## 主代理重构

1. 凹性及非 Dini 条件给 `omega(t)/t -> infinity`。缩小 `epsilon` 可使所有 `[0,epsilon]` 内非退化割线斜率大于 `K`，故 `Omega` 非负、非减、凹，并且仍非 Dini。`b`、`theta`、`m` 连续、非减、凹；`m(t)/t -> infinity`，且 `2m(t) <= Omega(t)`。

2. 对 `x=rp`, `x'=r'p'`，`r,r' in (1/2,3/2)`，`delta=||x-x'||<=R`，交换使 `r>=r'`，记 `t=|r-1|`, `t'=|r'-1|`。有 `|r-r'|<=delta`, `|t-t'|<=delta`, `||p-p'||<=4delta`, `|h-h'|<=qdelta`, `h'<=1+qt'`。凹性和 `theta<=1` 给出
\[
D:=\|R_m(t)-R_m(t')\|\le m(\delta),\qquad t'D\le\delta.
\]
于是 `||Jx-Jx'|| <= m(delta)+(4+4q)delta`，从而
\[
\|(2J-I)x-(2J-I)x'\|\le2m(\delta)+(9+8q)\delta
\le2m(\delta)+20\delta\le\omega(\delta).
\]
这里的 pair gate 是 `x,x' in U_R` 且 `delta<=R`；不能读成环带外或任意尺度的全局 all-pairs 模。

3. 定义内部模
\[
\widehat\omega(t)=2m(t)+(13+4q)t,\qquad
\widehat B(t)=\tfrac12(t+\widehat\omega(t))=m(t)+(7+2q)t.
\]
因 `13+4q<20`，有 `widehat{omega}<=omega`，所以 `omega` 是全对 RL 与最近零锚 RL 的共同上界，但 RLEB 半和兼容使用较小的 `widehat{omega}`。固定 `1<c<1/q`，利用 `m'_-(t)->infinity` 缩小窗口，使 `[0,c epsilon]` 的割线斜率大于 `((1+q)c+7+2q)/(c-1)`。于是 `H(t)=m(t)-(1+q)t` 严增且 `H(ct)>=widehat B(t)`；`psi(s)=qH^{-1}(lambda s)` 给出真残差兼容和严格 `qc<1` 门。

4. `d(Jx,S^1)=q d(x,S^1)`、`t_k=q^k t_0` 和原 C287-v1 的角增量/聚点论证不变。因 `m(t)~Omega(t)/2~omega(t)/2` 且减去线性项不改变非 Dini 积分，`sum_k m(q^k t_0)=infinity`；角步趋零且累计角发散，故每个非零轨道长度无限、聚点集为整圆，不能点收敛。

## 独立审查

未参与构造的 reviewer 从上述精确对象重构了差分分解并确认：必须把 all-pairs 写成局部 `RL_omega(R)`，显式保留 `R<1/2` 和 `delta<=R`；`theta<=1` 是推出 `t'D<=delta` 的小窗条件；`Omega=omega-Kt` 只用于全对 RL 的预算，RLEB 半和兼容不能未经补证改用给定 `omega`，因此保留 `widehat{omega}`；`H(ct)>=widehat B(t)` 需要凹函数割线斜率引理；在这些范围内没有发现代数或量词致命漏洞。

## 数学状态与边界

- **Truth：** 在局部图块、同尺度 pair gate、显式内部模的范围内，推导闭合。
- **Value：** 把旧的“同阶全对模”提升为“同一指定非 Dini 模的局部全对 RL”，同时保留紧零簇全圆绕行；这直接阻断“全对 RL + 集合距离几何收缩自动给点收敛”的宽泛推断。
- **Novelty：** 本轮检索比较了 Mexican-hat 梯度流离散绕行、tame sweeping、凸 PPA 的 self-contracted 长度以及吸引子指数文献；未找到同一固定完整 PPA 同时具备本记录全部对象的直接先行。有限检索不等于全球优先认证。
- **Mechanism：** 非 Dini 角预算在紧目标上可累积为无限绕行；多项式有界可定义的实际位移包络则提供另一条有限长度机制（C287-v1 §2）。
- **未闭义务：** 该反演关系不是单调/次微分/自然凸优化模型；更自然的原生模型、全局 all-pairs 延拓、以及同一个 `omega` 同时承担半和兼容仍未证明，不能在论文中偷换。

## 结论

C287-v2 可作为内部 `derived-checked` 结果进入研究地图；公开先行性、自然算法来源和同一模全套 RLEB 兼容继续标为开放。

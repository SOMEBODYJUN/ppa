# PPA 五层体系：原创性、研究价值与比较语义审计

日期：2026-09-20。角色：独立体系／价值审稿人。

本轮完整阅读 `01_ambient_axioms.md`、`02_convergence_topology.md`、`03_certificate_embeddings.md`、`04_priorart.md`、`05_stress_test.md`、`06_resolvent_family.md`。另直接回查 Rus–Petruşel–Şerban 2006、BRZ 2001、Tikhonov、Sipoş、Leuştean–Nicolae–Sipoş 及 Kohlenbach–López-Acedo–Nicolae 原文中的相关定义／定理。本文不重新审计原 RLEB 论文，不把旧尖点层的纲结论搬进新母空间。

## 0. 审稿结论

**体系方向：通过；作为已经完成的新分类理论：未通过；作为下一阶段研究底座：价值较高。**

五层顺序

\[
\text{完整图}\longrightarrow
\text{相容 resolvent 族＋算法策略}\longrightarrow
\text{轨道 incidence}\longrightarrow
\text{收敛／WPO／回缩结构}\longrightarrow
\text{证书像与类比较}
\]

符合用户要求，且比把某个 RLEB 预算类当作总母空间更准确。但前三层以及弱 Picard／回缩语言的大部分是已知工具的严谨组合；“把空间搭好”不自动构成一篇有新主定理的论文。

本项目真正需要、现有文献未替它自动完成的桥梁是：

1. **完整局部原图到同一良定算法图卡的嵌入**，保留全部 proximal 解、真实最小残差和共同初值／轨道域；
2. **证书到无标签结构坐标的表示**，包括允许步长、统一尾模、有限长度、极限选择模、规范化误差界；
3. **不依赖证书重数的类比较及迁移定理**，跨图卡、步长与拓扑时不能无证保持第一纲／余稀；
4. 在上述体系内真正证明 RLEB 与 LT 的结构差异，而非先要求结论必须为“LT 小、RLEB 大”。

还有一项本轮新增的体系警戒：在最宽闭图 AW 空间中，连固定初值的一步 proximal 可解性都可以是第一纲。故“母空间越大，比较越公正”并不成立；宽闭图应作为**对象本体层**，有意义的算法类比较还需要**中立的良定性层**。第 3 节给出完整证明，已获架构审计代理独立复核。

## 1. 哪些是已有结构，哪些才可能是本项目的新贡献

| 模块 | 原创性判断 | 本项目应保留的具体增量 |
|---|---|---|
| 闭图与固定步长完整 resolvent 的线性图变换 | 定义级／经典图坐标，不宜作创新主张 | 把局部截断、空值、多值及全纤维残差口径写清 |
| 同一图的 resolvent family 与 graph-shear 一致性 | 一般关系版是直接集合代数；非扩张 family 的强表征已有 | 处理非单调、多值和可用步长集合，而不是将各步长当独立函数 |
| 闭轨道 incidence | 由闭一步关系作可数交的标准闭集构造 | 非阻塞、选择量词和策略量词对本项目不可省略 |
| WPO、极限映射、极限纤维分解 | 成熟固定点语言 | 由 RLEB 的完整图证书推出哪些 WPO 定量性质 |
| 固定非点解集上的算子空间／泛型回缩 | BRZ 已有直接先例 | 覆盖非 Fejér、非 Lipschitz 的共同空间及严格嵌入 |
| 全时间距离使长期行为类完备／可分 | Tikhonov 有直接架构先例；本项目的 \(c(X)\) 闭表示证明简洁可信 | PPA 版本的准确适用范围、与单步拓扑的公平桥梁 |
| 共同尾预算层两拓扑等价 | 标准“有限段＋共同尾”原理，重要但单独创新有限 | 不同理论在相同实际结论预算上的比较接口 |
| direct gauge 规范化与标准图卡的 \(F_\sigma\) 编码 | 是有用的项目内整理增量；证明本身较短 | 推广至完整局部原算子、energy 与步长存在量词后，才可能形成有分量的表示定理 |
| 全中立空间中的 LT／RLEB 类结构 | 目前尚无本轮已证结论 | 这是研究核心，不能由以上基础引理代替 |

### 1.1 WPO：不能把新的应用接口误说成新的收敛母类

Rus–Petruşel–Şerban 的 Definition 1.6 已将“每个初值的迭代收敛到一个可依初值变化的不动点”定义为 WPO；Theorem 8.1 给出多种结构等价，但其中若干项允许重选状态空间度量。因此本项目应保留原欧氏／Hilbert 几何，不能借重度量化掩盖 RL、EB 和初值模的问题。[原始论文](https://www.math.ubbcluj.ro/~nodeacj/download.php?f=061rus.pdf)

### 1.2 BRZ：固定多解集、泛型连续极限回缩已不是空白

BRZ 2001 的 Theorem 2.1 在相对 Bregman 非扩张的完备算子空间中，给出泛型迭代在有界集上一致趋于回缩，并给邻近算子的长期控制；Theorems 3.1–3.2 提供相关版本。其母类预设 Bregman 下降，本轮不能据此判定所有 RLEB 已被覆盖，也不能声称“首次研究固定非点解集”。[论文 DOI](https://doi.org/10.1515/JAA.2001.151)、[作者原稿](https://math.haifa.ac.il/dbutnaru/publications/but-rei-zas-jaa.ps)

### 1.3 Tikhonov：全时间拓扑具有独立合理性，也已有先例

Tikhonov 用

\[
m(T,U)=d(T,U)+\sup_{g\in G}a(T^g,U^g)
\]

使 mixing 群作用空间成为完备可分空间（Theorem 1）；同一距离放在全部群作用上一般不可分。它支持本项目的设计原则，不提供 PPA 的现成结论；也足以否定“全时间上确界拓扑本身首次提出”。[原文](https://arxiv.org/pdf/1207.5255)、[DOI](https://doi.org/10.1007/s10883-013-9162-y)

### 1.4 Sipoş 与 abstract PPA：族公理化不是从零开始

Sipoş Theorem 3.3 已将“各正步长映射非扩张＋resolvent identity”与 jointly firmly nonexpansive family 等价联系。Leuştean–Nicolae–Sipoş 的 Theorems 3.13、3.15 给共同固定点存在、相容 family 和步长条件下的 \(\Delta\)／弱收敛，Theorem 5.1 增加 uniform(P2) 后给强收敛率。一般关系 graph-shear 表示本身没有超越这些定理的收敛内容；本项目的缺口是非单调完整图证书怎样进入共同结构空间。[Sipoş 原文](https://arxiv.org/pdf/2006.02167)、[Abstract PPA 原文](https://arxiv.org/pdf/1711.09455)、[后者 DOI](https://doi.org/10.1007/s10898-018-0655-9)

### 1.5 proof mining：证书转共同模也有强先例

Kohlenbach–López-Acedo–Nicolae 的 Theorem 4.1 由 Fejér 性、近似零点界及 regularity modulus 导出共同 Cauchy 模；Proposition 4.4 对非扩张映射给共同收敛率到正则模的反向桥梁。PPA 应用使用整个值集的 \(\operatorname{dist}(0,F(x))\)。因此“证书→统一模”不是新思想；RLEB 的非 Fejér 情形、全纤维接口和无标签类结构仍需本项目自己证明。[原文](https://arxiv.org/pdf/1711.02130)、[DOI](https://doi.org/10.1007/s11856-019-1870-x)

以上对应只是分解已覆盖部分，不是用“局部已知”推断“整体全已知”。

## 2. 应有三个母空间角色，不宜强迫一个空间包办全部

### 2.1 对象本体层：宽闭图空间

有限维首先采用全部非空闭图 \(\mathfrak G\) 的 AW 拓扑；固定步长的完整 resolvent 关系空间与其同胚。完整相容 family 没有新增自由度；步长策略、选择规则和观察域是附加算法数据。

这层适合定义“同一个算子”、比较图的闭包、研究合法性怎样失效，以及连接多个步长。但它不能未经中立合法性限制，就承担所有认证覆盖的统计分母，原因见第 3 节。

### 2.2 实际比较层：无理论标签的良定算法空间

最先可工作版本可取固定 \(\lambda\) 的连续、完整、全输入覆盖、单值 resolvent 图卡；在共同工作域上另声明非阻塞和留域。其单步 compact-open／一致拓扑是研究算子近似的基本拓扑。

这不是偷偷加入 RLEB 或 LT；它是固定被比较的算法语义。需要多值 LTT 时，建立并列的完整关系图卡并明示“所有选择／存在选择”，而非把它硬塞入连续单值层。

若研究原全局 \(F\)，图卡必须保留全图，不得用输入裁剪后的 \(F_{T,K}\) 替换原算子。

### 2.3 动力学子类：收敛者是重要子空间，不是唯一总母空间

在上述算法层内后置定义

\[
\mathfrak C_{\rm lu}\subset\mathfrak C_{\rm pt}\subset\mathfrak A,
\]

分别表示局部一致点收敛与逐初值点收敛。它们可以成为研究“在已收敛算法中，有多少由某理论认证”的相对母空间，但这与“某理论能证明多大范围的算法收敛”是不同问题。

把收敛性写进唯一母空间，不能再将其中的收敛本身记为 RLEB 新获得的优势。它仍能比较认证覆盖、极限回缩几何、初值正则性、可用步长谱和收敛性能。

### 2.4 闭轨道空间是通用动力关系，不是无标签算子统计空间

\[
\mathcal O_\Sigma
=\{(F,\sigma,(x_k)):\text{每步完整 inclusion 成立}\}
\]

闭合是重要基础，但同一个 \(F\) 可能对应大量初值、策略和分支轨道。在 \(\mathcal O_\Sigma\) 中数第一纲，数的是带轨道的对象；投回 \(F\) 不自动保纲。

因此推荐：**宽图本体＋良定算法层＋闭轨道 incidence＋收敛分层＋证书像。**“闭轨道空间更大，所以应作为唯一分类母空间”同样不正确。

## 3. 新增架构警戒：最宽闭图中一步可解性已经第一纲

这是一条一般结构引理，不涉及尖点、不涉及 RLEB 或 LT 的任何特殊构造。它的用途是检验母空间选择，不是证明哪套理论更好。

### 命题 3.1

令 \(E=\mathbb R^d\)、\(d\ge1\)，\(\mathfrak G=\mathrm{CL}(E\times E)\) 配 AW 拓扑，坐标记作 resolvent 输入／输出 \((x,u)\)。对固定 \(x_0\in E\)，

\[
\mathfrak D_{x_0}=\{\Gamma:\Gamma(x_0)\ne\varnothing\}
\]

是 \(F_\sigma\) 第一纲集。

**证明。** 令

\[
C_m=\{x_0\}\times\overline B_m,
\qquad E_m=\{\Gamma:\Gamma\cap C_m\ne\varnothing\}.
\]

\(C_m\) 紧。若 \(\Gamma_j\to\Gamma\) AW 且 \(z_j\in\Gamma_j\cap C_m\)，取收敛子列 \(z_j\to z\in C_m\)。距离函数在共同有界集上一致收敛，得 \(d(z,\Gamma)=0\)，所以 \(E_m\) 闭。

有限点集在此有限维 AW hyperspace 中稠密：对任何给定有限个观察球及误差，用原闭集在一个足够大球内的有限网即可一致逼近相应距离函数。把有限个网点的输入坐标作任意小移动，可令它们全部不等于 \(x_0\)，而逼近误差任意小。因此每个 \(E_m\) 无内点，故无处稠密。

最后

\[
\mathfrak D_{x_0}=\bigcup_{m=1}^{\infty}E_m.
\]

证毕。

### 固定精确解集的版本

给定非空闭 \(S\subsetneq E\)，在

\[
\mathfrak G_S
=\{\Gamma:\Gamma\cap\Delta_E=\Delta_S\}
\]

中取 \(x_0\notin S\)。同一结论仍成立：用 \(\Delta_S\) 加有限局部网逼近原图，并把网点小移到同时避开 \(\{x_0\}\times E\) 和 \(\Delta_E\) 的位置，即保持精确固定集且消除 \(x_0\) 纤维。上述 \(E_m\) 在该子空间中仍闭且无内点。经固定步长线性 graph shear，这就是精确零集 \(S\) 的原算子图版本。

**解释。** 如果共同初值域含有 \(S\) 外的一个指定点，那么任何认证完整 PPA 的类都包含在该点的一步可解类中；因而 RLEB 与 LT 在最宽闭图层里都已因“可解性”而第一纲。这不否定它们的收敛理论，也不能区分优劣。

这正是需要中立良定算法层的结构理由。它不要求提前加入 RL、EB、Lipschitz 或收敛率。

本命题的有限维精确 \(S\) 版本已经由 `ppa_architecture_audit` 独立核验。此处不主张该 elementary hyperspace 引理的原创优先权。

## 4. 全轨道拓扑：合理，但不能任意改变“大小”的含义

对连续单值算法，

\[
d_{\rm dyn}(T,U)=\sup_{n\ge0}d_0(T^n,U^n)
\]

表达“相同初值下所有时刻的行为接近”。它有算法含义，并非为了 Baire 定理凭空捏造的离散拓扑。局部一致收敛类的迭代序列在 \(c(C_{\rm loc})\) 中构成闭集，故 Polish 的论证值得保留。

但要遵守四条限制：

1. **明确研究的是长期行为扰动，而非仅原图／单步扰动。** 两个系统单步很近而长期不同，会被刻意分开；这改变了邻域与稠密性。
2. **相同 Borel 集不意味着相同第一纲集。** 没有保纲桥梁时，不得把动态拓扑中的泛型结论称为原图拓扑中的泛型结论。
3. **\(T\mapsto\Pi_T\) 在动态拓扑连续是该拓扑的设计结果。** 不能将其包装为 RLEB 推出的新算子扰动稳定性；\(x\mapsto\Pi_T(x)\) 的 Hölder 正则性则是另一问题。
4. **先报告两种拓扑，再证明可以桥接的范围。** 固定实际 Cauchy 尾预算 \(e_n\downarrow0\) 时，
   \[
   \sup_{m\ge N}\|T^m-U^m\|_K
   \le 2e_N+\|T^N-U^N\|_K
   \]
   给出该层上两拓扑一致。这是本轮最有用的公平比较接口之一，但层内结论仍不自动提升为全空间结论。

固定步长的完整图坐标变换具有真正同胚保障。更改状态空间的任意非线性坐标则可能改变 proximal inclusion、RL 模和 EB，不应以普通动力系统共轭自动视为本项目的合法不变量变换。

**判断：**全轨道拓扑适合研究无速率限制的收敛类及极限选择结构；它应与单步／图拓扑并行，而不应被指定成唯一正确的“算子占多少”的语义。

## 5. 至少一个值得争取的可发表核心定理目标

以下是研究目标，不是已证成果。不能因为它们现在写得精确，就汇报为已经解决。

### 目标 A：中立算法图谱中的完整证书表示及非平凡类比较

先固定一个不带 RLEB/LT 标签的良定算法图谱，保留原全图、步长、共同初值域与策略。令

\[
\mathcal R=\{\text{存在完整 direct 或 energy RLEB 证书的对象}\},
\quad
\mathcal L=\{\text{存在完整 LT 证书的对象}\}.
\]

目标由两个不可拆掉的部分构成：

**A1，表示桥梁。** 用内生剖面而非任意 proof label 描述 \(\mathcal R,\mathcal L\)，并证明图卡转换、完整局部化和允许步長量词下的像集可测性／拓扑一致性。可使用的坐标包括

\[
\begin{aligned}
\Omega_{F,\lambda}(r)
&=\sup_{\|x-y\|\le r}\|(2J_{\lambda F}-I)x-(2J_{\lambda F}-I)y\|,\\
\mathcal E_{F,V}(t)
&=\sup\{d(u,S):u\in V,\ \operatorname{dist}(0,F(u))\le t\},\\
\tau_{F,\Sigma,B}(n)
&=\sup_{x_0\in B,\,\sigma\in\Sigma,\,m\ge n}\|x_m-x_n\|.
\end{aligned}
\]

测试域、完整纤维和分支量词必须一并写进定义。direct 的规范 gauge 是 A1 的一个起点；energy 任意 gauge、全局外部纤维和存在步长仍未解决。

**A2，真正的结构判决。** 在预先定义的中立收敛类或其中的中立实际尾层，判定

\[
\mathcal L,\qquad \mathcal R,\qquad \mathcal R\setminus\mathcal L
\]

的相对内部、闭包和纲。一个有力的正结果，例如是在该完整中立层的某个非空相对开集 \(U\) 中证明

\[
\mathcal R\cap U\text{ 余稀},\qquad
\mathcal L\cap U\text{ 第一纲},
\]

且 \(U\) 不由尖点、指定 Hölder 指数或某份 RLEB 证书定义。更弱但仍有意义的结果，可以是可认证差集在其内生自然类中非第一纲，配合清楚的相对 Baire 与拓扑转移定理。

如果结果反而是两类都第一纲，或它们有相同闭包，应如实形成体系内的分类结论，再判断是否存在更细的性能谱差异；不能为追求预定答案重新定制母空间。

**发表价值判断：**A1 的完整图谱／规范表示加 A2 的非平凡结论，有机会构成真正的理论论文。只有本轮已有的空间完备性和一个标准紧图卡的 \(F_\sigma\) 编码，尚不足以支撑这种定位。

### 目标 B：可用步长谱的结构定理，作为 A 尚难完成时的实质支线

对原图定义

\[
\Lambda_{\rm wp}(F)
=\{\lambda>0:J_{\lambda F}\text{ 在声明域完整且良定}\},
\]

并分别定义收敛谱和各理论的可认证性能谱。研究这些谱的开性、局部稳定性、量词可数化，以及哪些弱结构保证跨步长迁移。

本轮已知全局有限 Lipschitz reflector 给一个开步长窗口；一般 Hölder 单步几何不够。真正值得证明的是**完整 RLEB 的额外 EB／兼容结构能推出什么**，并与 LT 的窗口结论形成必要充分或尖锐结构对照，而不是再给一个仅有 Hölder 的反例。

若能得到该结构定理，它能回答“两个理论放进同一算子体系后，分别限制了什么”，即使尚未完成全局纲分类也有独立价值。

## 6. 明确的失败判据

下面任何一项出现，都应停止相应大范围宣传，而不是停止整个研究：

- **只剩命名与重组：**主结果只是 graph shear、WPO 命名、\(c(X)\) 闭集和几何级数求和，没有新的桥梁或结构后果。可作理论背景，不够独立新理论。
- **隐藏选层：**最终所谓“自然类”重新预装法向超吸引、特定尖点结构或固定 \(\gamma<1\)，却把层内结果讲成全部 PPA／全部 RLEB 的结论。
- **空泛的最大母空间：**两类在全闭图中都因一步无解的泛型障碍而第一纲，然后据此评判理论优劣。第 3 节表明这没有比较价值。
- **拓扑制造结论：**仅在全轨道拓扑中证明某类小，却不说明换了邻域，或无桥梁宣称原图扰动下也小。
- **数了证书或轨道而非算子：**对多重 witness、多个策略或多个轨道做范畴统计，然后无证投回原对象。
- **仅修包含号：**把 LT 作为额外证书标签直接并入框架，再将形式包含当作覆盖优势。真正需要的是原条件推出的可验证性质与新的结构定理。
- **丢掉完整纤维：**局部裁剪后改变最小残差或 proximal 解集，仍声称嵌入原算子。此项是数学失效，不只是创新不足。
- **从“大”直接推出“好”：**第一纲／余稀不是概率、比例或计算收益；广覆盖还须兼顾可验证性、共同吸引域、步长容忍和实际结论强度。

## 7. 价值等级与下一步顺序

采用四档而非虚构期刊档次：V0＝组织材料；V1＝可靠基础模块；V2＝可独立成文的实质定理；V3＝有明显推广力的核心理论。

| 当前部分 | 当前等级 | 说明 |
|---|---|---|
| 五层架构及对象／量词清理 | V1 | 对项目非常必要，基础原则的原创性有限 |
| 全轨道完备／Polish 与共同尾桥梁 | V1 | 数学内容真实，精确 PPA 版本尚需完整优先权核查；不能单独高估 |
| direct 规范化与标准图卡 \(F_\sigma\) | V1 | 有效技术增量，范围仍局部且 proof 较短 |
| 完整局部图谱、energy 规范化、步长谱／投影桥梁 | V2 候选 | 尚未完成；可成为新结构定理的承重点 |
| 中立体系中的真正 LT／RLEB 类比较 | V2–V3 候选 | 结果和广度决定等级，目前无已证总体判决 |

建议下一阶段只保留三项承重任务，不立刻再做泛型尖点构造：

1. **冻结中立规格。** 统一完整原图、算法对象、共同域、策略／选择量词、单步与动态两种拓扑；把已证定理与额外公理逐条分开。图本体、良定算法层、收敛层和轨道 incidence 各司其职。
2. **完成结构嵌入。** 把 RLEB-direct、energy、LT 和 pointwise LTT 放到同一内生性质表；首先解决全纤维局部化和规范 gauge／性能谱，不把 LT 包含问题当主难点。
3. **再选择一个真正的分类定理。** 可以是目标 A，也可以先攻目标 B。证明或反证都应在已冻结空间中进行；不能根据想得到的结果倒改母空间。

**最终判断：**用户提出的“先建体系，再看 RLEB/LT 的位置”是正确的研究组织要求。本轮已能建立可信底座，但还不能宣布由此发现了新的全局分类理论。最重要的进展不是证明某个尖点很坏，而是现在已清楚：应该统计什么对象、哪些拓扑有独立含义、现有文献能接到哪里，以及哪几条新桥梁真正决定后续论文价值。

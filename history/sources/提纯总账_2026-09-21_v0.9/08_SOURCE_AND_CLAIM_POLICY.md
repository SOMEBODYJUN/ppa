# 来源、版本与声明政策

## 1. 三层事实

任何未来文档都必须把内容分成：

1. **数学事实**：命题在明确量词下已证明；
2. **优先权事实**：是否已有同对象、同量词、同结论的先例；
3. **价值判断**：是否足以形成论文或体系。

三者不得相互替代。数学通过不等于原创，存在另一证明路径也不等于新判据无价值。

## 2. 权威版本

- 旧报告若被申诉复核或负定理推翻，标为 `SUPERSEDED`，不得并列引用。
- 同一结论出现多个版本时，以“最终裁决＋同版红队＋哈希记录”三者一致的版本为准。
- 历史路径存在但当前文件缺失时，只能引用状态，不得引用证明细节。

## 3. 内部索引格式

恢复原件后，每个文件应登记：

| 字段 | 内容 |
|---|---|
| `asset_id` | 稳定内部编号 |
| `filename` | 实际文件名 |
| `sha256` | 文件散列 |
| `role` | 原稿/证明/审计/反例/文献/发布 |
| `status` | CURRENT / HISTORICAL / SUPERSEDED / BLOCKED |
| `claims` | 支持的主张编号 |
| `depends_on` | 上游文件 |
| `supersedes` | 替代的旧文件 |
| `evidence_level` | V-A/V-B/P/HOLD/NO-GO |

## 4. 外部文献格式

每条外部来源必须保留：

- 完整题名、作者、年份、DOI/arXiv；
- 实际读取版本；
- 定理/命题/页码；
- 假设对应；
- 已覆盖部分；
- 未覆盖部分；
- 读取等级；
- 最后核验日期。

搜索结果、摘要或关键词相似不得作为覆盖证明。

## 5. 失败路线格式

所有失败记录只用以下五行：

- 尝试；
- 动作；
- 发现；
- 结论；
- 可复用部分。

证明和反例放在链接文件中，不在主总账重复展开。

## 6. 本版的限制

本版没有重新取得旧研究包的文件字节，因此：

- 内部文件索引来自历史记录；
- 外部文献级别来自历史审计的报告性描述；
- 数学公式只保留历史记录中多次复核或明确终裁的部分；
- v1.0 必须在原件恢复后补齐哈希、相对链接、主张—文件映射和文献 BibTeX。

# Codex 下一轮旗舰攻关任务书

## 总规则

- 同时只开三条：A Markov、B multiweak、C momentum DRS。
- 每条都必须保留实际算法、实际 residual、实际目标集和完整量词。
- 任何结论必须标记 `PROVED / COMPUTATIONAL EVIDENCE / PENDING NOVELTY / OBSTRUCTED`。
- 成功标准是类级主定理 + 自然模型 + 锐边界 + 最近理论排除；单个漂亮例子不算旗舰完成。

## A. Markov：相关性感知的 necessary/sufficient theory

### 输入

- `ATTACK_MARKOV_SUBREG_NECESSITY_CONJECTURE.md`
- `AUDIT_MARKOV_COUNTEREXAMPLE.md`
- `ATTACK_MARKOV_CONDITIONAL_REPAIR.md`
- `AUDIT_MARKOV_CONDITIONAL_REPAIR.md`
- `AUDIT_MARKOV_NOVELTY_AND_JOURNAL.md`

### 主任务

从 conditional/fibered/adapted OT 现有工具出发，为随机 proximal/splitting 构造原生可验证的 correlation-aware residual；证明目标识别、定量 EB 和 uniform rate 的精确关系。

### 必须交付

1. 自然投影反例与 exact-zero/no-Hölder 反例的正式定理。
2. 不被普通 Gibbs/weak-Poincaré 定理直接覆盖的随机 proximal 或 random DRS/FB 类。
3. 条件残差从原生算子/集合数据的计算公式。
4. 线性或一般 gauge 的必要—充分定理。
5. 同步 (Psi)、实际位移、conditional residual 的严格比较。

### 停止条件

若正向部分完全退化为已有 tensorization，则只保留反例与修正问题，不再宣称完整旗舰理论。

## B. Multiweak：全非势签名反馈与表示排除

### 输入

- `ATTACK_IRREDUCIBLE_MULTIWEAK.md`
- `AUDIT_MULTIWEAK_ADR_FLAGSHIP.md`
- `ATTACK_MULTIWEAK_POSITIVE_DESIGN.md`
- `AUDIT_MULTIWEAK_POSITIVE_DESIGN.md`
- `AUDIT_NEGATIVE_RELAXATION_PRIOR_ART.md`

### 主任务

把 mixed-pole signature feedback 写成完整全非势、多值 central 主定理；证明同 oracle/同 state 意义下不被现有 positive matrix-relaxed PPPA、DCE 或 2608.16609 直接表示。

### 必须交付

1. 任意 (A_i=-M_i+e_i)、Lipschitz 非势扰动的 coverage 与收缩。
2. 强单调 maximal central relation 的 rank-one shared secant 定理。
3. 一个自然 multiblock/KKT/weakly-convex 模型和旧理论外参数区间。
4. 必要签名或最优反馈定理。
5. 物理 generalized EB 到 lifted residual 的同目标转移。

### 停止条件

若允许自然坐标变换后被现有框架完全包含，则降为谱分类与参数选择模块。

## C. Momentum DRS Conjecture 5.7

### 输入

- `ATTACK_MOMENTUM_DRS_CONJECTURE_5_7.md`
- `verify_momentum_drs_conjecture.py`
- `pep_momentum_drs_cutting_plane.py`

### 主任务

先在 (gamma=\lambda=1) 下恢复全 (N) PEP 对偶证书，再处理一般参数。

### 必须交付

1. 明确的 Gram/interpolation SDP。
2. 由 (N=1) 锐 SOS 和全 (N) 等号族反推出的符号乘子。
3. 对所有 (N) 的解析 PSD/SOS 分解，或一个可恢复函数的严格反例。
4. 若成功，说明证明方法是否推广 Conjecture 5.6/残差猜想。

### 停止条件

若高精度 PEP 稳定给出大于猜想界的值，立即停止证明路线并恢复反例；若只能得到数值证据，不得写成解决。

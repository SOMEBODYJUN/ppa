# RLEB—LT—极大单调研究资产：提纯总入口

版本：2026-09-21 · transcript-grounded v0.9

## 1. 这份资产解决什么问题

本包把此前分散在 RL、锥、Markov/OT、solution-selection、Koopman、算子空间、Baire/多孔性及内禀模表示各阶段的成果，重新压缩成可继续研究的主资产。

它不按对话时间复述过程，而只保留：

- 已经证明或经独立审核支持的数学核心；
- 已经碰壁的路线，以及碰壁的准确原因；
- 仍然有效的技术接口和可复用构件；
- 当前唯一值得继续的体系级问题；
- 内部文件索引与外部先行文献索引；
- 每一项结论的证据等级和原件可用性。

## 3. 当前总判断

### 已经建立

- RL、锥、Markov/OT 三条理论主线均有可保留的数学内容；不能因组件已有就判整体重复。
- solution-selection 新稿的 A–C 数学审计为 `PASS-AFTER-REPAIR`，精确联合结果在已核范围内未找到完全相同先例。
- 在多个自然的普通 Baire、轨道理想和多孔性环境中，LT 与 RLEB 会一起被判“小”；这是一组正式 no-go 结果，而不是直觉失败。
- 原 ‎\((X_D,d_{\rm dyn})\) 的绝对孔隙主目标已经被严格否定：RLEB 整体属于 \(\sigma\)-lower-porous，故原先希望的非 \(\sigma\)-upper-porous 结论为假。
- 证书选择无关的“内禀联合模谱”表示层已经通过审核：完整图、全部真实步长、共同窗口、反射模、真实全纤维残差模和单调响应可以无损编码三类成员资格。

### 尚未建立

- 尚无一个自然、参数中立、能真正区分 RLEB、LT 与极大单调类大小的最终体系。
- 尚无三类的最终纲、孔隙、prevalence 或其他规模分类主定理。
- 当前内禀模谱只有表示层通过；纯响应商的自然 Baire 性、大小回传和实际三类分离仍未解决。

### 当前策略

不再继续参数细化、计算化简、特殊几何例或换名编码。下一成果必须同时包含：

1. 自然母空间；
2. 三类规范嵌入；
3. 与证书参数无关的大小结构；
4. 真正的三类比较定理；
5. 证明结束后可完全拆除的脚手架。

## 4. 证据标签

| 标签 | 含义 |
|---|---|
| `V-A` | 历史记录显示已由独立数学审核通过，且有明确内部报告索引 |
| `V-B` | 阶段级结论已通过，但本轮没有原始证明文件可逐字节复核 |
| `P` | 候选、提案或只完成推导骨架 |
| `HOLD` | 数学可能成立，但原创性、价值或范围门未关闭 |
| `NO-GO` | 已有严格反例、归约或终裁，禁止作为主线重启 |
| `SUPERSEDED` | 后续结果已纠正或替代旧结论 |
| `SOURCE-MISSING` | 历史上有文件名或路径，但本轮未提供原件 |

## 5. 重要边界

本版依据当前可读的完整研究过程记录整理。历史研究包、LaTeX、PDF、审计稿及压缩包的路径和作用已经纳入索引，但这些原件本轮没有全部重新附入，因此：

- 本包是“提纯总账和导航”，不是对旧原件的逐字节替代；
- 标为 `SOURCE-MISSING` 的条目不得仅凭本包引用为定理证明；
- 恢复原始 ZIP、证明稿和审计报告后，应按 `08_SOURCE_AND_CLAIM_POLICY.md` 升级为 v1.0。

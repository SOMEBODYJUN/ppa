# Author-name font resource

The author is displayed exactly as **菠萝** (U+83E0 U+841D).

The existing runtime supplies a CJK font through `fitz.Font("china-s")`: its reported name is `Droid Sans Fallback Regular`, with 3,556,308 source bytes. The installed PyMuPDF/MuPDF wrapper describes its default CJK font as DroidSansFallback from Android. No font download or installation was performed.

`build_author_font.py` extracts only the two required Unicode characters and their component glyphs, assigns PostScript glyph names, and generates native pdfLaTeX resources:

- `author-cjk.ttf`: the 1,300-byte subset, internally named `AuthorNameCJK`.
- `author-cjk.enc`: the 256-slot TeX encoding with the two characters in slots 0 and 1.
- `author-cjk.tfm`: the corresponding TeX metrics, generated by installed `ttf2tfm`.

`main.tex` embeds this font through its PDF font map and supplies Unicode mappings for both glyphs. The visible name is text, not a raster image or a post-build overlay. PDF text extraction and author metadata both return `菠萝`.

A normal pdfLaTeX build uses the supplied three resources directly. Regenerating them, if desired, requires the producing environment's PyMuPDF, fontTools, and `ttf2tfm`; run `python3 build_author_font.py`. The source font's OS/2 `fsType` value is 8 and is retained in the subset. This provenance note does not substitute the PyMuPDF package's license for a font-specific license.
